## 1. 判据

互换性分析是上游结论，平台只认格子里的固定句「不影响互换性」（六个字，全等）。

| 结论 | 核价对象 | 走哪条 |
|------|----------|--------|
| 影响互换性 | 新零件号 | 现网设计变更 |
| 不影响互换性（能直接换装，只改材料） | 同号，材料从生效月切开 | **材料变更** |
| 没有结论 | 不准猜 | 两条都拒 |

零件号变不变是输出，不是原因。

本通道只收 **普通冲压件、材料真的变了**。一条不过 **整本拒**，禁止修格子当成功。

命名跟冲压现网：字段 `material`，列表「材料」，切点 `before_material` / `after_material`。料厚字段 `thickness`，切点 `before_thickness` / `after_thickness`。禁止再开 `grade` / 牌号 一套。工作表名「工程变更单（材质）」沿用工艺确认表列名（差一字拒），列名写「变更前材料 / 变更前料厚 / 变更后材料 / 变更后料厚」。

| 对象 | 为什么拒 |
|------|----------|
| 拼焊件（`is_tailor_welded`） | 不按子片切，不改总成一行 `material` |
| 利废件（`is_offal_nested`） | 材料跟母件废料走 |
| 家模副产品（`is_scrap_byproduct`） | 材料按废料 |
| 变更前材料 = 变更后材料 | **不是换** |

时间轴：切点必须 **往后切**。**变过以后还可以再变**：再 insert 一本，禁止改上一刀、禁止改工艺 `material`。细则见下节与 [02-upload-gates.md](02-upload-gates.md)。

## 1.1 再变；变更前 = 库里最新材料

工艺行上的 `material` 是投产字，**不是**「现在用的材料」。现在用的材料只认解析器。

上传「工程变更单（材质）」时，列 **变更前材料** 必须与 **该身份在本本生效月、不含本本** 的解析值 **全等**。这个值就是库里的最新材料：

| 库里已有切点 | 变更前必须写成 |
|--------------|----------------|
| 还没有成功切点 | 工艺行 `material`（115AA 第一次 = `DC01`） |
| 已有成功切点 | **上一刀的 `after_material`**（115AA 第一刀之后 = `DC03`），**禁止再写 `DC01`** |

写错（第一刀之后仍写 DC01→别的材料）→ `ECM_BEFORE_MATERIAL`，整本拒。不要拿工艺表当变更前，除非解析器算出来就是工艺表那个字。

再变硬条件：

1. 新变更版本（`MAT-YYYYMM` = 新生效月）
2. 新生效月 **严格晚于** 该零件已有最晚切点
3. 变更前 = 当时最新解析值
4. 变更后 ≠ 变更前，且与工艺同一套材料档案（stamping_parts.material 那条 FK）
5. 变更前料厚 = 工艺 `thickness`；变更后料厚相对变更前 **不能超过 20%**（`|后-前|/前 > 0.20` 拒）
6. 再 insert，禁止 UPDATE 上一刀

同一零件不要在同一本里写两行（那是重复，不是再变）。

### 1.2 来回、回滚（对照是否通畅）

T13J 两本：`MAT-202506` DC01→DC03，`MAT-202507` DC03→DC01。工艺行始终 DC01，生失效始终投产那一套。

| 库里切点 | 05 月当月材料 | 06 月 | 07 月及以后 | 再传 |
|----------|---------------|-------|-------------|------|
| 无 | DC01 | DC01 | DC01 | 06 样表过 |
| 只有 06 | DC01 | DC03 | DC03（06 未结束） | 07 样表过；再传 06 拒 |
| 06+07 | DC01 | DC03 | DC01 | 只能再传 **晚于 07** 的月；变更前必须 DC01 |
| 只回滚 07，06 仍在 | DC01 | DC03 | DC03 | 可再传 07（变更前仍须 DC03） |
| 07 再 06 都回滚 | DC01 | DC01 | DC01 | 可按样表再走一遍 06→07 |

回滚按 **基地 + 冲压工厂 + 项目 + 零件号**：该身份还有更晚成功切点就不能先删更早那本。振华的更晚刀不拦全鑫同号。列表仍是整本删除，所以 **本本里任一零件号** 在同基地同厂同项目上还有更晚刀 → 整本 `ECM_ROLLBACK_BLOCKED`。只看本通道 Excel 落下的切点。07 本全是别的零件、06 里的号没有更晚刀 → 可以回滚 06。

一本版本 **必须有厂**。成功 UNIQUE = 基地 + 项目 + 冲压工厂 + `MAT-YYYYMM`。振华的 `MAT-202506` 不占全鑫同月同版本。

列表删的是一本上传头，不支持单条切点回滚。唯一删除入口是 `DELETE /uploads/{id}`：成功头整本回滚该头下全部切点+链接+头；失败头只删头。禁止 `DELETE .../orders/{id}`，禁止按零件号只滚一行。本本任一零件号在同基地同厂同项目上还有更晚成功切点 → 整本 `ECM_ROLLBACK_BLOCKED`。

**下游计算不改公式。** 零件价仍按 `part_id` 取件，最后仍是 `grade == material`。要对上当月材料，钢材联动和零件单价都调冲压 **`list_materials_as_of`**。不改 `list_with_processes`。见 [04-steel-and-part-cost.md](04-steel-and-part-cost.md)。

## 2. 为什么独立（ADR）

设计变更现在是五句（完成停止 / 改图 / 增加零件 / 此件不装 / 增加分总成）。同号换材料不在这五句里。同号 UNIQUE 一行、换号抄旧 `material`、同号跳过。同号换材料塞进去会同时撞这些门。

已否决：同号第二行工艺；在旧行上改 `material`。

已定：工艺行仍是投产那一行。材料变更历史在冲压零件下，与工序同级。本通道只存这一本 Excel。当月材料由冲压 `list_materials_as_of` 按历史叠出。

禁止把材料变更写成设计变更的一种。禁止写回 `stamping_parts.version`。**禁止写生失效四列**（`effective_year` / `effective_month` / `expiry_year` / `expiry_month`）。材料变更不是改图，不到期、不另开一段有效期。

全部材料变更回滚完（该零件切点删光）：零件行必须与 **第一刀上传前** 逐格相同，包括生失效。不是「回滚时再改回去」，而是 **自始至终没动过**。设计变更改过的生失效不归本通道还原。

和设计变更衔接：

| 事 | 规则 |
|----|------|
| 先材料、后改图 | 工艺 **整行抄旧号**（投产 `material` 仍是旧号那一格，不准改写成解析值）。历史整表插到新零件 |
| 先改图、后材料 | 切点打在 **当前仍有效的零件号**（AB），只来自本通道 Excel |
| 同一零件同一月既改图又改材料 | **整单拒收**。只问冲压：该号生效月等于本本切点月。不查设计变更单 |
| 切点月已停号 | 工艺对该月 `is_in_period` 为假 → 不能切材料。停号只认生失效四列 |
| 共用件 | 同号切点对该号所有冲压件用法同时生效（不写 BOM、不算总成） |

SOP 再导可改投产列。该号上 **已经有切点** 时：再上传材料变更 **整本拒**（`ECM_PROCESS_MATERIAL_CHANGED`），先回滚删掉该号旧切点，再按新投产字重新切。切点还在时，解析仍从（已改过的）工艺列叠旧 `after_material`，所以不准再切、必须先清掉重来。

## 2.1 切片边界（禁止蠕虫）

说白了：材料变动属于冲压零件。历史表在冲压域。本通道只存 Excel。**一个接口：** `list_materials_as_of`。零件价计算器、钢材 `grade ==` 不改。禁止改 `app/common`。核价引擎不改。`list_with_processes` 不叠材料。零件明细不另开接口，`GET /api/stamping/parts/{id}` 带回 `material_changes`。

| 准 | 不准 |
|----|------|
| 本通道：Excel、上传、列表、整本回滚（回滚时调冲压删历史） | 改零件价公式、改核价引擎；本通道查询历史表 |
| 冲压：历史的插入、删除、按零件列出、当月叠材料 | 冲压 import 本通道或读切点单 |
| 钢材 Step1、零件价 prepare 都调 `list_materials_as_of` | costing 查历史表；改 `list_with_processes` 叠材料 |
| `list_material_specs(location)` 保持现网，只给统计 | 给它加年月；新开规格 HTTP；改 `GET /materials` |
| 普通件材料来自冲压历史叠在工艺列上，只出现在返回行上 | 给 session 里的 `StampingPart.material` 赋值或 flush 回工艺列 |
| 向冲压读工艺身份与生失效时调 `StampingDesignChangeService`。写入或删除历史时调 `StampingMaterialChangeService`。设变抄历史也调后者 | 设变调用本通道抄历史；本通道查设计变更单；改 `clone_revise_part_payload` 写历史；解析值写入新号工艺 `material` |

## 3. 范围

做：独立 Excel、上传/列表/整本回滚、**`list_materials_as_of`（钢材与零件价共用）**、原件由本通道下载。只切普通件。

不做：改零件价计算器、改 `SteelPrice.grade ==`、核价引擎、种树、换号、改 `app/common/`、拼焊/利废/副产品换材料、把叠出的材料写回工艺表、回滚时代重算、默认给所有用户材料变更菜单。

## 4. 现网举例（芜湖 T13J · 2025年06月）

**前提（第一刀）：** `DC03` 冲出来能直接装，不影响互换性。06 月变更后解析必须是 `DC03`。07 月样表是再变回去，变更后是 `DC01`。

振华 `V3-01`，料厚 1.5 mm，工艺生效 2025年01月：

| 零件号 | 名称 | 净重 kg |
|--------|------|---------|
| `403014115AA` | 左B柱气囊导向支架 | 0.151 |
| `403014116AA` | 右B柱气囊导向支架 | 0.151 |

对照样表（格子即规格）：

| 格 | 字 |
|----|----|
| 基地 | 芜湖 |
| 项目 | T13J |
| 变更版本 | `MAT-202506`（必须等于生效年月的年+月） |
| 生效年月 | `2025年06月` |
| 冲压工厂 | 安徽振华汽车部件有限责任公司 |
| 两行零件 | 上表两号，DC01→DC03，变更前/后料厚都是 `1.5`，互换性「不影响互换性」 |

一本只写这一厂。上传页必须选 **芜湖 / T13J / 2025 / 06**。头上必须落下冲压工厂；版本占用按 **基地+项目+厂+MAT-YYYYMM**。

导入后工艺行 `material` 仍是 `DC01`，`version` 仍是 `V3-01`。2025年05月解析 DC01；2025年06月解析 DC03。**库里最新材料从此是 DC03。**

再变回去（测试配套，必须先有 06 月那一本）：

| 本 | 文件 | 上传页 | 版本 | 变更前 | 变更后 | 料厚 |
|----|------|--------|------|--------|--------|------|
| 第一刀 | [samples/t13j-2026-06-material-change.xlsx](samples/t13j-2026-06-material-change.xlsx) | 2025 / 06 | `MAT-202506` | DC01 | DC03 | 1.5→1.5 |
| 第二刀 | [samples/t13j-2026-07-material-change.xlsx](samples/t13j-2026-07-material-change.xlsx) | 2025 / 07 | `MAT-202507` | **DC03**（对齐最新） | DC01 | 1.5→1.5 |

07 月若仍写变更前 DC01 → `ECM_BEFORE_MATERIAL`。两刀之后工艺行仍是 DC01；2025年06月解析 DC03，2025年07月起解析又是 DC01。

不要搅：全鑫投产就是 DC03 的铰链板；边梁 `502007777AA`；改图样本 `551003095AA`（那是 2025年05月设计变更，不是本通道）。
