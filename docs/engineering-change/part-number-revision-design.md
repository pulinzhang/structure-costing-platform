## 0. 对人怎么叫（采购、商务、设计填表）

同一件事只准一个称呼。封皮列名、菜单、提示语、样表都用左列。程序实现仍可用右列那些词，见 §4；**对人可见的字只用左列**。

| 对人说 | 就是 | 不要对人说 |
|--------|------|------------|
| 工程变更 Excel | 封皮 + 材料清单 + 工艺确认订在一本；模具布点有就带、没有也能过 | 合册、变更包 |
| 封皮 | 第一张表，一行一种改法 | 变更头、表头 |
| 生效年月 | 新总成从这月开始用；旧总成用到上一月 | 切点、切点月 |
| 总成 / 一级 / 二级 | 材料清单那三层 | L0 / L1 / L2 |
| 变更前总成 / 变更后总成 | 封皮上的交货总成号 | 树根、L0 |
| 总成名称 | 交货总成的名称；变更前后相同，只写一列 | 把名称写成两列 |
| 变更前零件 / 变更后零件 | 封皮上这一次动到的那一层零件号 | 把零件号写进总成列 |
| 零件名称 | 那一层零件的名称；变更前后相同，只写一列。零件层级=总成则空 | 把名称写成两列 |
| 完成停止 | 这个交货总成从生效年月起不再交货 | 停用、作废、删除 |
| 改图 | 图纸改了（多孔、少孔、改料厚都算）。一物一码，**同一颗**零件号跟着改成 AB | 换号、改版、升版（会和投产清单 D/09 混） |
| 增加零件 | **原来的交货总成还交货**，在原来的总成上另外加一颗零件（新号，不是旧件改成 AB）。不是另外交一个新总成 | 加零件、新增总成、独立总成、加行 |
| 此件不装 | 总成还交货，这一颗不装 | 胶块不装、减件、去除 |
| 材料清单序号 | 投产清单上的序号；系统按变更前总成带出，人不用填 | SOP序号 |
| 投产导入 | 第一次整表进来 | 对人少说 SOP |
| 模具布点 | 第三张业务表；表名仍是「零件汇总」（和日常模板相同） | 把「零件汇总」当成材料清单 |
| 本月 | 页面没选月份时 | 墙钟月 |

封皮固定十列：**项目、生效年月、变更类型、变更前总成、变更后总成、总成名称、零件层级、变更前零件、变更后零件、零件名称**。零件层级只准填总成 / 一级 / 二级。基地、顾客在上传页选；材料清单序号系统按 **变更前总成** 带出，人不用填。封皮变更类型只准这四句：**完成停止、改图、增加零件、此件不装**。

先写清楚改的是哪个交货总成，再写这一次动到的零件。增加零件是加在原来的总成上，不是另外交一个新总成。变更前总成 / 变更后总成必填（AA→AB）；不要把新零件号写进总成列。总成名称、零件名称给人看：变更前后名称不变，各只一列。零件层级=总成（含完成停止）时零件名称空。导入按零件号认，不按名称认。日常 **封皮恰好一行、只改一个交货总成**。四种类型这样填：

| 变更类型 | 变更前总成 | 变更后总成 | 总成名称 | 零件层级 | 变更前零件 | 变更后零件 | 零件名称 | 材料清单 |
|----------|------------|------------|----------|----------|------------|------------|----------|----------|
| 完成停止 | 这个交货总成号 | **空** | 该总成名称 | 必须 **总成** | **空** | **空** | **空** | **不写** 这个总成 |
| 改图 | 旧交货总成 | 新交货总成（末两位 AA 改成 AB） | 该总成名称 | 总成 / 一级 / 二级 | 那一层旧号；层级=总成则空 | 那一层新号；层级=总成则空 | 那一层名称；层级=总成则空 | **恰好一个** 新交货总成 = 封皮变更后总成；层级不是总成时，从总成写到改了图的那一层 |
| 增加零件 | 原来那个交货总成 | 同一个总成改成 AB | 原来那个总成的名称 | 必须 **一级或二级** | **空**（没有旧零件可对） | 新加的零件号 | 新加的零件名称 | 总成列 = 变更后总成；只写新零件（用量 > 0）。没改的零件不要抄 |
| 此件不装 | 原来那个交货总成 | 同一个总成改成 AB | 原来那个总成的名称 | 必须 **一级或二级** | 不装的那一层零件号 | **空**（号不变） | 不装的那一层名称 | 总成列 = 变更后总成；该行用量 0 + 第 23 列含「此件不装」 |

不是完成停止，交货总成一定换新号（一物一码，末两位字母版本进一位，如 AA→AB）。变更后总成 **写在封皮上**，并与材料清单总成列相同。改图是总成里 **已经有的那一颗** 旧零件改成 AB；增加零件是 **另外一颗** 零件加到原来的总成上，变更前零件必须空——不要用「改图、变更前零件空」冒充，那是漏填，整份拒收。

**用量不变。** 工程变更不改用量。改图换号、从变更前总成带走的零件：用量一律抄变更前总成上对应行（材料清单若写出用量，必须与旧行相同，否则拒收；系统写入仍以旧行为准）。此件不装：该行只能写用量 0（见 §1.1）。增加零件：无旧可抄，按文件用量写入（须 > 0）。不要为了改用量去走工程变更。

封皮「项目」「生效年月」可上下合并；系统取合并格的值。日常一份只有一行，合并与否结果相同。青岛 T28 五行对照样表见第 8.1 节，进系统须按行拆开。

不叫「改版」：投产清单上已经有版本字（D/09、D/00）。采购听到「改版」会以为要把 D/09 改成 D/10。图纸改了（多孔、少孔、改料厚），设计部说「改图」；一物一码，零件号才跟着变成 AB。号变是结果，不是原因。

## 1. 口径（先定再看实例）

**有效期针对「一棵对象」，不针对整包头。**

| 对象 | 生失效写在哪 | 头上的版本字（如 D/09） |
|------|----------------|-------------------------|
| 材料清单 | **总成树根**，不针对 snapshot | SOP：第一次标准化投产那份清单 |
| 冲压工艺 | **工艺零件行**，不针对「基地+厂+车型+工艺版本」整包 | SOP：第一次签字工艺确认表 |
| 模具布点 | **布点零件行**，不针对「基地+项目」整包 | SOP：第一次布点清单 |

子孙节点 **不独立改期**：落库每个节点仍抄树根同一套生失效（与现网 `bom_nodes` 四列一致），L0 PATCH 级联子树。采购对象行 **不落** 生失效四列。一条对象行某月在不在，**完全等于**所属树根该月命不命中；改树根时段，对象立刻跟，禁止对象行另写四列、禁止再按整份 snapshot 出本月数。合册不加采购对象表。

一份库里同时有有效行和已失效的旧行。**看项目、算项目，都要带「哪一个月」。** 不同月份会看到不同的树、不同的工艺行和布点行、不同的采购对象。核算该月：树要有效；树上的冲压号还要命中该月有效的工艺行（摊模具则还要命中有效布点行）。

头上 D/09 **只标记 SOP**，不是整包从 SOP 起一直有效，也不是当月选行的键。SOP 导入当时写下的每一行：版本抄 D/09，生效抄 SOP 开始月。之后设变 Excel 新增的 AA/AB 行，版本和生失效写在 **那一行** 上，与包头无关。

日常设变 **只走工程变更 Excel**，不要第二套模板、不要在系统里勾零件当入口：

| 文件 | 谁出 | 系统 |
|------|------|------|
| 供货材料清单 | 本公司设计部 | 同一材料清单解析；**按交货总成对齐**（变的总成停掉旧的、写入新的，没改的总成不动）。材料清单 **只写变化的行**，没变的零件从变更前总成带到变更后总成。某颗零件不装： **用量 0 + 备注含「此件不装」**（§1.1），不另开手工 |
| 冲压工艺确认表 | 有改图的冲压件：该厂/设计出确认表 | 同一工艺确认 Parser；**按零件号对齐**（新号增行并失效同后缀旧号，见 §4.2；表体空则不插也不失效） |
| 模具布点清单 | 要摊模具才填。项目本来就没有布点（如青岛 T28）可以不带这张表 | 同一布点解析；**按零件号对齐**（见第 4.3 节）。**不是硬门禁**：没有「零件汇总」、表体空，都不拒收 |

禁止走现网「整包覆盖」把未出现在文件里的树、工艺行或布点行删掉。

奇瑞不会为这一棵铰链重出整车清单。出材料清单 Excel 的是本公司设计部。工艺确认表同样 Excel 引入；本例 3096 未改图，海众不必出。模具布点能填就填，没有这张表也能过。此件不装仍出材料清单（总成/分总成已改成 AB），工艺确认、模具布点不填零件行。

曾草案「快照头互斥生失效、整表覆盖」不采用。

已否决：同一冲压号截断再插第二段有效期；取价 AB 回退 AA；日历日；用 status 当切点；另做非 Excel 的变更包/库内复制当主路径；为某颗子件不装单开手工勾树入口。  
改图（AA→AB）时把 **旧号工艺/布点行失效到切点前一月** 不是「冲压件再生失效」，见 §4.2。

### 1.1 此件不装也走同一份工程变更 Excel（用量 0 + 备注「此件不装」）

改图、增加零件、此件不装，**同一份工程变更 Excel**。总成/分总成仍 AA→AB 时，设计部在材料清单里写出 **变化的行**（变更后总成、改了图的零件、加在原来总成上的新零件、用量 0 +「此件不装」）；没变的零件不要抄。用量不随改图变：有旧可对的抄变更前总成。采购只上传一次。不要为少一颗胶块、多一颗支架去做第二套界面。

「此件不装」和「完成停止」不是一回事：

| | 完成停止 | 此件不装 |
|--|----------|----------|
| 停的是谁 | **这个交货总成** 从生效年月起不再交货 | **总成还交货**，只是这一颗不装 |
| 怎么写 | 封皮：完成停止；变更前总成=该号；变更后总成空；零件两列空。材料清单不写这个总成 | 封皮：此件不装；变更前总成 / 变更后总成=旧总成→新总成；零件层级一级或二级；变更前零件=不装的号；变更后零件空。材料清单留着该行：用量 0，第 23 列备注含「此件不装」 |

仅不装：封皮就写「此件不装」（T28 后围左胶块）。改图同时还要去掉某颗：封皮仍写「改图」，不装只写在材料清单里，不要第二行封皮（T13J 铰链可以同一份）。

工艺确认、模具布点 **不填零件行**，系统不加冲压零件、不加模具零件。不是「不要 3086AB 这个新总成」。胶块通常没有工艺/布点；它不装，交货总成和所在分总成仍改成 AB。不要在 `3086AA` 上删零件或改用量，不要给胶块单独写失效月。旧月还要看见带着胶块的 AA。

设计部习惯 **留着这一行** 标明此件不装，而不是从文件里抹掉。用量空则当 1，只留行不标的话 AB 总成上胶块还在、还会进核价。因此认这一对信号，两条 **同时** 才不写入新总成。「备注」= 材料清单 **第 23 列**，落到 **该行最深那一层**（有二级归二级，无二级归一级，不是总成格）。必须含「此件不装」四字；不是封皮上的说明。不要写「删除 / 取消 / 作废 / 停用」——那些词和「完成停止」分不清：

| 该行 | 系统 |
|------|------|
| 用量数值 = 0（`0` / `0mm`）**且** 该行最深一层备注含「此件不装」 | **不写入** 新总成。源 Excel 行保留；列表记下这些不装的零件号。这是「不装」闸，不是改用量 |
| 用量 = 0 但备注无「此件不装」 | **整份拒收**（分不清笔误还是不装） |
| 备注有「此件不装」但用量 > 0 或空（空当 1） | **整份拒收**（用量不是 0，仍在装） |
| 文件写出用量与变更前总成对应行不同，且不是上表「0 + 此件不装」 | **整份拒收**（工程变更不改用量；应抄旧用量） |
| 文件里根本没有这行 | **没变的零件**：从变更前总成带到变更后总成，**用量抄旧**。不要当成「必须把原来总成上所有零件再填一遍」。**要标明不装**：必须留行（用量 0 +「此件不装」），抹掉该行等于没说不装、变更前总成上的件还会带来 |

不要：先写入一个用量 0 的零件再靠核价跳过。不要：投产第一次整表就出现 0 +「此件不装」（投产清单不应带不装行）→ 整份拒收。

总成行禁止 0 +「此件不装」（整个总成不再交，用完成停止）。有下级的中间层自身 0 +「此件不装」时，下级必须 **仍出现在文件里且全部同样标记**，否则拒收（上面标明不装、下面的件还会从变更前总成带来）。不装之后变更后总成下若没有任何下级零件 → 拒收。「用量」认 **该层自己的用量列**（二级胶块看二级用量，不是总成用量）。

此件不装写入之后（胶块装在 1137 下；Excel 仍留该行，用量 0、备注含「此件不装」）：

```text
3086AA  用到生效年月的前一月     3096AA / 1137AA / 1133AA / QR36410 / 胶块
3086AB  从生效年月起             3096AA / 1137AB / 1133AA / QR36410
                                ↑ 3096、1133 仍是 AA；胶块未写入；工艺确认、模具布点不填零件
```

要加一个零件：走第 1.2 节，加在 **原来的交货总成** 上，不要写在「此件不装」里，也不要当成另外交一个新总成。

### 1.2 增加零件：加在原来的交货总成上（不是另外交一个新总成）

增加零件和改图不是一回事，也不是新的交货总成：

| | 改图 | 增加零件 |
|--|------|--------|
| 动的是谁 | **总成里已经有的那一颗**，图纸改了，号 AA→AB | **总成里没有的另一颗**，新号加到 **原来那个交货总成** 上 |
| 封皮总成两列 | 旧总成 → 新总成（AA→AB） | 同样：旧总成 → 新总成（AA→AB）。不是把新零件号写成总成 |
| 封皮零件两列 | 旧零件号 → 新零件号（层级=总成则空） | 变更前零件 **空**；变更后零件 = 新加的号 |
| 没改的零件 | 改图那一层改成 AB；没改的仍是原来的号，从旧总成带过来 | 没改的零件号都不变，从旧总成带过来 |
| 工艺 | 有旧号工艺则必须出新号，并停掉旧号（用到生效年月的前一月） | **不停任何旧工艺**。新号按是否冲压件决定要不要出工艺行 |

主场景：交货总成下 **再加一个一级冲压件**（下面没有零件，和现有一级并列）。青岛 T28 不要用流水槽（那个总成已经用来改 875 的图）；加在序号 4「中通道左后纵梁总成」`501007029AA` 上，与 `501007031AA` / `501004437AA` / `501005057AA` 并列。新号 **`501007040AA`**「中通道后纵梁加强板」（系统里没有；**不得**写成 `031AB`，那是改图）。

```text
变更前总成  501007029AA     031AA / 437AA / 057AA
变更后总成  501007029AB     031AA / 437AA / 057AA / 501007040AA
                            ↑ 三个旧一级号不动；只多一颗。040 不是新的交货总成
```

封皮：增加零件 · 变更前总成 `501007029AA` · 变更后总成 `501007029AB` · 总成名称「中通道左后纵梁总成」· 一级 · 变更前零件空 · 变更后零件 `501007040AA` · 零件名称「中通道后纵梁加强板」。  
材料清单只写：`501007029AB` + `501007040AA`（用量 1，内部号 `ACA613002`，备注不要「此件不装」）。031 / 437 / 057 不要抄，导入后从旧总成带过来。对照样表第五行即此例，整行淡绿。

加在二级：零件层级=二级；上面那一层一级若号不变，材料清单写出 **旧一级号** + 新二级（不要把一级改成 AB，那是改图分总成）。新一级若自己带下级：材料清单必须把这一层下面的零件写全，否则新总成上没有下面的零件。

系统认封皮 **变更前总成** 列，不必从材料清单倒推旧总成。变更后总成必须 = 变更前总成末两位 AA 改成 AB，且 = 材料清单总成列。把 `501007040AA` 写进变更后总成 → 整份拒收（当成另外交一个新总成了）。

| 该份 | 系统 |
|------|------|
| 封皮增加零件、总成两列 AA→AB、变更前零件空、变更后零件有、层级一级或二级 | 停掉旧总成、写入新总成，在原来的总成上插入新件 |
| 封皮写改图但变更前零件空 | **整份拒收**（漏填，不是增加零件） |
| 增加零件把变更后总成写成新零件号 | **整份拒收**（不是另外交一个新总成） |
| 变更后零件已经装在变更前总成上 | **整份拒收**（已经在装） |
| 变更后零件去掉末两位后，和旧总成上某一颗相同（031AB vs 031AA） | **整份拒收**（这是改图） |
| 变更后零件用量 0 或备注含「此件不装」 | **整份拒收**（增加零件不是不装） |
| 新件按现网规则会列入冲压件、该月要走零件价，工艺表却没有该号 | **整份拒收** |
| 新件是标准件/胶（核对区），工艺表体空 | 合法，不开冲压零件 |
| 工艺表出现材料清单没有的新号 | **整份拒收** |
| 增加零件材料清单新支上还有下级冲压件要走零件价，工艺表缺号 | **整份拒收** |

工艺：封皮增加零件时，新号当 **全新号**（排在工艺列表后面），**禁止**按末两位 AA/AB 去停旧号。系统里已有这一号（把现成冲压件装到这个总成）→ 跳过、不改、不停。模具布点 **不是硬门禁**：要摊才写；没有「零件汇总」、表体空、系统里本来就没有布点（如 T28），都合法，不拒收。写出新号才插入；不增加零件也不停其它件的模具布点。

采购对象：旧总成没有这一号 → 新行待确认、厂家空，不猜。标准件/胶进核对区。完成停止仍不插。

禁止：为增加零件去投产页插新总成（那是另外交一个新总成，投产页不收新号）。禁止：封皮零件层级=总成写增加零件（总成行不是「加一颗件」）。

## 3. 三方通常怎么操作（最大可能）

核价系统在 **一级总成供应商**（本公司，芜湖对奇瑞交 3086）。奇瑞是顾客。安徽振华是二级分总成。烟台海众是一级直接采购的冲压厂，不是分总成厂。

```text
奇瑞 ──买 3086──► 一级（本公司设计 + 采购/商务）──买 1137──► 二级振华
                                      └──买 3096──► 冲压厂海众
二级振华内部还有 1133 冲压（自制或再外协）
```

### 3.1 奇瑞

发的是 **工程变更**：3086AA 停用、3086AB 启用，附新图、哪一个月切换。子件号会写在变更单或数模结构里，但 **不会** 为这一棵铰链重出整车 T13J《产品材料清单》给一级。

奇瑞商务/采购对的是 **3086AB 的供货价**。他们不管振华内部 1133 怎么改图，除非 1137 也是奇瑞的散件号（本树里 1137 是一级的采购对象，不是奇瑞价目行）。

### 3.2 一级总成供应商 · 设计部（本公司）

收到奇瑞变更后，改自己手头的 **供货材料清单 Excel**（与现网上传的物料清单同一版式：总成 / 一级 / 二级列组）。这是最现实的：设计部本来就有这一本，不会另发明一套变更单表格给采购。

本例：把 3086AA 那一块改成 3086AB（仍挂 3096AA，1137/1133 换成 AB），焊信写在 3086AB 上。文件里 **其它总成可以原样留着**（整本再发一版），也可以只保留变更总成那几行——版式不变。变更总成内部 **没变的子件也不必列**；整棵重抄结果一样，但不要当成必填。表头版本写变更识别（变更单号或他们习惯的字），**不必** 把整本改成 D/10 来假装阶段冻结。

发给采购/商务：材料清单 Excel + 生效年月。若一级工艺库里有冲压件改图，另传 **与日常相同版式的工艺确认表 Excel**（只含新号或整本均可；工程变更写入：新号增行并把旧号用到生效年月的前一月，已有号跳过，**不删行**）。本例 3096 未改图，海众 **不必** 出工艺表。

此件不装：同一份材料清单，总成/分总成已写成 AB；不装的那一行 **用量写 0、备注含「此件不装」**（§1.1）；工艺确认、模具布点不填零件行。不要再走手工勾选。

| 通知谁 | 给什么 | 不给什么 |
|--------|--------|----------|
| 本公司采购/商务 | 材料清单同版式 BOM Excel | 等奇瑞整车新清单 |
| 海众（3096） | **不发**（号与工艺都不变） | 工艺确认表 |
| 振华（1137） | 分总成变更：1137AA→AB，含 1133AB | 一级整车材料清单、3096 图纸 |
| 一级工艺/模具台账（仅当自制冲压改图时） | **工艺确认表 Excel**、**模具布点 Excel**（均为现网列组） | 库内手改当主路径 |

### 3.3 二级分总成供应商（振华）

只认 **1137** 这一支。他们：

- 自己的 BOM：1137AB + 1133AB（+ 螺母）
- 1133 改图：改自己冲压工艺或通知更下一级冲压厂；**不** 给一级重出 3086 整棵树
- 向一级报价/交货的是 **1137AB** 的分总成价（对应本系统年度价/一口价对象），不是 1133 的板料价

一级核价时：1137AB 若仍当外购分总成，走年度价，**不拆** 1133 进一级冲压工艺库（与现网 1133 可无工艺、靠年度价模板一致）。除非变更后改由一级自制 1133，才进芜湖工艺库。

### 3.4 一级采购 / 商务（本系统用户）

对奇瑞出 **3086AB** 的总成价（财务树根卡）。  
对内应成本：3096AA 仍抄原冲压零件价；1137AB 抄年度价（振华）；3086AB 抄本厂焊接费。  
旧月、旧在制、旧发票仍是 3086AA / 1137AA，旧树失效后不再进入新月。

## 4. 管理上怎么管（本系统）

怎么填、怎么叫，看到第 0、1、8 节即可。下面给落地：系统按哪一个月给人看、Excel 怎么写入。这里会出现程序里的词。

### 4.0 查看跟着有效期走

项目下的总成、冲压工艺、模具布点、采购对象 **默认按年+月过滤**，和核价选的月同一套。没选月 = **本月**。不要默认成「这个基地最近一次核价月」。

冲压零件列表、模具清单现网 **不提供**「含已失效」；只靠查看年+月命中。产品结构 / 结构图可开 `include_expired`（默认关）。采购对象落地后与结构树同一开关。失效行要标出生失效，避免当成在产。

| 页 | 该月看见什么 | 不要做成 |
|----|----------------|----------|
| 材料清单结构 / 扁平 | 仅该月有效的树根及其子孙。**排序用 SOP 序号**（见 §4.1）。2026-07 见序号 5 = 3086AA；2026-08 仍是序号 5 = 3086AB | 一份快照把 AA/AB 并排；或按插入先后 / 变更 Excel 行序把 3086AB 甩到表尾 |
| 冲压工艺列表 | 仅该月有效的工艺零件行。3096AA 若 SOP 起一直未失效，两月都在 | 按工艺包版本把 SOP 全表和设变新号混成一包当前件 |
| 模具布点列表 | 仅该月有效的布点零件行 | 基地+项目下列出历史上全部号、不分月 |
| 采购对象 / 总成核价一览 | 只出该月命中树根下的行。生效/失效 **展示树根那两列**（从 L0 读） | 整份 snapshot 计数当本月账；对象行另写一套生失效 |

切换月份是看不同时候的结构，不是换项目、也不是换 snapshot。

### 4.1 清单库：同格式 Excel 进来，按树对齐

芜湖 T13J **仍是一份快照**。头上 D/09 = SOP 那一版清单的版本字，不是整库有效期。采购上传设计部这份材料清单版式 Excel。Parser 与现网整表导入相同。

写入（设变模式，禁止覆盖删库）：

| 封皮 / 文件 | 库里 | 系统做 |
|-------------|------|--------|
| **完成停止**：封皮点名这个交货总成；材料清单不写它 | 该总成仍有效 | **只失效**：填失效到生效年月的前一月（级联子树）。**不种新树**，不插采购对象/拆解，不停工艺/布点。材料清单没有它 **不是** 漏行 |
| **改图 / 增加零件 / 此件不装**：材料清单出现新交货总成号 | 变更前所属旧总成仍有效；新号库里没有 | 旧总成失效到生效年月的前一月（级联子树）；**新增** 整棵。以旧总成为底：文件里的变化行盖上去；**没写的未改零件从旧总成带到新总成，用量抄旧**。改图换号行用量也抄旧（文件用量须与旧行相同）。用量 0 且第 23 列备注含「此件不装」的行 **不插入**（§1.1）。增加零件插入变更后那一颗（及写出的新支），**用量按文件**（无旧可抄）。**材料清单序号继承旧总成投产时的序号**，不采用变更 Excel 的行序。新总成生效=生效年月；失效抄 **项目结束月**（空则空）。节点 `bom_version` 写本文件头/变更字；snapshot 头仍 SOP 字 |
| 未改总成（同号且仍有效） | 有 | **跳过**，不换 `source_node_id`、不重建子孙 |
| 文件没有、库里仍有效 | 其它总成 | **不动**（整本漏行也不许当删除）。唯一例外是上行「完成停止」点名的那一棵 |
| 新交货总成已在库里 | 已有 | **整单拒绝**（不幂等覆盖；改 AC 另传一次） |

本例种完后：

```text
树 551003086AA  项目 T13J  版本 D/09       生效 2026-01  失效 2026-07
    3096AA / 1137AA / 1133AA / QR36410     （旧节点，确认保留；内部号 ACA674 仍在旧树上）

树 551003086AB  项目 T13J  版本 EC-202608（节点变更字）  生效 2026-08  失效 （抄项目结束；空则空）
    3096AA / 1137AB / 1133AB / QR36410     （新节点；3096 仍是 AA；内部号仍可沿用 ACA674）

其它 T13J 总成树  版本 D/09  生效 2026-01  失效 （空）  ← 即使 Excel 里又出现一遍也不重建
snapshot 头仍 D/09。拆解 / 焊接费行的 bom_version 抄头，不抄节点变更字。
```

禁止：把这份 Excel 当成新 `bom_version` 快照整表覆盖（走 SOP 上传会因头版本对不上 D/09 整单拒绝，见 §4.6）。  
禁止：在 3086AA 节点上改零件号/改子件。  
禁止：`BomService.create_node`（现网强制节点版本=头）。合册插入走 `BomNodeWrite`。  
同一零件号两棵树根时段不得重叠（现网更严：同一 snapshot 同一 L0 零件号只能一行，AA/AB 是两个号）。

一份工程变更 Excel **日常只改一个交货总成**。多个总成分多次上传。封皮恰好一行。封皮与材料清单必须对上，否则整份拒收。

先定 **变更前总成**（列表、继承序号、失效对象都认封皮这一列）：

| 变更类型 | 变更前总成 |
|----------|------------|
| 四种都一样 | 封皮「变更前总成」必须仍有效。一级/二级改图、此件不装：变更前零件必须装在这个总成上，且系统里的层级与封皮一致。增加零件：变更前零件空，变更后零件不得已经装在这个总成上。封皮总成与零件所在的总成对不上 → 拒收。青岛 T28 不选 `501007031AA`，就是因为它同时装在两个总成上 |

再定 **变更后总成**（列表、材料清单总成列）：

| 变更类型 | 变更后总成 |
|----------|------------|
| 完成停止 | 封皮空。材料清单不得出现该总成，也不得写成 AB |
| 改图、增加零件、此件不装 | 封皮「变更后总成」= 变更前总成末两位字母版本进一位（`AA`→`AB`，`AB`→`AC`）= 材料清单 **恰好一个** 新总成号。旧总成不含字母版本后缀 → 拒收。新号库里已有 → 拒收。增加零件禁止把新零件号写进这一列 |

封皮零件两列对的是零件层级那一层；总成两列对的是交货总成。不要拿变更后零件去跟材料清单总成列比：

| 校验 | 失败则 |
|------|--------|
| 封皮恰好一行；项目、生效年月与上传页一致（合并格取合并值） | 多行 / 空 / 不一致 |

### 4.3 模具布点：有就写，没有就不挡

**模具布点导入不是硬门禁。** 青岛 T28 投产就没有布点表，工程变更也可以没有「零件汇总」、也可以表体空，**都不拒收、不碰系统里已有的布点**。下载模板仍带这张表，方便要摊模具的项目填；不是每份都必须有。

有效期写在 **布点零件行**（`stamping_die_parts`）：项目号、版本、生效、失效。现网覆盖键是基地+项目整包——设变模式禁止整包替换，也 **不得**调用 SOP `upload_service`（空表体会 `"未解析到零件数据"`）。SOP 第一次导入：每行抄 SOP 版本与开始月。此件不装、完成停止：不填布点零件行 → **不加、不停**。

| 文件 | 系统做 |
|------|--------|
| 没有「零件汇总」这张表 | **跳过**，不拒收 |
| 有表、零件行为空 | **不插、不停**（抽出零行 = 什么也不做，不得走投产空表报错） |
| 有表、写出新号，库里没有 | 先把同厂同项目、末两位字母版本相同且仍有效的旧号失效到生效年月的前一月（有则继承其序号），再增行。封皮是增加零件则 **禁止**按字母版本停旧号，当全新号插入。**`alloc_ratio`：改图换号时从旧号同工序序号抄**（Excel 无此列；与工艺 `cost_ratio` 对称）；无旧工序可对则用现网默认。增加零件 / 无旧布点 → 默认 |
| 有表、写出已有号 | **一律跳过**。不改尺寸/工序/生失效；已手改分摊比例保持。改布点走投产页 |
| 文件没有的旧号 | **不删**。只有文件里出现对应新号时才停旧号 |

有布点且该月有效才可能摊模具费。布点 **不是** 工艺表的自动副本：工艺改图必须出新号（第 4.2 节）；布点要摊才写，不摊就不写，**不要因为没写布点把整份拒收**。

封皮是改图、旧号系统里已有布点，但文件没写出新号 → **不拒收、旧布点不动**（和工艺不同）。接受的后果：新总成已经用 AB，模具布点仍挂在 AA 上，该月可能摊不到 AB（或 AA 仍在布点列表里）。列表可提示「材料清单有换号、布点未跟」；人要摊模具就补传带「零件汇总」的工程变更，或走投产布点页。旧号还装在别的仍有效总成上、文件却要按字母版本停它 → 仍拒收（只在真正写出新号、要停旧号时才查这一条）。

旧号没有布点、文件却写出新号 → 当全新号插入（排在列表后面），该月起可摊模具。T28 对照样表里若写出几行，只是给人看怎么填，不是导入门禁。

检具费另表、同样 Excel：有效期在检具零件行上，按号增行、不删旧号（本期不展开公式）。检具同样不是硬门禁。

### 4.4 采购对象：设变导入后自动带出（跟树根有效期，不另上传）

**目的：导入后不必再点「开始生成」。** 合册 **没有** 采购对象表；种树成功后，**同一事务**按现网分类规则扫新树插行——**含结构化总成下有内部号的 L1 冲压件、分总成、退化供货件**（§2 / §3）。缺对象只能工程变更重传，生成页不提供「只补该月」。

仍是 **一 snapshot 一份清单**，行按 `source_node_id`。对象行 **不加** 生失效四列。命中、计数、检测、确认、审核、删除、核价覆盖 **只用树根 as_of**（与结构树同一月）。列表两列生效/失效从所属 L0 读，与结构树 L0 同值、同 `YYYY-MM`；L0 改期对象立刻跟。禁止对象行另存一套、禁止用清单头整包 `qa_passed` / `l0_count` 当本月账。细则见 [bom-procurement-objects-design.md](../bom/bom-procurement-objects-design.md) §14。

**同交付：** 合册落地须与采购对象 §14.1–14.3（as_of 列表/审核 + 设变插行）**同一波**，否则整 snapshot 列表会 AA/AB 混显。不要用「再点生成」当退路。

现网生成页对整份 snapshot **删头重写**。**合册落地时**才禁止再点「开始生成」（门禁之 2：会撞已审锁定，且按 `source_node_id` 带回 **抄不到** 新树上的同号对象）。落地前现网仍可整包 generate。

材料清单按树对齐成功后，**同一事务**只扫新种的那一棵，往原清单 **插行**（不删头、不碰旧行）：

| 前置 | 系统做 |
|------|--------|
| 该 snapshot **尚无**采购对象清单头 | **先建空清单头**（范围抄 snapshot；不跑整包 generate），再插行 |
| 已有清单头 | 直接往该头下插行 |

| 新树上的节点 | 系统做 |
|--------------|--------|
| 列入采购对象，且被替换旧树上有同行（同 `part_number` + `section` + `object_kind`，本例 3096AA） | **插新行**（新 `source_node_id`，`l0_*` / 父件 / Excel 行号抄新节点）。确认三态、确认人时、确认备注、`supplier_name` **从那棵旧树抄**。**不抄** `audit_status`（新行待审） |
| 列入采购对象，旧树无同号，但能对上旧树 **字母版本换号**（去掉末两位后相同、末两位字母版本进一位），且旧树有旧号同行、`object_kind` 不变（本例 1137AB←1137AA；T28 `875AB`←`875AA`；**此件不装**时祖先分总成 AA→AB 同样适用） | **插新行**；确认三态 / 确认人时 / 确认备注 / `supplier_name` **从旧树旧号同行抄**。**不抄** `audit_status`。认的是树上号关系，**不看**封皮变更类型是改图还是此件不装。禁止从钢厂列 / 备注 / 年度价猜 |
| 列入采购对象，旧树无同行且无上表字母版本可对（增加零件的新一级；`object_kind` 变了） | **插新行**，`confirm_status=pending`，`supplier_name` 空 |
| 核对区（QR36410 标准件/胶等、异常；T28 左胶块 `504000341AA` 有内部号但仍是胶，进核对区） | **插新行**；无确认可抄。用量 0 + 备注「此件不装」未插入的叶子 **不插**（7 月核对区没有左胶块，右胶块从旧树带来则插新行） |
| 完成停止（不种新树） | **不插**。7 月 as_of 打不到这棵旧树 |
| 旧树已有行 | **不动**，已审保持已审 |

匹配只认 **被替换的那一棵旧树**，禁止扫 snapshot 里其它总成的同号。`object_kind` 变了当新号，不抄确认。抄来的 `supplier_name` 不跑 `require_enabled`；全称已不在供应商表则落空，不让整单失败。

7.1–7.3、HUD、确认/审核门禁：对该月 **命中树根** 的节点与对象行做，不做全林。本例 8 月只对 3086AB + 仍有效的其它树；7 月只对 3086AA + 当时有效的树。已审锁定只约束被打到的那批行；增量不要求先反审整项目。不写一条冒充整单覆盖的生成日志；带出件数记在工程变更列表。

8 月打开即见 3096AA（新节点、确认已带、待审，生失效 = 3086AB）和 1137AB（确认/厂家已从 1137AA 带，待审），**不必再点生成**。7 月仍是 1137AA（生失效 = 3086AA）。一点「审核」不得打到未命中的树。改图后厂家未变则人只审一遍；厂家真变了再走行上改。

SOP 页单条 PATCH 纠错请在种树前做；种树后改期走结构页 L0，不要再点采购对象 / 拆解生成。

### 4.4.1 焊接拆解：只拆新树（对标采购对象 §14.2）

现网 `POST /generate` 按 `location+vehicle+bom_version` 扫 **整份 snapshot**：有已审就 409，无已审就删未审再全林重走。合册 **不得**调用这条。

**与采购对象同一事务、同一目的：导入后不必再点拆解「开始生成」。** 只扫新种那一棵有 `weld_info` 的节点 **插行**（不删旧树拆解、不碰已审）。焊信仍在材料清单节点上；合册按现网 Parser 从新节点焊信拆出工序行。完成停止不种新树 → **不插拆解**。拆解 / 焊接费行的 `bom_version` **抄 snapshot 头 D/09**，不要抄节点变更字（现网 UNIQUE 含 `bom_version`；引擎 `discover_l0_scopes` 分组键是头版本）。`source_node_id` 指向新节点。

**合册落地时**（门禁之 2）：该 snapshot 一旦有已失效树根、**或** 存在生效月不是项目 SOP 开始月的树根，拆解生成页「开始生成」拒绝（即使没有已审）。与采购对象 §14.2 同一把钥匙。缺拆解走工程变更重传，生成页不提供「只补该树」。落地前现网仍可整包 generate。

**合册落地时**（门禁之 3）：引擎 `annual_welding_breakdown` 该年年交集已齐则跳过；缺新树拆解 **不得**调现网整包 generate（会 409 或误扫已失效树）。只能走合册重传。落地前引擎缺拆解仍调 generate。

拆解细则见 [welding-process-breakdown-design.md](../bom/welding-process-breakdown-design.md)。

### 4.5 价表与核算

**合册不抄年度价 / 包装价。** 改图不等于改价：加工费比例、模具分摊比例、采购确认关系已在 §4.2–4.4 自动带；价表仍等人补报价后导入。

年度价：1137AB 一行（振华）；必要时 1133AB。包装：3086AB 若走 I1/I2。3096 号没变，不必出布点/检具 Excel。此件不装若分总成也改了图才导 1137AB；只交货总成改图、分总成号未动则年度价不换行。不装的零件不进该月核价。

2026-07：有效树含 3086AA（序号 5），抄 3096AA、1137AA。  
2026-08：有效树含 3086AB（仍序号 5），仍抄 3096AA，改抄 1137AB。

财务对奇瑞：3086AB 树根 `grand_total`。采购协议：3096AA + 1137AB。分析跨月口径 **loose**。

引擎：该月只收有效树根（按 SOP `seq_no` 序）；叶子冲压价抄该月有效工艺行。总成卡抄树根项目号、**节点**版本字（给人看）；发现范围仍按 snapshot 头版本，不要为铰链新建 D/10。完成停止不停工艺行：零件价月账仍可能算到旧总成下的冲压号（T28 的 `501009532AA`）；总成核价不收已失效的树，两本账不要当成打架。

### 4.6 对着现网写死：让步什么、落地时只改哪三条门禁

**设计让步给现网。** Parser、UNIQUE、引擎发现键、`create_node`、SOP 空表硬停、一物一码只看本文件、未选月=墙钟月、子孙落库四列：**都不改**。合册绕开 SOP 三条写入链，不要去「修」它们。

合册怎么喂现网 Parser（抽表，不改 Parser）：

| 现网保持 | 合册怎么绕 |
|----------|------------|
| BOM Parser 只读第一张表 | 按表名抽出 `车身件材料清单` 再交给 Parser |
| 工艺 Parser 自动找「零件号+工序」或退回第一张 | 按表名抽出 `冲压工艺确认表` |
| 布点 `find_sheet` 扫到「零件号」就用 | 有「零件汇总」才按表名抽出。材料清单表头也有「零件号」，**禁止**对整本文件调用 `parse_die_layout_excel`。没有这张表 = 跳过，不拒收 |
| 布点 SOP 用文件名认项目 | 工程变更文件名不是布点清单名。项目以封皮/上传页为准 |
| `BomUploadService` 用 Excel 头版本对 snapshot | 合册不走这条。按基地+项目找 **唯一** SOP 头，头仍 D/09 |
| `create_node` 强制节点版本=头 | 合册不走它，走 `BomNodeWrite` |
| 布点 SOP 空表体硬停 | 没有「零件汇总」、或抽出后零行 = 跳过，不调用 `die/upload_service`，不拒收 |
| 工艺 SOP 拒新号 | 合册自己按号增行；已有号跳过 |
| 一物一码只看本文件 | 保持。允许 AB 沿用 AA 的内部号 |
| 引擎 `L0Scope` / 拆解 UNIQUE 用 snapshot 头 | 拆解与焊接费行 `bom_version` 抄头，不抄节点变更字 |
| 宪法同步 Excel 封闭名单 | 合册是长任务（`task_id`），不进该名单 |

**合册落地时才改现网的三条门禁**（整包写入会掐断新树；不改 Parser / UNIQUE）。**启用时序：** 合册写入能力与三条门禁 **同一发版打开**；不要只合入半套跳过逻辑。运行时按表中 **判定谓词** 生效——**完成停止**只失效旧树、不种新树，也会出现「已失效树根」，门禁 2 同样挡住整包生成。

| 门禁 | 改哪个入口 | 判定 | 对人提示 |
|------|------------|------|----------|
| 1 | `BomUploadService` 再导对齐树（`_align_existing_trees` 一类） | 只更新：树根仍有效 **且** 生效月 = 项目 SOP 开始月。已失效、或生效月是合册切点的整棵 **跳过**（文件里即使写出也不重建） | 投产页仍可上传纠错；合册种的总成不会被 SOP 再导掐掉 |
| 2 | 采购对象「开始生成」、焊接拆解「开始生成」 | 该 snapshot 存在已失效树根，**或** 存在生效月 ≠ 项目 SOP 开始月的树根 → `BusinessException` `code=409` | 「设变后请走工程变更重传，勿整包生成」 |
| 3 | 引擎 `annual_welding_breakdown`（`runners` 调 `breakdown_svc.generate` 处） | 年交集已齐 → 跳过；缺新树拆解 → **禁止**调现网整包 `generate`，本阶段失败并记原因 | 提示缺拆解须工程变更重传，不要自动整包生成 |

门禁之 2 与 [采购对象 §14.2](../bom/bom-procurement-objects-design.md)、拆解设计同文案。

写入顺序（一次事务，失败全滚）：

```text
封皮 + 材料清单校验（§0 / §4.1：恰好一行；变更前总成仍有效；
            改图/增加零件/此件不装：变更后总成=变更前总成字母版本+1=材料清单恰好一个新总成，且新号不存在；
            零件两列符合 §0；一级/二级改图、增加零件要求路径写到那一层；此件不装双信号；完成停止不写该总成；
            生效年月=上传页、晚于旧总成生效、项目在生效年月可引入；
            改图：材料清单里换号且旧号有仍有效工艺 → 工艺表必须有对应新号；
            工艺表不得出现材料清单没有的新号；旧号仍挂其它有效树则拒；
            增加零件禁止字母版本失效旧工艺，禁止把新零件号写成变更后总成；
            有旧可对的零件：文件用量须等于变更前总成对应行（此件不装写 0 除外）；
            布点缺表/空表不拒收）
  → 按表名抽业务表（缺封皮 / 材料清单 / 工艺确认表整单失败；
            缺「零件汇总」不失败。工艺零行 = 不改工艺；布点缺表或零行 = 不改布点）
  → 完成停止：只失效旧交货总成（级联子树），不种新树、不插对象/拆解
     改图 / 增加零件 / 此件不装：失效旧交货总成 + 种新树
            （继承 seq_no；带走/换号用量抄旧；用量0且备注「此件不装」不插入；
            增加零件插入新件按文件用量；本文件一物一码）
  → 有新树：本树采购对象插行、本树焊接拆解插行（不走 generate；bom_version 抄头）
  → 工艺表按号增行（仅改图才按字母版本失效旧号；增加零件走全新号；
            改图换号 `cost_ratio` 从旧号同工序抄）
  → 布点：有零件行才按号增行（改图换号 `alloc_ratio` 从旧号同工序抄）；
            没有这张表或表体空则跳过，不挡整份
```

三库都禁止整包删。任一步失败全部回滚。AB→AC 同一套：被替换的是 AB，抄确认从 AB 树来，`seq_no` 仍是 SOP 槽。

## 5. 作业顺序（生效年月 = 2026-08）

改图、增加零件、此件不装都是这六步。增加零件时材料清单只写新总成 + 新件；工艺确认有冲压件才填新号（不失效旧号）。此件不装时材料清单里该行用量 0、备注含「此件不装」；工艺确认、模具布点不填零件行。

1. 奇瑞变更单到位；本公司设计部按工程变更模板填好发给采购  
2. 采购在 **工程变更** 页上传该 Excel，生效年月 2026-08：3086AA 用到 7 月，写入 3086AB（**材料清单序号仍是投产时的 5**）；**自动带出** 这个总成的采购对象与焊接拆解。本例工艺确认、模具布点不填零件。  
3. 海众：不必另出工艺确认或布点（3096 未改图）  
4. 若有冲压件改图或增加零件：填在同一份 Excel 的「冲压工艺确认表」。要摊模具才填「零件汇总」；T28 这类本来没有布点的项目可以不填、也可以没有这张表。增加零件不停旧工艺。不要再走投产那三页覆盖上传  
5. 通知振华：1137AB 报价 → 年度价导入 1137AB（及必要时 1133AB）；3086AB 包装若需要则补  
6. 跑 2026-08 引擎  

7 月及以前重算仍走 3086AA。不要把旧月改成 AB。

## 6. 一份工程变更 Excel（不要拆成三次上传）

日常设变只走 **工程变更** 页（§8）。下载的模板里一次性包含材料清单、冲压工艺确认、模具布点。增加零件、此件不装也用这份，不要手工勾选。第一次投产仍走日常三页分别上传；那三页页顶写明「只导入投产，投产后改图必须走工程变更」，见 [有效期 §7.1](bom-process-die-effective-period-design.md)。

| 文件 | 第一次投产 | 日常设变 |
|------|------------|----------|
| 材料清单 | 整表导入，多个总成 | **同一套列**，按交货总成对齐；变更后总成写本文件版本与生效年月 |
| 冲压工艺确认表 | 每行抄投产版本与开始月 | 改图：新号增行、旧号用到生效年月的前一月；增加零件：全新号增行、**不**失效旧号；已有号跳过；不填零件行则不加也不停 |
| 模具布点（表名「零件汇总」） | 同上，写在布点零件行 | 要摊才写。不填零件行、没有这张表，工程变更都 **不拒收**（不要走投产上传，空表会报错） |

生效年月写在 **封皮**（及上传页，须一致）。一份文件进系统后，只落到 **这一个** 交货总成：完成停止只失效旧总成；改图 / 增加零件 / 此件不装种新总成，并按表体增工艺行 / 布点行。用量 0 且第 23 列备注含「此件不装」的材料清单行不写入新总成（§1.1）。没改的行保持投产当时写下的生失效。

**不要拆成三次上传** = 不要把材料清单、工艺确认、模具布点拆成三个文件、三次点。**要拆的是多个交货总成**：日常一份一行封皮。青岛 T28 对照样表把五行订在一本，是给人对照填法，整本上传会因多个新总成拒收，须按封皮行拆开（第 8.1 节）。不要把工程变更文件丢进投产那三页。

## 7. 现网 vs 本文

| | 现网（保持） | 本文（合册） |
|---|------|------|
| Parser / UNIQUE / 引擎发现键 | 不动 | 合册抽表绕开；拆解抄头版本 |
| 有效期列 | 树根 / 工艺行 / 布点行已有 | 合册 expire+insert 种树；包头 D/09 只表示 SOP |
| 核价 as_of | 零件价 / 总成 / 引擎月命中；费年交集 | 沿用；不另开取价回退 |
| SOP 三页 | 按对象对齐、拒新号、空表硬停 | **不走这三页** |
| 未改总成 | SOP 再导仍重建文件里出现的有效树子孙 | 合册里再出现一遍不重建。**落地时** SOP 再导跳过合册种的树（§4.6 三条门禁之 1） |
| 序号 | SOP 再导冻结 `seq_no` | AB 占 AA 的槽；封皮不填序号，系统按 **变更前总成** 带出（不是封皮上的一级/二级零件号） |
| 采购对象 / 拆解 generate | 整 snapshot 覆盖 | 合册插行。**落地时** 生成页拒绝整包（门禁之 2）；引擎不得调 generate（门禁之 3） |

## 8. 产品：工程变更上传与列表

单独做，不塞进材料清单上传页、工艺上传页、布点上传页。那三页只做投产导入，页顶文案见 [有效期 §7.1](bom-process-die-effective-period-design.md)。侧栏与 **冲压工程、焊接工程同级**，一级分组 **工程变更**（上传 / 列表，见 §8.6）。不要再开第二颗「此件不装」或「增加零件」按钮。

### 8.1 上传

表单字段（全部必填）：

| 字段 | 规则 |
|------|------|
| 基地 | 下拉已启用基地 |
| 顾客 | 下拉；须与该基地+项目 **唯一投产清单头** 上的顾客一致，否则整份拒收。只作校验，不写入 BOM 节点 |
| 项目 | 在 **生效年月** 可引入（不是看本月） |
| 生效年 + 月 | 与封皮「生效年月」必须一致（封皮写「2025年07月」↔ 页选 2025 / 7） |
| 文件 | `.xlsx`；日常封皮恰好一行、一个交货总成 |

变更后交货总成已存在则拒收。上传走后台任务（§8.5），不要做成同步卡死。

同基地+项目允许排队多个任务；**同一变更后总成** 已被成功写入或进行中的任务占用 → 后到的拒收（409）。失败任务不占号，可改文件重传。成功后源文件可经文件溯源再下（若本次登记了 `upload_files`）；列表不提供「把历史变更再导成一本 Excel」。

#### 8.1.1 模板下载

| 项 | 约定 |
|----|------|
| 方法 | `GET /api/engineering-change/template` → `StreamingResponse`（无 `ApiResponse`） |
| 权限 | `Perm.ENGINEERING_CHANGE_UPLOAD_UPLOAD` |

工作表与样表填法：

| 工作表 | 对齐日常模板 | 本例怎么填 |
|--------|----------------|------------|
| `封皮` | 工程变更专用。十列：项目、生效年月、变更类型、变更前总成、变更后总成、总成名称、零件层级、变更前零件、变更后零件、零件名称 | T13J：改图 · `551003086AA` → `551003086AB` · 总成名称「右前门上铰链加强板总成」· 总成 · 零件两列与零件名称空。一级/二级改图、增加零件、此件不装见 T28。材料清单序号系统按变更前总成带出（本例 5），人不用填 |

## 9. 拒收原因（稳定文案常量）

落地用 `BusinessException(message=..., code=400|409)`；常量名放合册包（类似 `SOP_NEW_NUMBER_REJECT`），**不要**另发明数字业务码表。对人只展示 `message`。

| 常量名（建议） | HTTP | 对人 message（要旨） |
|----------------|------|----------------------|
| `EC_COVER_ROW_COUNT` | 400 | 封皮必须恰好一行 |
| `EC_COVER_TYPE_INVALID` | 400 | 变更类型只准四句 |
| `EC_COVER_COLUMNS` | 400 | 封皮十列填法不符合该变更类型 |
| `EC_EFFECTIVE_MISMATCH` | 400 | 生效年月与上传页不一致 |
| `EC_PROJECT_MISMATCH` | 400 | 封皮项目与上传页 / 投产清单不一致 |
| `EC_CUSTOMER_MISMATCH` | 400 | 顾客与投产清单头不一致 |
| `EC_BEFORE_ASSEMBLY_INVALID` | 400 | 变更前总成无效或不存在/已失效 |
| `EC_AFTER_ASSEMBLY_EXISTS` | 409 | 变更后总成已存在 |
| `EC_AFTER_ASSEMBLY_BUSY` | 409 | 同一变更后总成正在导入 |
| `EC_SEQ_MISMATCH` | 400 | 材料清单序号与投产序号不符 |
| `EC_BOM_NEW_ROOT` | 400 | 材料清单新总成数量或号与封皮不符 |
| `EC_QTY_CHANGED` | 400 | 用量与变更前总成不一致（工程变更不改用量） |
| `EC_NOT_INSTALL_SIGNAL` | 400 | 此件不装必须用量 0 且备注含「此件不装」 |
| `EC_ADD_VS_REVISE` | 400 | 改图变更前零件空，或增加零件把新号写成总成 |
| `EC_PROCESS_MISSING_NEW` | 400 | 材料清单换号/新加且旧号有工艺，工艺表缺对应新号 |
| `EC_PROCESS_EXTRA_NEW` | 400 | 工艺表出现材料清单没有的新号 |
| `EC_PROCESS_SHARED_OLD` | 400 | 旧号仍挂其它有效总成，不能按改图停掉 |
| `EC_SHEET_REQUIRED` | 400 | 缺封皮 / 车身件材料清单 / 冲压工艺确认表 |
| `EC_EFFECTIVE_TOO_EARLY` | 400 | 生效年月必须晚于旧总成生效月 |
| `EC_GATE_FULL_GENERATE` | 409 | 设变后请走工程变更重传，勿整包生成（门禁 2） |
| `EC_GATE_ENGINE_BREAKDOWN` | 409 | 缺新树拆解，请工程变更重传（门禁 3） |

上表未列尽的校验，仍用一句人话 `message`，风格与上表一致。
