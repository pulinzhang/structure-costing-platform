## 1. 口径（先定再看实例）

**有效期针对「一棵对象」，不针对整包头。**

| 对象 | 生失效写在哪 | 头上的版本字（如 D/09） |
|------|----------------|-------------------------|
| 材料清单 | **总成树根**，不针对 snapshot | SOP：第一次标准化投产那份清单 |
| 冲压工艺 | **工艺零件行**，不针对「基地+厂+车型+工艺版本」整包 | SOP：第一次签字工艺确认表 |
| 模具布点 | **布点零件行**，不针对「基地+项目」整包 | SOP：第一次布点清单 |

子孙节点、采购对象行 **都不写生失效**。一条对象行某月在不在，**完全等于**所属树根该月命不命中；改树根时段，对象立刻跟，禁止对象行另写四列、禁止再按整份 snapshot 出本月数。合册不加采购对象表。

一份库里同时有有效行和已失效的旧行。**看项目、算项目，都要带「哪一个月」。** 不同月份会看到不同的树、不同的工艺行和布点行、不同的采购对象。核算该月：树要有效；树上的冲压号还要命中该月有效的工艺行（摊模具则还要命中有效布点行）。

头上 D/09 **只标记 SOP**，不是整包从 SOP 起一直有效，也不是当月选行的键。SOP 导入当时写下的每一行：版本抄 D/09，生效抄 SOP 开始月。之后设变 Excel 新增的 AA/AB 行，版本和生失效写在 **那一行** 上，与包头无关。

日常设变 **一律合册**，不要第二套模板、不要库内勾树当入口：

| 文件 | 谁出 | 系统 |
|------|------|------|
| 供货材料清单 | 本公司设计部 | 同一材料清单 Parser；**按树对齐**（变的树失效+新增，未改树不换节点）。少零件用 **用量 0 + 备注含「去除」**（§1.1），不另开手工 |
| 冲压工艺确认表 | 有换号的冲压件：该厂/设计出确认表 | 同一工艺确认 Parser；**按零件号对齐**（新号增行，文件里没有的旧号 **不删**） |
| 模具布点清单 | 有换号且要进一级模具台账的冲压件 | 同一布点 Parser；**按零件号对齐**（新号增行，文件里没有的旧号 **不删**） |

禁止走现网「整包覆盖」把未出现在文件里的树、工艺行或布点行删掉。

奇瑞不会为这一棵铰链重出整车清单。出材料清单 Excel 的是本公司设计部。工艺确认表、布点清单同样 Excel 引入；本例 3096 未换号，海众不必出这两份。少胶块仍出材料清单（总成/分总成已升 AB），工艺/布点表体空。

曾草案「快照头互斥生失效、整表覆盖」不采用。

已否决：冲压件再生失效；取价 AB 回退 AA；日历日；用 status 当切点；另做非 Excel 的变更包/库内复制当主路径；为少零件单开手工勾树入口。

### 1.1 少零件也走合册（用量 0 + 备注「去除」）

换号、改图、少胶块、加叶子、只改用量，**同一份合册**。总成/分总成仍 AA→AB 时，设计部在材料清单里写出新树；采购只上传一次。不要为少一颗胶块去做第二套界面。

「别开零件」= 工艺确认、模具布点 **表体空**，合册不插 `stamping_parts` / `stamping_die_parts`。不是「不要 3086AB 这棵新树」。胶块通常是核对区叶子，没有工艺/布点；但它一少，交货总成和所在分总成仍升版。有效期针对整棵树根：禁止在 `3086AA` 上删子件或改用量，禁止给胶块单独写失效月。旧月还要看见带着胶块的 AA。

设计部习惯 **留着 Excel 行** 标取消，而不是从文件里抹掉。现网 Parser 用量空则当 1，只留行不标的话 AB 树上胶块还在、还会进核价。合册因此认这一对信号，两条 **同时** 才剔除：

| 该行 | 系统 |
|------|------|
| 用量数值 = 0（`0` / `0mm`）**且** 备注含「去除」二字 | **不插入** 新树节点。源 Excel 行保留溯源；变更列表记剔除零件号 |
| 用量 = 0 但备注无「去除」 | **整单拒绝**（分不清笔误还是减件） |
| 备注有「去除」但用量 > 0 或空（空现网当 1） | **整单拒绝**（还在用，不是去除） |
| 用量改小但仍 > 0，备注无「去除」 | 当普通用量变更，**照种** 该节点 |
| 文件里根本没有这行 | 新树本来就没有（与现网「按文件种树」相同）；能标「去除」时仍建议留行 |

不要：把「删除 / 取消 / 作废 / 停用」当「去除」的同义词。不要：种一颗用量 0 的活节点再靠核价跳过——结构树、采购对象、焊接拆解、引擎任一处漏滤就会把胶块算进去。不要：SOP 第一次整表出现 0 +「去除」（投产清单不应带剔除行）→ 整单拒绝。

闸：L0 禁止 0 +「去除」。有子件的中间节点自身 0 +「去除」时，子孙必须全部同样标记，否则拒绝（禁止半棵幽灵树）。剔除之后新 L0 下若没有任何结构化子件 → 拒绝（不要静默变成退化供货件）。

少胶块种完（胶块挂在 1137 下；Excel 仍留该行，用量 0、备注含去除）：

```text
树 3086AA  失效到切点前一月     3096AA / 1137AA / 1133AA / QR36410 / 胶块
树 3086AB  切点月起             3096AA / 1137AB / 1133AA / QR36410
                                ↑ 3096、1133 仍是 AA；胶块未插入；工艺/布点表体空
```

加叶子：新行用量 > 0、备注不要写「去除」，合册照种。不另开加件入口。

## 2. 现网这棵树（变更前）

范围：**芜湖 / 奇瑞公司 / T13J / D/09**。名称「右前门上铰链加强板总成」。采购协议实例与分类测试用的就是它。

口中短码对现网全码：

| 人说的 | 现网零件号 | 现网角色 |
|--------|------------|----------|
| 总成 3096 | 树上一级是 `551003096AA`；**对奇瑞交货的树根是 `551003086AA`** | 3096 = 一级冲压件「右前门上铰链加强板」（烟台海众）。3086 = 供货总成 |
| 分总成 1137 | `551001137AA` | 一级分总成「左后门上铰链安装板总成」（安徽振华） |
| 冲压 1133 | `551001133AA` | 挂在 1137 下的二级冲压件「左后门上铰链安装板」。现网常 **不在一级工艺库**，走年度价 |

```text
L0  551003086AA  右前门上铰链加强板总成     内部号 ACA674
    ├─ L1  551003096AA  右前门上铰链加强板           冲压对象 · 烟台海众
    └─ L1  551001137AA  左后门上铰链安装板总成       分总成对象 · 安徽振华
           ├─ L2  551001133AA  左后门上铰链安装板     振华侧冲压（一级工艺库可无）
           └─ L2  QR36410      焊接方螺母             标准件，不进合同包
```

下列是 **换号实例**（合册）。少胶块仍走合册，见 §1.1。本次：**3096 不变**。换号的是分总成支路，树根对奇瑞交货号跟着变：

```text
3086AA → 3086AB     供货总成（奇瑞买的）
3096AA  不动        一级冲压（海众，新树仍挂这个号）
1137AA → 1137AB     分总成
1133AA → 1133AB     分总成下的冲压
QR36410 不动
```

未改的其它 T13J 总成树仍在同一快照里，节点不动。

## 3. 三方通常怎么操作（最大可能）

核价系统在 **一级总成供应商**（本公司，芜湖对奇瑞交 3086）。奇瑞是顾客。安徽振华是二级分总成。烟台海众是一级直接采购的冲压厂，不是分总成厂。

```text
奇瑞 ──买 3086──► 一级（本公司设计 + 采购/商务）──买 1137──► 二级振华
                                      └──买 3096──► 冲压厂海众
二级振华内部还有 1133 冲压（自制或再外协）
```

### 3.1 奇瑞

发的是 **工程变更**：3086AA 停用、3086AB 启用，附新图、切点（按月，到供应商就是某月切换）。子件号会写在变更单或数模结构里，但 **不会** 为这一棵铰链重出整车 T13J《产品材料清单》给一级。

奇瑞商务/采购对的是 **3086AB 的供货价**。他们不管振华内部 1133 怎么换号，除非 1137 也是奇瑞的散件号（本树里 1137 是一级的采购对象，不是奇瑞价目行）。

### 3.2 一级总成供应商 · 设计部（本公司）

收到奇瑞变更后，改自己手头的 **供货材料清单 Excel**（与现网上传的物料清单同一版式：总成 / 一级 / 二级列组）。这是最现实的：设计部本来就有这一本，不会另发明一套变更单表格给采购。

本例：把 3086AA 那一块改成 3086AB（仍挂 3096AA，1137/1133 换成 AB），焊信写在 3086AB 上。文件里 **其它总成可以原样留着**（整本再发一版），也可以只保留变更总成那几行——版式不变。表头版本写变更识别（变更单号或他们习惯的字），**不必** 把整本改成 D/10 来假装阶段冻结。

发给采购/商务：材料清单 Excel + 切点月。若一级工艺库里有冲压件换号，另传 **现网同版式的工艺确认表 Excel**（只含新号或整本均可，写入不删旧号）。本例 3096 未换号，海众 **不必** 出工艺表。

少胶块：同一份材料清单，总成/分总成已写成 AB；被拿掉的叶子 **用量写 0、备注含「去除」**（§1.1）；工艺/布点表体空。不要再走手工勾树。

| 通知谁 | 给什么 | 不给什么 |
|--------|--------|----------|
| 本公司采购/商务 | 材料清单同版式 BOM Excel | 等奇瑞整车新清单 |
| 海众（3096） | **不发**（号与工艺都不变） | 工艺确认表 |
| 振华（1137） | 分总成变更：1137AA→AB，含 1133AB | 一级整车材料清单、3096 图纸 |
| 一级工艺/模具台账（仅当自制冲压换号时） | **工艺确认表 Excel**、**模具布点 Excel**（均为现网列组） | 库内手改当主路径 |

### 3.3 二级分总成供应商（振华）

只认 **1137** 这一支。他们：

- 自己的 BOM：1137AB + 1133AB（+ 螺母）
- 1133 换号：改自己冲压工艺或通知更下一级冲压厂；**不** 给一级重出 3086 整棵树
- 向一级报价/交货的是 **1137AB** 的分总成价（对应本系统年度价/一口价对象），不是 1133 的板料价

一级核价时：1137AB 若仍当外购分总成，走年度价，**不拆** 1133 进一级冲压工艺库（与现网 1133 可无工艺、靠年度价模板一致）。除非变更后改由一级自制 1133，才进芜湖工艺库。

### 3.4 一级采购 / 商务（本系统用户）

对奇瑞出 **3086AB** 的总成价（财务树根卡）。  
对内应成本：3096AA 仍抄原冲压零件价；1137AB 抄年度价（振华）；3086AB 抄本厂焊接费。  
旧月、旧在制、旧发票仍是 3086AA / 1137AA，旧树失效后不再进入新月。

## 4. 管理上怎么管（本系统）

### 4.0 查看跟着有效期走

项目下的树、冲压工艺、模具布点、采购对象 **默认按年+月过滤**，与核价月同一根轴。未选月则用墙钟月（或该基地最近一次核价月，产品定一处，四页一致）。

| 页 | 该月看见什么 | 不要做成 |
|----|----------------|----------|
| 材料清单结构 / 扁平 | 仅该月有效的树根及其子孙。**排序用 SOP 序号**（见 §4.1）。2026-07 见序号 5 = 3086AA；2026-08 仍是序号 5 = 3086AB | 一份快照把 AA/AB 并排；或按插入先后 / 变更 Excel 行序把 3086AB 甩到表尾 |
| 冲压工艺列表 | 仅该月有效的工艺零件行。3096AA 若 SOP 起一直未失效，两月都在 | 按工艺包版本把 SOP 全表和设变新号混成一包当前件 |
| 模具布点列表 | 仅该月有效的布点零件行 | 基地+项目下列出历史上全部号、不分月 |
| 采购对象 / 总成核价一览 | 只出该月命中树根下的行。生效/失效 **展示树根那两列**（从 L0 读） | 整份 snapshot 计数当本月账；对象行另写一套生失效 |

允许单独开关「含已失效」做档案核对，默认关。失效行要标出生失效，避免当成在产。

切换月份是看不同时候的结构，不是换项目、也不是换 snapshot。

### 4.1 清单库：同格式 Excel 进来，按树对齐

芜湖 T13J **仍是一份快照**。头上 D/09 = SOP 那一版清单的版本字，不是整库有效期。采购上传设计部这份材料清单版式 Excel。Parser 与现网整表导入相同。

写入（设变模式，禁止覆盖删库）：

| 文件里的树根 | 库里当前有效树 | 系统做 |
|--------------|----------------|--------|
| 3086AB（新号） | 有 3086AA 有效 | 3086AA 填失效；**新增** 3086AB 整棵（新节点）。用量 0 且备注含「去除」的行 **不插入**（§1.1）。**`seq_no` 继承 3086AA 的 SOP 序号**，不采用变更 Excel 的行序 |
| 3096AA 等未改总成 | 同号且仍有效 | **跳过**，不换 `source_node_id` |
| 文件没有、库里仍有效 | 其它总成 | 不动（整本漏行也不许当删除） |

本例种完后：

```text
树 551003086AA  项目 T13J  版本 D/09       生效 2026-01  失效 2026-07
    3096AA / 1137AA / 1133AA / QR36410     （旧节点，确认保留）

树 551003086AB  项目 T13J  版本 （Excel 头版本/变更字） 生效 2026-08  失效 （空）
    3096AA / 1137AB / 1133AB / QR36410     （新节点；3096 仍是 AA）

其它 T13J 总成树  版本 D/09  生效 2026-01  失效 （空）  ← 即使 Excel 里又出现一遍也不重建
```

禁止：把这份 Excel 当成新 `bom_version` 快照整表覆盖。  
禁止：在 3086AA 节点上改零件号/改子件。  
同一零件号两棵树根时段不得重叠。

子孙不写生失效，跟树根。未改总成即使出现在新 Excel 里，也不要给它们新生效月。

**序号 = SOP 第一次整表时的序号，设变不改槽位。** 树根 `seq_no` 在 SOP 导入时写入（本例铰链为 5）。3086AB 占用同一序号 5。列表/树/合册按 `seq_no` 排，该月有效树各占各的槽，不会出现「新树排在最后、中间一个洞」。变更 Excel 里的行号只作文溯源（`excel_row`），不作展示序。工艺列表、布点列表同样：SOP 导入顺序当槽；新号若替换旧号则继承该零件在 SOP 表里的位置，不要追加到表尾。

「含已失效」时同一序号可能有多棵（不同时段），先 `seq_no` 再按生效月，并标出生失效。按月过滤时每个序号至多一棵有效树。

### 4.2 冲压库：工艺确认表 Excel，按零件号对齐（策略同树）

与材料清单同一纪律：**Excel 引入**，现网工艺确认表版式，同一 Parser。有效期写在 **零件行**（`stamping_parts`）：项目号、版本、生效、失效。不要写在整包覆盖键上，不要库内「从 AA 复制为 AB」当主路径。少胶块合册工艺表体空 → **不插** 工艺行。

SOP 第一次导入：每行版本抄确认表头版本，生效抄 SOP 月。设变导入（禁止整包覆盖删除）：

| 文件里的零件号 | 库里 | 系统做 |
|----------------|------|--------|
| 新号 | 无 | **增行**（主表+工序），版本=本文件头/变更字，生效=切点月 |
| 已有号且未换号（3096AA） | 有 | **跳过或按文件更新工序**；**不改** 其 SOP 生失效、不删 |
| 文件没有的旧号 | 有 | **不动** |

同一项目同一零件号，两行时段禁止重叠（AA 与 AB 是不同号，可并存）。本例 3096 未换号，**可以不传工艺 Excel**。

### 4.3 模具布点：布点清单 Excel，按零件号对齐（策略同树）

有效期写在 **布点零件行**（`stamping_die_parts`）：项目号、版本、生效、失效。现网覆盖键是基地+项目整包——设变模式禁止整包替换。SOP 第一次导入：每行抄 SOP 版本与开始月。少胶块合册布点表体空 → **不插** 布点行。

| 文件里的零件号 | 库里 | 系统做 |
|----------------|------|--------|
| 新号 | 无 | **增行**，版本与生效写在该行；`alloc_ratio` 默认同现网首次导入 |
| 已有号 | 有 | 可更新尺寸/工序；已手改 `alloc_ratio` 沿用；**不改** SOP 生失效 |
| 文件没有的旧号 | 有 | **不动**，不删 |

本例 3096 未换号，**不必** 出布点 Excel。新号要进一级台账才传。有布点且该月有效才可能摊模具费。

检具费另表、同样 Excel：有效期在检具零件行上，按号增行、不删旧号（本期不展开公式）。

### 4.4 采购对象：设变导入后自动带出（跟树根有效期，不另上传）

仍是 **一 snapshot 一份清单**，行按 `source_node_id`。对象行 **不加** 生失效四列。命中、计数、检测、确认、审核、删除、核价覆盖 **只用树根 as_of**（与结构树同一月）。列表两列生效/失效从所属 L0 读，与结构树 L0 同值、同 `YYYY-MM`；L0 改期对象立刻跟。禁止对象行另存一套、禁止用清单头整包 `qa_passed` / `l0_count` 当本月账。合册 **没有** 采购对象表。细则见 [bom-procurement-objects-design.md](../bom/bom-procurement-objects-design.md) §14。

现网生成页对整份 snapshot **删头重写**。设变后 **禁止** 再点「开始生成」（会撞已审锁定，且按 `source_node_id` 带回 **抄不到** 新树上的 3096AA）。缺对象走工程变更重传，生成页不提供「只补该月」。

材料清单按树对齐成功后，**同一事务**只扫新种的那一棵，往原清单 **插行**（不删头、不碰旧行）：

| 新树上的节点 | 系统做 |
|--------------|--------|
| 列入采购对象，且被替换旧树上有同行（同 `part_number` + `section` + `object_kind`，本例 3096AA） | **插新行**（新 `source_node_id`，`l0_*` / 父件 / Excel 行号抄新节点）。确认三态、确认人时、确认备注、`supplier_name` **从那棵旧树抄**。**不抄** `audit_status`（新行待审） |
| 列入采购对象，旧树无同行（1137AB） | **插新行**，`confirm_status=pending`，`supplier_name` 空。禁止从钢厂列 / 备注 / 年度价猜厂家 |
| 核对区（QR36410 标准件/胶等、异常） | **插新行**；无确认可抄。用量 0 + 备注「去除」未插入的叶子 **不插** |
| 旧树已有行 | **不动**，已审保持已审 |

匹配只认 **被替换的那一棵旧树**，禁止扫 snapshot 里其它总成的同号。`object_kind` 变了当新号，不抄确认。抄来的 `supplier_name` 不跑 `require_enabled`；全称已不在供应商表则落空，不让整单失败。

7.1–7.3、HUD、确认/审核门禁：对该月 **命中树根** 的节点与对象行做，不做全林。本例 8 月只对 3086AB + 仍有效的其它树；7 月只对 3086AA + 当时有效的树。已审锁定只约束被打到的那批行；增量不要求先反审整项目。不写一条冒充整单覆盖的生成日志；带出件数记在工程变更列表。

8 月打开即见 3096AA（新节点、确认已带、待审，生失效 = 3086AB）和 1137AB，不必再点生成。7 月仍是 1137AA（生失效 = 3086AA）。一点「审核」不得打到未命中的树。

焊接拆解对本棵新树同样 **随设变导入自动生成**（只拆新树，不碰旧树），否则总成核价仍要人补一步。拆解细则不在本文展开。

### 4.5 价表与核算

年度价：1137AB 一行（振华）；必要时 1133AB。包装：3086AB 若走 I1/I2。3096 号没变，不必出布点/检具 Excel。少胶块若分总成也升了才导 1137AB；只交货总成升版、分总成号未动则年度价不换行。剔除叶子不进该月核价。

2026-07：有效树含 3086AA（序号 5），抄 3096AA、1137AA。  
2026-08：有效树含 3086AB（仍序号 5），仍抄 3096AA，改抄 1137AB。

财务对奇瑞：3086AB 树根 `grand_total`。采购协议：3096AA + 1137AB。分析跨月口径 **loose**。

引擎：该月只收有效树根（按 SOP `seq_no` 序）；叶子冲压价抄该月有效工艺行。总成卡抄树根项目号、版本。

3. 海众：不必另出工艺确认或布点（3096 未换号）

6. 跑 2026-08 引擎  

7 月及以前重算仍走 3086AA。不要反审旧月改成 AB。

## 6. 一份合册 Excel（不要三次上传）

日常设变只走 **工程变更** 页（§8）。下载的模板里一次性包含 BOM、冲压工艺确认、模具布点。少胶块也用这份，不要手工勾树。首次 SOP 仍走现网三页分别上传；那三页页顶写明「只导入 SOP，投产后换号必须走工程变更」，见 [有效期 §7.1](bom-process-die-effective-period-design.md)。

| 文件 | 首次/阶段冻结 | 日常设变 |
|------|----------------|----------|
| 材料清单 | 整表导入，多种树；每棵树根抄 SOP 版本与开始月 | **同一 Parser**，按树对齐；新树根写本文件版本与切点月 |
| 冲压工艺确认表 | 首次导入每行抄 SOP 版本与开始月（不再用整包 version 当有效期） | **同一 Parser**，新号增行并写该行生失效，**不删** 旧号 |
| 模具布点清单 | 同上，写在布点零件行 | 同上 |

切点月写在 **变更头** 工作表（及上传表单，须一致）。一份文件进系统后，只落到新树根 / 新工艺行 / 新布点行。用量 0 且备注含「去除」的材料清单行不种节点（§1.1）。未改行保持 SOP 当时写下的生失效。不要拆成三次上传。

## 8. 产品：工程变更上传与列表

单独做，不塞进材料清单上传页、工艺上传页、布点上传页。那三页只做 SOP，页顶文案见 [有效期 §7.1](bom-process-die-effective-period-design.md)。侧栏建议在焊接工程附近：**工程变更**（上传 / 列表）。不要第二颗「减件」按钮。

### 8.1 上传

表单：基地（下拉已启用）、项目（该月可引入）、**切点年+月**、文件。切点月与文件「变更头」必须一致，否则整单拒绝。

| 工作表 | 对齐现网模板 | 本例怎么填 |
|--------|----------------|------------|

| `工艺确认填写说明` | 现网模板「填写说明」 | 原文保留 |

### 8.2 列表

分页。列：切点年月、基地、项目、被替换树根、新树根、SOP 序号、材料清单是否有树、**剔除件数**（用量 0 +「去除」）、工艺新增件数、布点新增件数、采购对象新增（含核对区）、上传人、时间、源文件名。点行可看该次写入的树根零件号与生失效，以及剔除的零件号。筛：基地 / 项目 / 切点年。下载仍是 §8.1 同一模板（空表体），不是把历史变更再导成合册。
