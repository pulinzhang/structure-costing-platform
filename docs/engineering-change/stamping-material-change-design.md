## 0. 一句话

> **互换性不影响时，核价对象仍是同一个零件号；牌号必须从生效月切开。**  
> 本通道只做这件事。图变、少装、加装、整棵停交，仍走现网四句改图工程变更。

动机：现网芜湖 T13J 振华工艺里，左右 B 柱气囊导向支架牌号是 `DC01`（见 §0.1）。**上游已给出切到 `DC03`，且不影响互换性。**

冲压零件价按 **牌号全等 + 料厚** 匹配当月钢材联动价，再按料片消耗算材料费。`DC01` 与 `DC03` 是两个档案牌号，会匹配到两条不同的联动价。不影响互换性，只说明核价对象仍是同一个零件号；**不**说明生效月及之后仍按 `DC01` 匹配联动价。

没有本通道时：工艺行 `material` 仍是投产时的 `DC01`；同号确认表再导会跳过；改图换号还会把旧行材质`DC01`整列抄到新号。零件价计算因此一直用 `DC01` 去匹配钢材联动价，该件材料费仍按 `DC01` 那条联动价计算，不会改用 `DC03` 那条。

### 0.1 现网举例（芜湖 T13J）

数据来自本机现网库 `stamping_parts`（芜湖 / T13J，查询日 2026-09-22）。工艺承制与确认表版本是投产事实；本通道 **不改** 这两列。

**前提（上游已给出，全文只用这一条）：** 用 `DC03` 冲出来的件能直接装到原来的位置上，不改孔位、不改焊接规范、不换配套件 → 不影响互换性。本通道 **不替设计部做这个判断**，只认格子里的固定句。变更后牌号因此 **必须是 `DC03`**，禁止在同一条故事里改写成别的牌号。

振华确认表 `V3-01` 上，现网牌号为 `DC01`、且本例子要切到 `DC03` 的，用这一对（料厚均 1.5 mm，工艺生效 2025年01月）：

| `403014115AA` | 左B柱气囊导向支架 | 0.151 | 现网为 0 级交货件（无父节点） |
| `403014116AA` | 右B柱气囊导向支架 | 0.151 | 同上，右件 |

| 谁 | 2025年12月 | 2026年01月起 |

再变一次：2026年07月不能再用 `MAT-202601`。另传一本新的变更版本（例 `MAT-202607`），变更前必须写成当时解析值 **`DC03`**。回滚先删后一本。本文主例子只写到 DC03 这一刀。

- 全鑫现网已有 `DC03`（如 `502007700AA` 左侧后背门铰链安装板）——那是 **另一厂、另一零件、投产就是 DC03**，不能证明 115AA 该不该换号，也不能把全鑫行写进振华这一本。全鑫自己的 DC01 件若同一通知覆盖，另开一本，冲压工厂写全鑫。

- 芜湖 T13J 改图样本（2025年05月）是 `551003095AA` 左前门上铰链加强板（振华，`HC340/590DPD+Z`）换号成 AB——图变，走四句改图。本通道的 115AA / 116AA 现网仍是 AA，没有换号。

## 1. 判据（根）

互换性分析是上游变更管理的结论，核价平台不替设计部做。本通道 **消费** 结论，不推断结论。

| 结论 | 核价对象 | 走哪条 |
|------|----------|--------|
| 影响互换性（外形、安装接口、焊接规范或配套件要跟着动） | 新零件号 → 全新核价对象 | 现网改图 / 增加零件 / 此件不装 |
| 不影响互换性（能直接换装，只改牌号/状态） | 同号，材质从生效月更新 | **本文** |
| 没有结论 | 不准猜 | 两条都拒；回去补互换性判定 |

零件号变不变是这个判据的 **输出**，不是原因。禁止用「号没变」证明变更合规，也禁止用「号变了」代替互换性。

本通道 Excel **必须**写明「不影响互换性」。这不是可空备注，是选用本通道的准入句。写不出这句，不要走本通道。

## 2. 为什么必须独立（ADR）

现网改图工程变更已经冻结：

- 变更类型只准四句：完成停止 / 改图 / 增加零件 / 此件不装。
- 五种结构场景：总成图变了 → 交货总成必换号；旧到期、新启用。
- 冲压件 UNIQUE：`(location, stamping_supplier, vehicle_model, part_number)`，**同号只能一行**；`version` 不当身份；生失效四列永远不进 UNIQUE。
- 改图换号：除零件号、版本、生失效、简图外整行抄旧号（**含材质**）；当月已有号一律跳过。

把「同号换牌号」塞进改图，会同时撞上：变更后号已在树上拒收、同号跳过、抄旧材质、UNIQUE 不能插第二行。这不是漏一列，是身份模型不同。

**因此：另做一条工程变更，另做一本 Excel，另做列表与回滚。禁止给现网四句加第五句「材质变更」。**

### 2.1 身份怎么切（已定）

**不**为同号再插一行 `stamping_parts`。那会拆 UNIQUE，把改图、布点、加工费引用一起拖下水。已否决。

**不**在旧工艺行上改 `material`。若直接改字，对生效月之前的账期重算零件价时，也会按新牌号匹配联动价。已否决。

**已定：工艺行仍是投产/确认表上的那一行、那个零件号。** 切点写在独立的材质变更单上。当月牌号 = 解析器按账期月叠变更单，不是直接读 `stamping_parts.material`。

```text
as_of 月 < 该件第一条材质变更的生效月
    → 用工艺行 material（投产/确认表字）

as_of 月 ≥ 某条材质变更的生效月
    → 用「生效月 ≤ as_of」的最后一条变更单的变更后牌号
```

多条按生效月排队。同一零件同一生效月只准一条。后一条的变更前牌号必须等于前一条叠完后的当月牌号。

工艺行 `material` 列 **不改字**。列表、导出、零件价、钢材测算凡按月取牌号，必须走解析器。禁止业务把 `StampingPart.material` 当成「这个月的牌号」。

### 2.1.1 变更版本记在哪（管理必须有，不当零件身份）

工程变更要能回答：这是第几次、哪一份通知、原件在哪。这和「工艺 UNIQUE 里有没有 version」不是一件事。

现网改图已经是这样拆的：管理版本写在 Excel 表头（如 `EC-202507`），原件进 `upload_files`，列表按变更单管；工艺行上的 `version` 只是那张确认表头的字，**不是**零件唯一键。本通道同一纪律，只是没有工艺确认表可写回头——所以 **变更版本只落在材质变更单 + 上传头 + 存档文件上**，禁止写回 `stamping_parts.version`（那一列继续表示投产/改图确认表头，避免和 `D/00` 搅在一起）。

| 要管的事 | 记在哪 | 不记在哪 |
|----------|--------|----------|
| 这一次叫什么版本 | 变更单「变更版本」列；整本同一字；上传头冗余一份 | 工艺 UNIQUE、零件号 |
| 变一次再变一次 | 各插一条变更单，按生效月排队；每本自己的变更版本 | 覆盖上一条、改工艺行 |
| 存档 / 对原件 | 原件落盘 + 文件溯源（`file_category` 本通道独立一类）；列表能下载当时那本 Excel | 只改库里牌号、不留文件 |

对人说 **变更版本**。不要说升版。系统不猜、不从生效月拼 `EC-202507`；格子里写什么用什么。同一项目未回滚的变更版本不得重复（第二次变更必须换一个字）。同一本里所有行必须同一变更版本、同一生效月。

示例见 §0.1：2026年01月 `MAT-202601`，`403014115AA` 的 DC01→DC03；若再变必须换变更版本（例 `MAT-202607`），变更前写成当时的 `DC03`。列表两本都在。解析器：账期月 ≥ 后一本生效月 → 用后一本的变更后牌号；此前仍用前一本。回滚必须先删后一本。

### 2.2 和改图怎么衔接

| 事 | 规则 |
|----|------|
| 先材质变更、后改图换号 | 改图抄旧号时，材质必须抄 **改图生效月对旧号解析后的牌号**，禁止抄工艺行投产列。否则新号工艺行会写成 `DC01`，换号之后零件价仍按 `DC01` 匹配联动价 |
| 先改图、后材质变更 | 材质变更打在 **当前仍有效的零件号** 上（AB，不是已到期的 AA） |
| 同一零件同一月既改图又改材质 | **整单拒收**（两条通道任一条）。先定互换性：影响 → 只改图；不影响 → 只材质 |
| 共用件 | 工艺一行一号。同号材质变更对该号生效的所有总成同时生效。这是对的（仍是同一件物料）。不要套改图的 `EC_PROCESS_SHARED_OLD` |

SOP 工艺再导：可以改投产列；**账期月一旦落在某条材质变更生效月及之后，解析器以变更单为准**，再导改不掉切点后的牌号。切点前的月仍看投产列。

## 3. 范围

### 3.1 做

- 独立菜单、独立上传、独立列表、整本回滚。
- 一本 Excel：工程变更单（材质）+ 填写说明。不要材料清单、不要工艺确认表、不要布点。
- 钉死：基地（上传页）+ 项目 + **变更版本** + 生效年月 + 冲压厂 + 零件号 + 变更前牌号 + 变更后牌号 + 不影响互换性。
- 拼焊：按子片改（子片序号 + 子片零件号）；总成行材质空的不要当普通件改。
- 核价：钢材联动规格扫描并入当月解析牌号；冲压零件价从生效月起按新牌号匹配钢材联动价；总成核价只引用零件价金额。旧月已算过的结果不自动重算（与改图同一纪律）。
- 原件落盘并登记文件溯源；变更单带变更版本，列表可下载原件、可回滚。

### 3.2 不做（第一期）

- 不种树、不换零件号、不到期旧工艺/旧布点、不抄检具费/模具费/包装/年度价。
- 不改工序、料厚、净重、料片尺寸、利废标记、简图。
- 不改 BOM 节点上的「材料」列（产品结构第一期仍显示投产字；总成核价引用已算好的冲压零件价，不按树上材料列匹配钢材联动价）。
- 不改采购对象行上的材料快照。
- 不在上传时硬要当月已有新牌号联动价（缺价仍在零件价计算时报「未匹配到钢材联动价」）。
- 不把批次/炉号/库存状态做成核价身份。
- 不给 DC01→DC03 做牌号模糊匹配（也不从别的牌号猜 DC03）；只认档案 `grade` 全等（O/0 规则与牌号分类同一套 `grade_match_key`）。
- 不猜下一位字母、不从旧牌号拼新牌号。
- 利废件、家模废料副产品：材料不走新板牌号，本通道拒收。
- 不把本通道做成同步 Excel（宪法同步名单不为本功能开口）。上传仍异步，与改图同一形态。

## 6. 系统怎么写

切片仍是下游 `engineering_change`，只调上游 Service。禁止 stamping / costing import 本通道的 Router。解析器纯函数放 `app/common/` 或 stamping Service 稳定查询（一处），零件价 / 列表 / 导出都走这一处。

### 6.1 表

上传头：与改图上传头分开，避免回滚搅在一起。字段：基地、项目、**变更版本**、生效年月、文件 id、状态。表名自管。

变更单行 = 一条切点（列表实体）：

| 列 | 含义 |
|----|------|
| 上传头 id | 整本删除用 |
| 文件 id | 溯源；与上传头同一原件 |
| 变更版本 | 抄上传头；给人检索 |
| excel_row | 行号 |
| 项目 / 生效年 / 生效月 / 冲压厂 / 零件号 | 切点身份 |
| 子片序号、子片零件号 | 可空；普通件空 |
| 变更前牌号 / 变更后牌号 | 档案 `grade` |
| 互换性 | 落库固定句 |
| `source_part_id` | 指向当时命中的 `stamping_parts.id`，RESTRICT |
| 拼焊则 `source_blank_id` | 指向子片，RESTRICT |
| status | `active` / `rolled_back` |

两把唯一（都只约束未回滚）：

- 切点：同一厂同一项目同一零件号（+ 子片）同一生效月只能一行。
- 管理版本：同一项目同一变更版本只能一本。

生失效不进 UNIQUE。工艺行 `version` **不更新**。

原件：成功路径写入磁盘并 `register_existing`。`file_category` 单开一类（落地时列入 [文件溯源](../file-trace/file-trace-design.md) 封闭名单），不要和改图 Excel、工艺确认表混类。失败回滚不登记。

效果链接：供整本回滚指到本行 id。未知 `effect_kind` 仍拒收。本通道只登记这一种业务对象。

### 6.2 写入纪律

- 只 **insert** 变更单行。禁止 UPDATE `stamping_parts.material` / 子片 `material` / `stamping_parts.version`。
- 禁止为本通道去改工艺 UNIQUE、禁止同号第二行工艺。
- 指挥家：prepare（校验）→ persist（插行 + 链接）→ commit。主方法不种树、不抄费。
- 失败：先 rollback 再标上传失败。

### 6.3 解析器（当月牌号）

输入：基地、冲压厂、项目、零件号、年、月；（拼焊再加子片键）。

1. 取该月命中的工艺行（现网 `is_in_period`）。没有行 → 没有当月零件，本通道也不该给它建切点。  
2. 取该身份上 `status=active` 且 `生效月 ≤ as_of` 的变更单，按生效月升序。  
3. 从工艺行材质出发，按序把每条的变更后牌号叠上去（每条的变更前必须等于叠到它之前的值，导入时已校验；解析时仍按变更后走）。  
4. 输出当月牌号。

消费方如何调用见 §6.4。钢材联动价公式仍按牌号+料厚匹配，不因本通道改加减价算法。

### 6.4 消费链（谁读当月牌号）

工艺行 `material` = 投产/确认表字。**「这个账期月这件用什么牌号」只问解析器。** costing / stamping 只调解析器（或 stamping Service 包一层带账期月的规格查询），禁止 import 本通道 Router，禁止各自再叠一遍变更单。

依赖顺序（与核价引擎 4.1 → 4.2 → 4.3 同一条）：

```text
材质变更单（切点）
    → 解析器(as_of 月) → 当月牌号
        → 钢材联动 Step1 规格（基地 × 牌号 × 料厚）
            → 基价 + 牌号分类大类 + 厚度/宽度政策 → 当月钢材联动价行
                → 冲压零件价：解析牌号 + 原料厚 匹配联动价 → 材料费；快照记下解析牌号
                    → 总成核价 / 总成还原：只引用零件价金额与当时绑的钢价行，不再解析牌号
```

用 §0.1 的 `403014115AA`：2026年01月解析为 `DC03`。芜湖现网另有 `DC03` + 1.2 mm（全鑫铰链安装板），钢价按 **牌号+料厚** 分行，1.2 mm **不能**当 1.5 mm 用。该月 Step1 必须出现 `DC03` + 1.5 mm，零件价才能匹配到对应联动价。2025年12月解析仍是 `DC01`，Step1 仍由本件贡献 `DC01` + 1.5 mm。

#### 必须走解析器（第一期）

| 消费方 | 现网 | 落地后 |
|--------|------|--------|
| 钢材联动 Step1 `list_material_specs`；引擎钢种门禁 `inspect_steel_coverage` 同一套 | 该基地工艺行 ∪ 子片去重，**不按账期、不叠变更** | 在现网集合上 **并入** 该账期月在期零件（+子片）的解析牌号+原料厚。未切件的解析结果等于投产列。不要改成「只扫解析后」而丢掉未切件规格。已到期件是否进扫描沿用现网，本通道不顺手改 |
| 冲压零件价计算（含拼焊按子片） | 读 `part.material` / `blank.material` | 用解析牌号去 `find_steel_prices`；快照 `stamping_part_costs.material` 记解析值 |
| 零件价列表 / 导出 / 供应商价格通知（已审零件价） | 读零件价快照 | 仍读快照，不回头读工艺行 |
| 冲压零件列表、详情、材料列表、工艺确认表导出、钢材采购测算导出 | 读工艺行列 | 查询带账期月时，展示与按材质筛选都用解析牌号。禁止 `WHERE stamping_parts.material = 'DC03'` 去找 115AA（库里仍是 `DC01`） |
| 改图换号抄材质 | 抄旧号工艺列 | 抄 **改图生效月** 对旧号的解析值（§2.2） |

零件价页、引擎、单独点「计算钢材联动」三条入口，规格扫描必须同一套 as_of。只改零件价计算器、不改 Step1：115AA 会报「未匹配到钢材联动价（材质=DC03, 料厚=1.5）」，因为联动价表里可能根本没有这一行。

#### 不走解析器（第一期）

| 消费方 | 仍读什么 | 原因 |
|--------|----------|------|
| 工艺行 / 子片库字段、SOP 确认表再导 | 投产字 | 切点不改库 |
| BOM 节点「材料」、采购对象行材料快照 | 清单导入时的字 | 总成核价不按树上牌号匹配钢价 |
| 加工费 / 模具费 / 检具费计算与结果快照 | 工艺行材质（展示用） | 公式不用牌号；快照不当「当月牌号」第二源 |
| 模具清单导出、布点 | 模具侧材质 | 本通道不改模具 |
| LLM 工艺分析 | 工艺行 | 第一期不改 |

总成核价的材料金额 = 树上冲压件已算好的零件价。它 **消费零件价结果**，不消费变更单，也不消费工艺行牌号。要让 2026年01月总成材料费跟上 DC03，顺序是：该月钢材联动（规格已含 DC03+1.5）→ 重跑该月零件价 → 再跑总成（或引擎一次跑完）。只重跑总成、不重跑零件价，总成仍引用旧快照。

#### 不是消费方

变更单不存单价。基价表、牌号分类档案、厚度政策 **不**读变更单；它们按牌号全等 / 大类工作。本通道只要求变更后牌号已在档案（上传门禁）；该月能否展开基价、厚度政策，是钢材计算/引擎门禁的事，缺了报现网那句，不在上传材质变更时硬挡。

### 6.5 对月度自动核价引擎

引擎设计见 [核价引擎](../costing/costing-engine-design.md)。本通道 **不改** 引擎三参数、DAG、R5（不改公式）、年度补算名单。引擎仍然只编排：发现 → 门禁 → 年度补算 → 4.1 钢材 → 4.2 零件价 → 4.3 总成。它 **不读** 材质变更单，ready 里 **不**增加「本月是否有未回滚材质变更」门禁，硬停跳转 **不**指向本通道上传页。

影响只发生在引擎已经调用的钢材覆盖检查和子计算：那些入口改成按账期月问解析器之后，引擎自动跟上。禁止在 `CostingEngineService` 里再叠一遍变更单。

| 阶段 | 影响 |
|------|------|
| 0 发现 | **无。** 仍按该月命中工艺 ∪ L0，再滤可引入项目。`403014115AA` 还是同一零件号，T13J 还在名单里。同号换牌号不产生新 scope |
| 1 门禁 §5.1 | **覆盖集合变，门禁结构不变。** `base_price` / `thickness_policy` / `width_policy` 仍走 `inspect_steel_coverage`，必须与 4.1 Step1 **同一套 as_of 规格**。芜湖 2026年01月将算规格须含 `DC03`+1.5 mm；基价或厚度/宽度政策盖不住 → 现网硬停，跳转仍是基价上传 / 政策页。没有材质变更时，集合与现网相同 |
| 2–3 年度补算 | **无。** 加工费、模具费、采购对象、焊接拆解/焊接费不因同号换牌号而缺行，引擎不为此重补 |
| 4.1 钢材 | 调现网 `SteelPriceCalcOrchestrator`。Step1 并入解析规格后，该月可多落 `DC03`+1.5 mm 一行。已审核的旧规格行仍跳过不覆盖（现网纪律） |
| 4.2 零件价 | 调现网零件价 Orchestrator；计算器按解析牌号匹配联动价。该件该月若 **已审核** → 引擎跳过不覆盖，快照仍是切点前牌号。未审才会按 `DC03` 重算。引擎不因本通道反审、不删结果 |
| 4.3 总成 | **间接。** 仍只引用零件价金额。4.2 没按新牌号写出快照，总成材料费仍是旧的 |
| 5 月度核对导出 | **无。** 只导出不算价 |
| 删 Run | **无。** 仍只清编排账本，不回滚钢材/零件价/总成 |

对人说：材质变更导入成功 **不会**自己改已算账。要 2026年01月跟上 DC03，对芜湖跑该月引擎（或按 §6.4 顺序手点钢材 → 零件价 → 总成）。该月零件价已审，先走现网反审/重算，不要指望引擎覆盖已审行。对 2025年12月跑引擎：解析不到 `MAT-202601`，覆盖集合与切点前相同。

## 7. 门禁（失败则整本拒收）

文案常量另开前缀，不要复用改图 `EC_*` 把两种通道搅在一起。落地时再定全文；这里定语义。

| 语义 | 拒收条件 |
|------|----------|
| 表不够 | 缺「工程变更单（材质）」或没有数据行 |
| 项目不一致 | 上传页、变更单项目不是同一个 |
| 变更版本空/不一致 | 缺变更版本，或本本各行不是同一个字 |
| 变更版本重复 | 该项目已有未回滚的同一变更版本 |
| 生效月不一致 | 整本不是同一个生效月，或不等于上传页 |
| 厂不一致 | 整本不是同一个冲压厂 |
| 类型/互换性 | 互换性不是「不影响互换性」 |
| 零件不在 | 该厂该项目该生效月没有命中的工艺行 |
| 零件已到期 | 生效月晚于零件失效月，或生效月不晚于零件生效月（切点必须往后切） |
| 变更前对不上 | 变更前牌号 ≠ 解析器在叠本行之前的当月牌号 |
| 变更后不合法 | 空、与变更前相同、牌号分类没有（O/0 规则命中后落档案字） |
| 同月重复 | 该身份该生效月已有未回滚切点，或本 Excel 内重复 |
| 与改图同月 | 该零件号在该生效月有未回滚的改图换号（旧号到期或新号启用打在同一月） |
| 利废/副产品 | `is_offal_nested` 或 `is_scrap_byproduct` |
| 拼焊填法 | 普通件填了子片；拼焊总成没指子片却去改总成空材质 |
| 项目期 | 生效月不在项目可引入期内 |

不拒：基价表暂时没有新牌号。那是核价月的事。

## 8. 核价与旧账

消费顺序见 §6.4。这里只定旧账：

| 月 | 行为 |
|----|------|
| 生效月前 | 解析仍得旧牌号；已有钢材联动行 / 零件价快照 / 总成卡不动 |
| 生效月及之后，尚未重算 | 零件价快照仍是旧牌号（与改图「已算过的月不自动改号」同一句）。要按新牌号匹配联动价 → 从生效月起按 §6.4 顺序重跑钢材联动（若该规格尚未落行）→ 零件价 → 需要时总成 / 引擎 |
| 生效月及之后，重算 | 解析得新牌号，按新牌号+原料厚匹配联动价；料厚、工序、加工费、模具费不因本通道而变 |

快照表 `stamping_part_costs.material` 仍记 **计算当时** 解析出的牌号，便于对账。不要把变更单 id 塞进公式。总成还原展示的钢价来自零件价当时绑定的联动价行，不现场再解析。

`DC01` 与 `DC03` 各自匹配各自的钢材联动价。变更单只记前后牌号，不存单价、不存价差。

## 9. 列表、回滚、权限

列表按项目、变更版本、生效年月、零件号、牌号筛。一行 = 变更单的一行，必须能看见变更版本、生效年月、前后牌号、原件文件名。详情/列表提供下载当时 Excel。删除列表任意一行 = **整本**回滚（与改图一头多行一起没同一纪律）。

回滚：

- 其后还有该零件（+子片）更晚的未回滚材质变更 → 拒绝（必须从最新切点往回删）。
- 只删本通道插的变更单行 / 上传头 / 效果链接。工艺行、BOM、费表一行都不动。
- 已有零件价快照 **不**当 RESTRICT 挡回滚（快照不是本通道插的行）。回滚后旧月快照仍可能写着新牌号，直到人重算；列表提示「回滚后请视需要重算生效月及之后的零件价」。不要静默改历史快照。

权限（落地进 `catalog.json`，本文不抄树）：一级仍 `menu:engineering-change`。新增：

- `menu:engineering-change-material-upload` + `op:…:view` / `op:…:upload`
- `menu:engineering-change-material-list` + `op:…:view` / `op:…:delete`

不要复用改图上传/删除码，避免授权改图的人顺带改材质。

API 前缀建议 `/api/engineering-change/material`（静态段在参数路径之前）。整数 id 写成 `/{id:int}`。

## 12. 明确不在本文的

- 互换性判定怎么在顾客/设计部系统里做出来（只要结论句）。
- 实物批次、仓库一物一码怎么贴。核价只切牌号时间轴。
