## 0. 一句话

**L0 给财务：算出核算成本，将来对实际成本看差异。L1 和退化 L0 给采购：算出应成本，和二级签采购合同。奇瑞不准总成直接委外（电泳等除外），二级只接分总成和冲压件。**

两件必须分开说，**使用部门也不同**：

| 口径 | 对象 | 给谁用 | 回答什么 | 现网 |
|------|------|--------|----------|------|
| **财务核算账** | 有子件的 L0 供货总成 | **财务** | 核算成本是多少；将来对 **实际成本**，看差异 | 已有：成品月总账（一口价剪枝 + L0 焊接费） |
| **采购应成本账** | **L1 分总成、L1 冲压件**、退化 L0 | **采购** | 和二级签合同时，这件「应该」值多少 | **缺口** |

现网焊接工艺拆解 **已经拆 L1 分总成**；缺的是把允许外发的 **L1 分总成 / L1 冲压件 / 退化 L0** 做成采购可用的应成本。财务继续用 L0 成品账去对实际。

## 1. 背景

### 1.1 主机厂约束（写死）

我们是奇瑞的 **一级供应商**：交给奇瑞的必须是 **供货总成（L0）**，由我们对外报价、交货。

奇瑞要求：

| 对象 | 可否委外 | 说明 |
|------|----------|------|
| **供货总成**（有子件的 L0，本厂冲焊装配后交货） | **否** | 总成不得直接委外。不能把整层 L0 交给别人做成成品再送给奇瑞，也不能按「买一个现成总成」经营 |
| **电泳等特殊处理** | **是（唯一例外）** | 总成/零件需要电泳、黑漆、盐雾等表面处理时，处理可以外发。这不是把总成整层外包，只外包处理工序 |
| **分总成**（L1 且有子件） | **是** | 直接采购焊好的分总成（如凸焊总成供货） |
| **L1 冲压件**（L1 无子件） | **是** | **同样是直接采购**：买冲好的板料件，不是自己冲完再往上焊。T13J 里这类叶子很多，**一部分**外发 |
| **其它冲压件**（L2、无工艺的退化 L0） | **是** | 板料件可以外发冲压；L2 多半包在分总成合同里，不一定单独签 |

承接分总成和冲压件的厂，业务上通常叫 **二级供应商**（分总成厂 / 冲压件厂）。电泳厂是特殊处理外协，挂在例外条款下，不要和「总成委外」混称。

```text
奇瑞（主机厂）
    ▲  只认一级交出的 L0 供货总成
我们（一级供应商）          ← 总成冲焊装配必须在这一层
    ├─ 自制：L0 自己焊，子件自己冲
    └─ 允许外发的只有
         ├─ 分总成 L1（有子件）──────► 分总成厂（二级）  直接采购分总成
         ├─ L1 冲压件（无子件）──────► 冲压件厂（二级）  直接采购冲压件
         ├─ 其它冲压件（L2 / 退化 L0）► 冲压件厂（二级）
         └─ 电泳等特殊处理（例外） ─► 表面处理外协
```

**核价含义：** 财务看有子件的 L0。采购看 **L1 分总成和 L1 冲压件**（都是直接采购）以及退化 L0。有子件的 L0 **不要做成「整层应成本对二级报价」**。

### 1.2 为什么会有委外

产能不够时，交给二级的经营方式都是 **直接采购**，不是买散件回来自己做：

| 买什么 | BOM 形态 | 合同标的 |
|--------|----------|----------|
| 分总成 | L1 **有子件** | 焊好的分总成（凸焊等加工费 + 里面的冲压） |
| **L1 冲压件** | L1 **无子件** | 冲好的板料件（只有冲压应成本，没有焊接拆解） |

T13J：205 个 L1 里 53 个有子件（分总成），**152 个无子件（冲压件叶子）**。后者不是「剩下的自制件」一笔勾掉——**其中一部分也是直接采购委外**。哪些外发、哪些自制，BOM 没有供应商列，靠年度价 / 人工，见 §12.1。

因此对二级件要同时看见：

1. **加工费**（仅分总成 / 退化 L0 电泳）：凸焊、焊点、电泳等。
2. **冲压成本**：L1 冲压件本身，以及分总成里的 L2 板料。无论谁冲，都按本台冲压核价口径（材料净成本 + 冲压加工费）。

**退化 L0**（L0 下没有任何子件，现网拆解备注已有这个词）要拆开看：

- 有电泳 / 黑漆等原文 → 符合主机厂例外：冲压件（可二级）+ 特殊处理外协。
- 无工艺 → 这件就是一张板当成品交，允许作为 **冲压件** 给二级，**不是**总成委外，也 **不要**编成电泳。采购签合同时按冲压件应成本；财务侧它仍是一笔 L0 交货，核算成本里也要有这一笔。

### 1.3 谁用哪一层（写死）

一级供应商对内两套用法，不要做成一张给所有人看的总账。

| 层 | 部门 | 现在做什么 | 将来做什么 |
|----|------|------------|------------|
| **L0（有子件的供货总成）** | **财务** | 用系统算出的 **核算成本**（成品月总账）入账、分析结构 | 拿到财务 **实际成本** 后，核对实际 vs 核算的差异 |
| **L1 分总成**（有子件） | **采购** | 应成本 = 子件冲压 + 分总成加工费 | 与二级分总成厂 **签订采购合同** |
| **L1 冲压件**（无子件） | **采购** | 应成本 = 该件冲压价；**直接采购**，不是自制后再装配 | 与二级冲压件厂 **签订采购合同** |
| **退化 L0** | **采购**（合同）+ 财务仍见其 L0 交货 | 电泳例外：冲压 + 处理费；无工艺：按冲压件 | 与二级冲压件厂 / 表面处理外协签合同；财务对实际时仍按 L0 成品核对 |

```text
财务 ──看──► L0 供货总成核算成本 ──将来──► 对实际成本，出差异
采购 ──看──► L1 分总成 / L1 冲压件 / 退化 L0 ──现在──► 和二级签采购合同
```

约束：

- 财务不拿 L0 去和二级签「总成采购合同」（主机厂也不允许总成直接委外）。
- 采购不拿有子件的 L0 整层应成本当合同标的。
- **L1 无子件 ≠ 一定自制。** 一部分是直接采购的冲压件，和分总成一样要进采购应成本账。
- 退化 L0 对奇瑞仍是一级交货，所以财务账里要有完整核算成本；对内它又是采购对象，合同用采购应成本，不要两套公式。

### 2.2 委外分总成的信号在备注，不在供应商列

有子件的 53 个 L1 **全部带焊接原文**（几乎都是凸焊）。备注高频写法：`凸焊总成供货`、`沿用件（凸焊总成供货）`。

这是经营信号：「这层不是自己焊完再往上交，而是向 **二级分总成厂** 按凸焊分总成买进来」。  
**表上没有二级厂名称。** 若同一行备注落到有子件的 L0 上，按主机厂约束视为 **违规候选**（总成不得直接委外），先人工核对是不是其实写在 L1 上。

### 2.2b L1 冲压件：152 个叶子，一部分也是直接采购

T13J 的 L1 **叶子一律没有焊接原文**（0 / 152）。形态就是一张板（或标准件），挂在 L0 下面。

现网成品核价把它们当叶子取冲压价 / 年度价，**没有「这是不是买来的」标记**。业务上：**除了分总成，一些 L1 冲压件也是直接采购委外**——和分总成同一套采购动作，只是合同标的没有焊接。

备注里已有「改成冲压单件供货」这类写法（左右后轮罩后内加强板），说明经营上会明确「这层按冲压件买/供」，不是分总成。哪些叶子外发，不能从「无焊信」自动全选，见 §12.1。

## 3. 现网：L1 拆解了吗？

**拆了。计费没用它。**

### 3.1 焊接工艺拆解（已上线）

生成入口扫的是 **所有带 `weld_info` 的 BOM 节点**，不限 L0：

- L0 原文 ← Excel 第 7 列「焊接总成信息」
- L1 原文 ← Excel 第 12 列「焊接总成信息」
- L2 **没有**焊接列，现网也不会给 L2 拆；若 L≥2 出现焊接信息会标 `anomaly`

L1 拆完后只做 **rollup 对账**：

```text
L0.process_qty(token) == Σ(L1.process_qty × L1.assembly_qty)
  → L1 行 rollup_flag = rolled_in_parent
L1 有、L0 无同名 token
  → orphan_child
其余 own
```

列表默认筛 L0，但可以切到 L1。退化 L0 会备注「供货总成无下级子件（退化 L0）」；L0 且拆不出工艺时再叠「计费异常」。

### 3.2 成品焊接费（已上线，只认 L0）

`bom_l0_welding_fees` 写死：**仅 `level=0` 过程量 × 分年焊接单价；下级工艺不计费。**

所以 L1 拆解在现网的角色是 **核对 L0 数量从哪来**，不是 **给委外开一张加工费账单**。

### 3.3 成品月核价（已上线）

对有子件的 L1：命中年度价 → **一口价剪枝**，L2 不 rollup（明细落 `skipped_by_bundle`）。  
对无子件的 L1：当叶子，先冲压价再年度价。

**L0 自己永远不当叶子。** `rollup_l0` 只遍历 L1。退化 L0（没有 L1）的月总账里，冲压 / 外购 / 一口价全是 0，只剩焊接费（还可能拆失败）。

这和「退化 L0 也要核算冲压 + 电泳」直接冲突。

## 4. 现网缺口（对着 T13J）

| # | 缺口 | 证据 |
|---|------|------|
| G1 | 委外加工费没有独立结果 | 焊接费只挂 L0；L1 凸焊被当成 L0 的构成，不单独对供应商 |
| G2 | 一口价挡住了应成本 | 经营上「直接采购分总成」走包价是对的；核价要把子树打开 |
| G3 | 退化 L0 不算冲压 | rollup 不给 L0 自身取 `stamping_part_costs` |
| G4 | 退化 L0 的材料 / 备注导入丢失 | `node_parser` 材料属性 **故意不落到 L0**；仅 L0 行的牌号、料厚、厂家、重量、备注丢了 |
| G5 | BOM 无二级厂名 | 没有「供应商」列；`材料厂家` ≠ 分总成厂 / 冲压件厂 |
| G6 | 电泳写法未拆全 | `电泳黑漆：0.098m2` → `partial`、0 行工艺（中支撑） |
| G7 | 凸焊双冒号未拆 | `凸焊:：2` 归一化后变成 `凸焊：：2` → `unparsed`（左右后尾灯安装板分总成） |
| G8 | 盐雾升档无规则 | 备注「240h 提升至 720h」，标准工艺仍默认 ≤244H |

G4 / G6 / G7 是采购应成本账的前置数据问题：表已经进库，但退化 L0 的钢厂/料厚和部分工艺量是空的。

## 5. 名词（先对齐，再谈表）

| 对外说法 | 内部代号 | 含义 |
|----------|----------|------|
| 供货总成 / 成品 | L0（有子件） | 交给奇瑞的报价单元；**不得整层委外**；**给财务**，核算成本将来对实际 |
| 一级供应商 | 我们 | 对奇瑞交货、报价；总成冲焊装配在这一层 |
| **二级供应商** | 分总成厂 / 冲压件厂 | 只承接奇瑞允许外发的 **分总成** 和 **冲压件** |
| 分总成 | L1 且 **有子节点** | 直接采购焊好的分总成；**给采购**签二级合同 |
| **L1 冲压件** | L1 且 **无子节点**（板料叶子） | **一部分直接采购**冲好的件；**给采购**签冲压件合同；无焊信 ≠ 自制 |
| 其它冲压件 | L2；无工艺的退化 L0 | 可外发；L2 常包在分总成合同里 |
| 特殊处理外协 | 电泳 / 黑漆 / 盐雾等 | 主机厂例外；采购合同标的是处理费（可含冲压件） |
| **退化 L0** | L0 且无子节点 | 成品=零件；**采购**用来签合同，财务仍按 L0 交货看核算成本 |
| 凸焊总成供货 | 备注信号 | 向二级采购焊好的分总成；若写在有子件的 L0 上视为违规候选 |
| **核算成本** | 财务口径 | 系统算出的 L0 成品成本；将来 vs **实际成本** |
| **实际成本** | 财务口径（未来） | 账上真实发生；本台先把核算成本算准，差异分析另期 |
| **应成本** | 采购口径 | L1 分总成 / L1 冲压件 / 退化 L0 摊开的冲压 + 加工；签合同时用 |
| 财务核算账 | 现网 L0 月总账 | 原称经营账；给财务 |
| 采购应成本账 | 本稿要建的 | 原称核价账；给采购 |
| 材料厂家 | `material_mill` | 钢厂或标准件商，**不是**二级冲焊厂 |
| 二级供应商名称 | **本 BOM 没有** | 需要另源：年度价 `supplier_name`、人工、或以后加列 |

## 6. 节点怎么走（分类写死）

```text
BOM 节点
  ├─ L0 有子件          ← 总成不得直接委外；**给财务**（核算成本，将来对实际）
  │     财务账：本厂容器 + L0 焊接费 + 子树材料（一口价或拆散）
  │     采购账：不对 L0 整层开合同应成本；只对下面允许外发的 L1 / 冲压件开
  │
  ├─ L1 有子件          ← 允许给二级；**给采购**签分总成合同（直接采购分总成）
  │     ├─ 委外分总成（候选：备注含「凸焊总成供货」等）
  │     │     应成本 = Σ(L2 冲压或外购) + L1 工艺费
  │     │     对账   = 年度一口价（二级报价）→ 合同价
  │     └─ 自制分总成（无委外信号）
  │           工艺已含在 L0 焊接费里（rolled_in_parent）
  │           材料按现网拆 L2 或一口价
  │
  ├─ L1 无子件          ← **L1 冲压件**；**一部分直接采购**；**给采购**签冲压件合同
  │     应成本 = 该 L1 冲压 unit_cost × 用量（无焊接拆解）
  │     自制的 L1 叶子不进采购合同账，仍进财务 L0 材料
  │
  ├─ L2                 ← 多半随父 L1；委外分总成里打开算应成本，不单独签合同
  │     叶子取价：冲压 → 年度价 → `-` 回退冲压
  │
  └─ L0 无子件（退化 L0）← **给采购**签合同；财务仍见 L0 交货核算
        ├─ 有电泳 / 面积 / 黑漆 / 喷粉 / 电镀
        │     主机厂例外：冲压（可二级）+ 特殊处理外协
        │     应成本 = L0 自身冲压价 + 表面处理费
        └─ 无工艺
              按冲压件：应成本 = L0 自身冲压价
              可二级冲；不是总成委外，无工艺 ≠ 电泳
```

**不要**把「没有子件」直接等于「一定电泳」。T13J 14 个退化 L0 里 8 个没有任何处理原文。  
**不要**把「L1 没有子件」直接等于「自制」。T13J 152 个 L1 叶子里，**一部分是直接采购的冲压件**。  
**也不要**把有子件的 L0 标成二级采购对象：那直接违反主机厂「总成不得直接委外」。

## 7. 两本账（财务 vs 采购）

不要把「买分总成」和「一级成品核算」揉在一口价里。按部门拆开：

```text
财务（L0 有子件）
  核算成本 = 现网成品月总账
  将来：实际成本 − 核算成本 → 差异

采购（L1 分总成 / L1 冲压件 / 退化 L0）
  应成本 = 冲压 [+ 分总成工艺或特殊处理]
  现在：应成本 vs 二级报价 → 签采购合同
```

```text
                    ┌──────────── 财务核算账（已有，L0）────────────┐
供应商报价 / 一口价 ─► L0 月总账 bundle_amount / 外购
L0 焊接费           ─► welding_amount（只认 L0 原文）
叶子冲压            ─► stamping_amount（不穿过一口价剪枝）

                    ┌──────────── 采购应成本账（待建）────────────┐
委外 L1 分总成      ─► 冲压（L2）+ L1 拆解工艺 × 焊接单价
委外 L1 冲压件      ─► 该 L1 自身冲压价（无工艺行）
退化 L0             ─► L0 当叶子取冲压价 + 拆出的电泳等
对比                ─► 应成本 vs 一口价 / 二级报价 → 合同
```

### 7.1 财务核算账：保持现网 L0，避免双计

成品卖给奇瑞的月总账 **继续给财务**（核算成本）：

- 委外 **L1 分总成** 有年度价 → 一口价，不从 L2 rollup（否则和直接采购分总成不一致）。
- 委外 **L1 冲压件** 有年度价 → 财务侧按外购叶子计（现网取价顺序已覆盖）；采购侧仍要出冲压应成本卡合同。
- L0 焊接费仍只挂 **本厂交到奇瑞的那一层工艺**（L0 原文）。L1 上已 `rolled_in_parent` 的凸焊不要再加进 L0。

委外加工费 **不要** 再累进同一条 `welding_amount`，否则凸焊会记两遍。

### 7.2 采购应成本账：签二级合同用

**委外分总成（一个 L1 有子件）——采购合同标的：**

```text
stamping_amount     = Σ (L2 命中当月冲压 unit_cost × 相对该 L1 的有效用量)
purchased_amount    = Σ (L2 未命中冲压、命中年度价的叶子)
process_fee         = Σ (L1 拆解明细 计费用量 × 焊接单价)   // 只认该 L1 自己的工艺，不认 L0
should_cost         = stamping_amount + purchased_amount + process_fee
vendor_quote        = 年度零件价 unit_price × L1 用量   // 可空
gap                 = vendor_quote - should_cost        // 报价缺失则只出应成本
```

冲压取价键与成品侧一致：**年 + 月 + 基地 + 项目 + 零件号**（不认 `stamping_supplier`）。  
工艺单价与 L0 焊接费同一张 `bom_welding_unit_price`（基地 + 年 + 标准工艺名）。

**委外 L1 冲压件（无子件）——采购合同标的：**

```text
stamping_amount = 该 L1 当月冲压 unit_cost × L1 用量
process_fee     = 0          // 无焊接原文，不编工艺
should_cost     = stamping_amount
vendor_quote    = 年度零件价 unit_price × L1 用量   // 可空
gap             = vendor_quote - should_cost
```

无冲压价则 `partial`。不要因为「L1 无子件」就当成外购标准件跳过冲压应成本——直接采购的是冲好的板料，应成本仍是冲压口径。

**退化 L0 ——采购合同标的（冲压件或处理外协）；财务 L0 交货核算另见 §12.2：**

```text
stamping_amount = L0.part_number 的当月冲压 unit_cost × 单车用量
process_fee     = L0 拆解出的电泳/面积等 × 对应单价
should_cost     = stamping_amount + process_fee
```

财务核算账上，退化 L0 目前材料为 0。采购应成本补上之后，**财务 L0 核算账要不要同步把自身当叶子** 是拍板项（§12.2）：财务将来要对实际 vs 核算，材料为 0 会对不出差异。

### 7.3 防双计（写死）

| 场景 | 财务核算账（L0） | 采购应成本账（L1 / 退化 L0） |
|------|--------|--------|
| 委外 L1 分总成有一口价 | 只进 bundle，L2 不进冲压合计 | 打开子树算应成本，**对比**一口价 |
| 委外 L1 冲压件 | 叶子取价（冲压或年度价）进材料 | 另出冲压应成本卡合同；不要和财务材料再加总成「付两遍」 |
| 委外 L1 分总成无一口价 | 现网会拆 L2 进冲压/外购 | 仍要补 L1 工艺费；材料不要和财务账再加总到同一张「应付」 |
| L1 工艺已 rolled_in_parent | L0 焊接费已含 | 采购账可以展示「含在 L0 工艺里」，但 **加总应成本时若该 L1 被标委外，用 L1 自己的工艺，不要再加 L0 同名 token** |
| 退化 L0 电泳 | L0 焊接费（拆得出才有） | 与财务账同一笔工艺，采购账用来配冲压和签合同，不要再复制一笔进月总账 |

## 12. 待拍板

### 12.1 哪些 L1 进采购应成本账？

要分开认：**分总成** 和 **L1 冲压件** 都是直接采购，认定规则不同。

**分总成（有子件）：**

| 方案 | 做法 | 风险 |
|------|------|------|
| A. 备注关键词 | 「凸焊总成供货」等 | T13J 覆盖好；别的项目写法一变就漏 |
| B. 结构 | 凡 L1 有子件且有焊接原文 | 53 个全中；自制分总成也会进来 |
| C. 年度价 | 有一口价的有子件 L1 即委外 | 买进来但还没导价的会漏 |
| D. 人工标记 | 打 `outsourced` | 准，但要人 |

**L1 冲压件（无子件）：**

| 方案 | 做法 | 风险 |
|------|------|------|
| B′. 凡无子件 L1 全进 | T13J 152 个全进采购账 | 自制叶子也会进合同列表 |
| C′. 年度价有该 L1 | 有报价才当直接采购 | 还没导价的外发件会漏 |
| D. 人工标记 | 打 `outsourced` | 准，但要人 |
| 备注 | 「冲压单件供货」等 | T13J 只有零星几条，覆盖不够 |

**推荐默认：** 分总成用 B 出候选 + A 加置信；L1 冲压件用 **C′ 出候选 + 人工确认**（不要 152 个全当外发）。不要在导入时因没供应商就失败。两种都确认后才进采购应成本账。

### 12.2 退化 L0 的冲压进不进财务核算账？

现在成品月总账材料为 0，对 顶横梁Ⅱ 这类「成品就是一张板」核算成本是错的。财务将来要对 **实际 vs 核算**，缺冲压会对不出差异。

| 选项 | 做法 | 谁受影响 |
|------|------|----------|
| 只进采购账 | 合同有数，财务 L0 核算仍缺材料 | 采购能签合同；财务差异失真 |
| 改 `rollup_l0`：无子件 L0 自身当叶子 | 财务核算完整 | 成品总额变化，要单独验收 |

**推荐：财务核算账要进**（否则 §1.3 对实际对不上）；采购合同用同一套应成本，不要两套公式。实施仍单独验收，不和 P2 绑死。

### 12.3 无工艺的 8 个退化 L0 算不算委外？

**推荐：不算电泳 / 不算总成委外。** 按 **冲压件** 核算应成本。主机厂允许冲压件给二级，没有处理原文就不要编电泳。是否真的外发给了冲压件厂，靠年度价 / 人工，不靠「无子件」自动判定。

### 12.4 盐雾 720h

备注写明升档。自动映射到 `电泳（盐雾试验要求244H-720H）`，还是默认 ≤244H 留人工改？自动更贴近 T13J 这两件卡钳支架。

### 12.5 委外加工费单价

复用基地年焊接单价（推荐），还是按供应商另维护价表？一期建议复用，避免两套目录。
