# 供应商 — 设计初稿

> 状态：**设计初稿（未落地）**  
> 界面：**供应商**。工艺筛选项「冲压工厂」、采购对象「合同对方」、年度价「供应商」为同一主数据，不另立工厂表。  
> 库字段（现网下游仍存字符串）：`stamping_supplier` / `supplier_name`，落地后写入 **缩写**。  
> 基地见 [location-design.md](location-design.md)，项目见 [vehicle-model-design.md](vehicle-model-design.md)。本文不定义基地、项目。

---

## 0. 一句话

> **供应商只在本页手工增加。有缩写、全称、ERP 代码，以及启用/禁用。下游找不到：停止，来本页手工增加。禁止从文件名或自由文本发明供应商。**

---

## 1. 为什么做

现网没有供应商实体。工艺从文件认出厂名写入 `stamping_supplier`（常是全称）；年度价、采购对象行上 `supplier_name` 是自由文本。同一家单位多种写法，无法对 ERP。

主数据给出稳定身份：**ERP 代码** 对外系统，**缩写** 给人看、给下游字符串列存，**全称** 对文件核对与正式名称。

钢厂 / 紧固件商（`material_mill`）不是本文，仍在一事一议 / 材料侧。

---

## 2. 已定规则

| # | 规则 |
|---|------|
| S1 | 供应商只在本文。不挂在项目下。不替代基地 |
| S2 | 与基地同属主数据；**不依赖** 项目 / 冲压 / BOM / 核价。按供应商写入的下游依赖本文 |
| S3 | 只在供应商页手工增加。下游找不到就回本页手工补，禁止代建、禁止 `get_or_create` |
| S4 | 必填 **缩写**、**全称**、**ERP 代码**。三者各自唯一。ERP 代码创建后不改。全称、缩写创建后不改（历史写法用别名） |
| S5 | 凡要点选供应商，选项只来自本文。禁止自由输入 |
| S6 | 文件名/表头里的厂名只核对已选供应商（或已维护的别名），不能当身份来源 |
| S7 | 不从下游表 `DISTINCT stamping_supplier` / `supplier_name` 发明自己 |
| S8 | **启用 / 禁用** 即可。已启用才允许新引入。不物理删除。不做生效/失效日期、不另做暂停 |

钢价、冲次单价不按供应商写，不走本文。  
采购对象指定对方、年度价供应商：走本文。点选细则：[bom-procurement-object-supplier-design.md](../bom/bom-procurement-object-supplier-design.md)（已改为点选本文，不再自由文本）。

## 3. 位置

```
基地               ★ 位置绝对上游
供应商             ★ 对方绝对上游（与基地平行，互不隶属）
    │
    ├── 项目（只依赖基地）
    │
    └── stamping / bom / costing   写供应商字符串时先问本文
```

下游继续存字符串，值 = **缩写**（与现网列对齐，不把 ERP 代码、全称铺进每张业务表）。列表展示缩写，需要正式名称时读主数据全称。

---

## 4. 概念

| 字段 | 含义 |
|------|------|
| `erp_code` | ERP 代码，唯一，创建后只读 |
| `abbreviation` | 缩写，唯一，界面主显示；下游 `stamping_supplier` / `supplier_name` 存这个。例：常庆 |
| `full_name` | 全称，唯一。例：安庆常庆汽车部件有限公司。文件名/表头核对优先对全称 |
| 别名 | 可选。其它历史写法映射到同一条。全局唯一，不得等于任一缩写或全称 |
| 启用 / 禁用 | 已启用才允许新引入 |

缩写 ≠ 全称；不要只用其中一个。界面点选可显示「缩写（全称）」。  
已禁用：不准新引入，已有数据仍可查。

---

## 5. 找不到

| 情况 | 去哪 |
|------|------|
| 没有这条供应商（缩写、全称、ERP 代码、别名都不中） | 本页手工增加 |
| 有行但已禁用 | 本页改为启用；下游不代建 |

上传/计算/采购对象页可深链，不得内嵌创建。

---

## 6. 范围

**做：** 供应商可维护（缩写 + 全称 + ERP 代码 + 启用/禁用）；可选别名；点选改读本文；按供应商写之前先过本文（已启用）；一次性把现网已出现的厂名对上全称或灌成待补（ERP 代码、缩写须人工补齐，禁止空 ERP / 空缩写 / 空全称入库）。

**不做：** 钢厂主数据；一件对多家；合同号/单价；按基地区分同一供应商成两条；全库整型外键；生效/失效日期；暂停。

侧栏独立项「供应商」，不要和基地、项目做成同一张表。
