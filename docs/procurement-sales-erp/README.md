# 采购、销售与 ERP 接口

> **状态：设计与合同送审稿。不写业务代码，不改、不删现有程序和结果表。**  
> 产品名：结构件自动核价平台。  
> 三件事：销售核价、采购部与销售部分工、结果与 ERP 对接。合同把这三件事写成产品范围和定制开发范围。

本目录是给业务、商务和后续实施看的。现网核算公式仍以 [总成月核价](../costing/assembly-costing-design.md) 为准。这里不另起一套算法。

## 三句话

1. **采购**继续认采购对象，结算价是应成本，不含这张卡上的管理费等间接费用。
2. **销售**认供货总成。基数相同来源的月总账，管理费、财务费、报废费、税前利润都是基数乘费率。销售价等于现网总费用。
3. **ERP 双向接口**分写入和读取。写入把已审核的采购结算价、销售价及比例明细写入 ERP。读取按字段对照从 ERP 取得约定的业务数据。

核算逻辑不分成两套。一次计算落成同一批核价卡，两个部门读不同的行、不同的列。
