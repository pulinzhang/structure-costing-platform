# 销售核价 — 设计说明

> **状态：设计定稿，未落地。** 不新写核算程序，不删除现有核算程序。  
> 公式来源：[总成月核价](../costing/assembly-costing-design.md)。采购对照：[采购核价表](../costing/procurement-pricing-sheet-design.md)。  
> 现网已经一次算出应成本和总费用。本文只规定销售部读哪一行、哪一列，以及比例费用怎么向业务解释。

---

## 0. 一句话

**销售核价的一行是一台供货总成，不是一个采购对象。** 基数是这张卡的月总账。管理费、财务费、报废费、税前利润都是基数乘系统费率。销售价是基数加上这些比例费用，再加上包装档案上的运输和仓储捆包。这个销售价就是现网树根卡的总费用，不另算一遍。

---

## 1. 和采购差在哪

两边用同一次计算结果。差别是身份和读哪一列。

| | 采购 | 销售 |
|--|------|------|
| 一行是谁 | 采购对象（冲压件、分总成、退化供货件） | 供货总成（材料清单的树根） |
| 结算价 | 应成本，等于月总账 | 销售价，等于总费用 |
| 管理费等 | 不进采购结算价。对象卡上即使算过间接费用，采购列表也不拿来当结算价 | 按比例单列，加进销售价 |
| 读者 | 采购部 | 销售部 |

采购对象清单里的件，是向二级厂买的。供货总成是向客户交的。销售部不对着采购对象加管理费。

有子件的树根不会出现在采购清单里。它只出现在销售列表。无子件的退化供货件既是树根也是采购对象：采购部看它的应成本，销售部看它的销售价。两个数都在同一张卡上，不允许销售部把应成本再乘一遍费率。

---

## 2. 基数

基数只认供货总成那张卡的月总账。

```text
基数 = 材料 + 本卡自己的焊接费 + 本卡自己的焊接其它费用
     = total_amount
     = should_cost
```

材料已经含叶子的零件标准成本。零件标准成本里面有过一次零件级的财务费、管理费、仓储包装费、税前利润。那是零件价里的构成，不是销售页上再乘的那一次。

销售页禁止：

- 把下级分总成、采购对象的焊接费加进基数
- 把零件标准成本里的四项附加拆出来，在销售页再加一次
- 用采购对象的应成本之和代替树根基数
- 缺年度价、缺包装时改基数或禁止出销售行。缺了就按现网：对应金额为 0，行仍在

---

## 3. 比例费用

只此四项。费率来自系统设置，计算时抄进这张卡的快照。以后改设置，不改已经落下的月份。

| 费用 | 算法 | 系统设置默认 |
|------|------|----------------|
| 财务费 | 基数 × 成品财务费率 | 2% |
| 管理费 | 基数 × 成品管理费率 | 2% |
| 报废费用 | 基数 × 成品报废率 | 3‰ |
| 税前利润 | 基数 × 成品税前利润率 | 2% |

```text
比例费用合计 = 财务费 + 管理费 + 报废费用 + 税前利润
```

四项都按本卡基数乘。基数为 0，四项为 0，仍要列出，不能省行。费率以卡上快照为准，不拿当前设置回算历史月。

这四项对应现网间接费用里的财务、管理、报废、税前利润。不新造费率字段，不按部门各存一套费率。

---

## 4. 进销售价、但不是比例

下面三项仍进销售价，销售页单独列出，并标明「非比例」。不得把它们改成基数乘费率。

| 费用 | 从哪来 |
|------|--------|
| 单件运输费 | 该年、该基地、本卡零件号的包装档案 |
| 仓储费 + 捆包费 | 同一条包装档案上的其它费用 |
| 检具分摊、器具分摊 | 现网未建主数据，金额为 0，仍占位 |

没有包装档案时，运输和仓储捆包为 0，不因此把整张卡算失败。

零件级「仓储+包装管理费用率」已经含在零件标准成本里，不拿到销售页再乘一次。

---

## 5. 销售价

```text
销售价 = 基数 + 比例费用合计 + 单件运输费 + 仓储捆包费 + 检具分摊 + 器具分摊
       = grand_total
```

对不上这张恒等式，沿用现网：这张卡记失败，不在销售页改数凑平。

销售价不是客户合同价，也不是开票价。平台不维护销售协议价，不算与客户结算价的价差。那条线已经否决，见 [锚点送货与价差](../costing/anchor-true-up-design.md)。

---

## 6. 列表上有什么

查询条件与总成核价相同：基地、年、月，项目可选。不按采购对象、不按供应商筛。

每一行：

| 列 | 含义 |
|----|------|
| 基地、项目、年、月 | 账期范围 |
| 零件号、零件名称 | 供货总成 |
| 基数 | 月总账 |
| 财务费、管理费、报废费用、税前利润 | 金额，并带出本卡费率 |
| 比例费用合计 | 四项之和 |
| 单件运输费、仓储捆包费 | 非比例 |
| 销售价 | 总费用 |
| 核算状态、审核状态 | 沿用现网 |

不出现：供应商、采购分类、应成本、对二级厂的报价和价差、冲压工序、采购对象块。

展开只打开这张卡的费用构成，不打开下级采购对象的材料还原。材料还原仍是采购部的采购核价表。

导出跟当前筛选。文件是销售核价表，不是《批量零部件价格协议》。

---

## 7. 计算与审核

月度计算仍是现在这一次。算完同时得到采购可读的应成本和销售可读的销售价。不为销售部再跑一轮，也不按部门覆盖对方的数。

审核仍按年、月、基地、项目成批处理，不按当前打开的是采购还是销售来少审一半。未审核通过的行可以查询，不能作为对 ERP 或对外报价的正式数。

---

## 8. 落地时不要做的事

- 不新建销售结果表，不复制一套总成核价
- 不删除现有核价卡、加工费、零件价程序
- 不把采购结算价改成销售价
- 不把比例费用摊回采购对象
