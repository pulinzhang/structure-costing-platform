# 暂估与正式结算 — 设计说明

> 状态：**与实操不符，不要落地。**  
> 现场口径见 [锚点送货与价差核价](anchor-true-up-design.md)：送货价是一个锚点月，不是每个自然月两套暂估/正式账。  
> 下文仅作讨论留痕，避免再按「计划库/实际库」实施。

---

## 0. 一句话

> **生产经营等不到当年订价：先用上年协议价把当月成品账算出来并锁住（暂估）；当年价下来后再用同一套公式把同一月再算一遍（正式）。两套结果都留在表里，按零件/月对差额。**

不是「计划库 + 实际库」。暂估不是预算，是已经拿去结算的账；正式不是另一套系统，是同一月的定稿重算。

---

## 1. 场景（和「年中改价」不是一件事）

客户最终订价往往晚到 7、8 月。2026 年 1–6 月生产经营必须走：用 **2025 年沿用价** 做暂估结算。2026 年协议价在 7/8 月才定，再对 1–6 月按新价算正式，并比较两次差额。

| | 暂估 vs 正式（本文） | 生效期（另一篇） |
|--|---------------------|------------------|
| 同一月算几次 | **两次**（沿用价 / 定稿价） | 通常一次 |
| 2026 价 8 月才到 | **回溯** 1–6 月，用定稿价重算正式 | 不该用「8 月起生效」冒充这件事 |
| 8 月商务把已定稿价从 1 元改 2 元 | 不是本文 | 才是生效期：1–7 月正式不动 |

两篇正交。晚到的全年订价 = 正式重算已过月份；已定稿后再改口 = 分段生效。不要用生效期去表达「价还没来」。

现网缺口：成品月账唯一键是 `(年, 月, 基地, 车型, BOM 版本, 零件号)`，一格一行。正式一算，暂估被盖掉，差额比不成。

---

## 2. 不要两套库

「结构一样的计划库 / 实际库」心智接近，做法错。

| 两套 SQLite / 两套全表 | 同一库加账本 |
|------------------------|--------------|
| 用户、BOM、工艺、权限、原件都要复制或硬跨库 | 主数据仍一份 |
| 差异只能导出再对 | `JOIN` 同一零件同一月 |
| 引擎、列表、审核全部 ×2 | API 多一个参数 |
| 备份、哪套是真的，说不清 | 一行上写明暂估还是正式 |

结构一样 = **月度结果表多一列账本，其余列不动**。不是 clone 整个应用。

对外用词：**暂估** / **正式**。不用「计划 / 实际」（计划像预算，实际像另一套生产系统）。

代码枚举：`provisional` / `final`。现网已有行迁移为 `final`（当时并没有第二套账，视为正式）。

---

## 3. 最小范围（先做完再谈扩）

客户要比的是 **结算单上的钱**：这个月这个成品、这个冲压件，暂估多少、正式多少、差多少。

**一期只给两张月度结果表加账本：**

| 表 | 现网唯一键加上 |
|----|----------------|
| `costing_assembly_costs`（及 items / indirects 仍挂主表 id） | `settlement_kind` |
| `stamping_part_costs` | `settlement_kind` |

明细不必自己再标账本：跟着主表走。

**不加账本（一期）：**

| 对象 | 原因 |
|------|------|
| 用户、权限、BOM、冲压工艺、文件溯源 | 不是两套公司 |
| 一事一议基价 / 厚度政策、当月钢材联动 | 月度政策通常已到；暂估与正式默认 **共用该月已审钢材价**，差异才落在晚到的协议价上 |
| 年度零件价、焊接单价、冲次单价、包装 | 仍是一份主数据。暂估计算时 **取哪一年的价** 写在结果头上，不要把 2025 价复制进一套「2026 计划价表」 |

钢材若也经常晚到、也要两版，再给 `steel_prices` 加同一列。一期不要全盘双份，否则差异里分不清是钢价变了还是一口价变了。

成品焊接费、冲压加工费：一期正式重算成品时，若仍按年取、且主数据已被定稿覆盖，焊价/加工费会跟着变，差额会含进去。若暂估时必须钉死「沿用的焊价/冲次」，结果头上同样记下取价年（见 §5），计算走该年主数据。不必先给焊接费结果表加账本，除非列表也要单独对比加工费。

---

## 4. 账本规则

`settlement_kind`：`provisional` | `final`。

| 规则 | 说明 |
|------|------|
| 同一月可以两行 | 青岛 · 2026-03 · 某 L0：一行暂估、一行正式 |
| 审核独立 | 暂估已审，仍可算正式；正式不覆盖暂估 |
| 正式不要求先有暂估 | 1 月订价已到，只跑正式 |
| 覆盖仍按「同账本」 | 重算 2026-03 **暂估** 只动暂估行（未审才覆盖，已审跳过，与现网一致） |
| 禁止用正式覆盖暂估 | 引擎 `settlement_kind=final` 不得 delete/update provisional 行 |

列表默认：有正式显示正式；筛选可切暂估 / 正式 / 全部。对比不走列表行点击，走单独「暂估正式对比」页（操作列或顶栏入口）。

---

## 5. 计算时「沿用哪一年」

暂估不是把 2025 价改写成 2026 价表再算（那样定稿一导入，沿用没了）。而是 **算 2026 年 3 月账时，协议价去读 2025 年那张已审表**。

结果主表记下取价来源（整数年，可空表示「等于本结果年」）：

| 字段 | 暂估示例（算 2026-03） | 正式示例 |
|------|------------------------|----------|
| `year` / `month` | 2026 / 3 | 2026 / 3 |
| `settlement_kind` | `provisional` | `final` |
| `annual_price_year` | 2025 | 2026 |
| `welding_price_year` | 2025 | 2026 |
| `tonnage_price_year` | 2025 | 2026 |

成品 / 零件 orchestrator 取年度价、焊接单价、冲次单价时用这些年，**不要**用结果年去撞还没来的 2026 价表。钢材联动仍用结果年+月。

引擎启动：现有基地 + 年 + 月，加上：

- `settlement_kind`（必填）
- 暂估时：沿用年度，默认 `year - 1`，可改
- 正式时：取价年默认等于 `year`，门禁要 2026 协议价已审

门禁：暂估不要求当年年度零件价存在；要求沿用年有已审协议价。正式相反。

## 6. 差异怎么比（给客户、给程序、给分析）

对比键：`year + month + location + vehicle_model + bom_version + part_number`（冲压件对比键对齐零件价唯一键，不含 BOM）。

只比 **两边都有** 的行。仅暂估、仅正式，列表标「缺正式 / 缺暂估」，不编造差额。

成品一行建议输出：

| 列 | 来源 |
|----|------|
| 暂估月总账 / 总费用 | provisional |
| 正式月总账 / 总费用 | final |
| 差额、差额率 | 正式 − 暂估 |
| 分项差 | 冲压、外购、一口价、焊接、焊接其它、间接 各自相减 |
| 取价年 | 两行头上的 `annual_price_year` 等，解释「为什么差」 |

金额用 Decimal。分析 / LLM 读同一张对比结果或同一套 JOIN，不要读两个库。

一期先做 **按月 + 基地** 的成品对比列表 + 导出。零件价对比同构，可同一页 Tab。不要一期做瀑布分解到每一个焊点。

## 7. 和现网流程怎么接

```text
2026-01～06  订价未到
  引擎：settlement=暂估，沿用年=2025
  → 写出 2026 各月 provisional，审核后用于厂内暂估结算

2026-07/08  2026 协议价导入并审核
  引擎：对 1～6 月逐月（或批量月份）settlement=正式，取价年=2026
  → 写出 final；provisional 仍在

对比页：选基地 + 2026 + 1～6 月 → 看差额
```

已审核暂估月：正式计算 **不得** 为了腾地方去反审暂估。两套并存。

## 8. 明确不做

| 非目标 | 原因 |
|--------|------|
| 第二套数据库 / 全表 `_plan` 副本 | §2 |
| 把暂估叫计划、正式叫实际 | 用词错 |
| 一期钢材、基价、BOM 双份 | 差异会脏；主数据仍一份 |
| 用生效期表达「价 8 月才到」 | 那是回溯重算，不是 8 月起生效 |
| 正式自动覆盖暂估 | 比不成 |
| 审核 Excel 快照当第二套账 | 已否决过的偷懒 |
| 一期焊点级差异树 | 先出成品/零件差额 |

---

## 9. 实施顺序

1. 两张结果表加 `settlement_kind`（默认 `final`）+ 三个取价年字段；UNIQUE 含账本。  
2. 计算 / 引擎入参加账本与沿用年；取协议价走取价年。  
3. 列表筛选账本。  
4. 对比 API + 一页 HUD 表 + 导出。  

现网数据全部视为正式，行为与现在「一月一行」相同。没有暂估行就不显示对比。

---

## 10. 验收

> 2026 年 1–6 月用 2025 价跑暂估并审核。8 月导入 2026 价，再跑 1–6 月正式。暂估行还在、金额不变。对比页 3 月某成品能看到两列金额和分项差。没有第二套库。

| 场景 | 通过 |
|------|------|
| 只跑正式 | 与现网一月一行一致 |
| 暂估后再正式 | 两行；暂估已审不被覆盖 |
| 对比 | JOIN 得差额；缺一边不编数 |
| 取价 | 暂估读 2025 年度价；正式读 2026；钢材仍读 2026-03 |
