## 0. 一句话

**按供应商出合同附件。** 行来自已指定对方的采购对象；列是查询窗口内每个自然月一列应成本。给采购和二级厂签合同用，不是总成一览的单月核价卡。

## 1. 为什么单独切片

| 现网 | 不够的地方 |
|------|------------|
| 采购对象列表 | 无月度金额 |
| 总成一览 · 采购视图 | **一个月**一张卡，不能按合同期横排 |
| 年度零件价 | 年协议价，不是应成本月序列 |

本切片 **禁止**：

- 再算一遍 walk / 间接 / 焊接。
- 再实现一套 `object_kind` 分类器。
- 新建 `costing_outsourced_*` 结果表。
- 回写采购对象或总成卡。

依赖方向：`costing` → 只读 `bom` 采购对象 + 只读 `costing_assembly_costs`。BOM 不得依赖本切片。

## 2. 查询范围

必填：

| 键 | 含义 |
|----|------|
| `location` | 采购基地 |
| `vehicle_model` | 项目 |
| `bom_version` | BOM 版本（解析当前 snapshot，与清单相同） |
| `start_year` + `start_month` | 窗口起（含） |
| `end_year` + `end_month` | 窗口止（含） |

可选：`supplier_name`（精确或规范化后全等，签约附件按一家一导）。

窗口规则：

- 闭区间，按自然月展开列。例：`2026-01`～`2026-03` → 三列；`2025-11`～`2026-02` → 四列。
- 开始不得晚于结束。
- **列数上限 12**（一次查询）。常用 **3～6** 个月；页面默认 3 个月（结束 = 开始 + 2 月）。
- 禁止固定 1～12 月全年横表当唯一形态。
- 超过 12 个月 → `BusinessException`（400），不要截断 silently。

清单未生成 → 404 或业务 400「请先生成采购对象清单」（与 summary 一致，实施时与现网采购对象 summary 对齐）。  
检测 `qa_passed=false`：**允许查、允许导出**，页头标明未通过（与清单导出相同：看见缺口，不假装合格）。

## 3. 行集

默认签约包（签合同用）：

```text
section = object
confirm_status = outsourced
supplier_name 非空
该 snapshot 的清单行
```

自制、待定、未指定供应商：**默认不出**。筛选项可打开「含未指定」供采购补洞，但导出文件名/页头须标明「含未指定」，避免当合同附件发出去。

核对区（标准件/胶等、异常）**永不进入**本报表。至少有一个一级件带内部号的 L0 成品不在集合里。全部 L1 无内部号的 L0 按退化供货件列入。

### 3.1 准备表 → 汇总（价目表）

两步，**不落库**。页面和合同附件只出第二步。导出可附「准备」Sheet 供核对。不要和查询接口 `/prep`（供应商下拉）混名。

**① 准备表（按节点）**

签约包内每个采购对象一行。键是 `source_node_id`（=`bom_nodes.id`）。清单表 `id` 再生成会变，不要当键。

每行至少：零件号、零件名称、内部号、供应商、所属供货总成、`seq` 口径序号、**节点单车用量**、窗口内各月 `should_cost`。

节点单车用量 = 从所属 L0 到本节点 `qty` **沿树连乘**（BOM 已约定；不要只抄相对父件的 `1`）。  
月价：总成卡唯一键 `(year, month, location, vehicle_model, bom_version, source_node_id)`，IN 节点 id。无卡空。

例：`551001137AA` 挂在多棵树上 → 准备表多行，各行自己的用量和单价。

**② 汇总（价目表，按零件号）**

本附件范围内（已按供应商筛）按 **`part_number` 一行**。

| | 规则 |
|--|------|
| 单车数量 | `SUM(节点单车用量)` |
| 月结算价格 | 组内该月 `should_cost` **去重**。同号同月只应有一个单价 |
| 名称 / 存货编码 | 组内一致则写出；不一致仍按第一处（准备表可对） |

同号同月只应有一个单价。出现两个不同 `should_cost`：**算错了或数据不一致**（不是缺月那种正常空格）。禁止平均、禁止挑一个、禁止静默空格当缺口。查询和导出都 `BusinessException`（400），文案带零件号、月份、各节点 id 与价，去对总成采购视图 / 重算。无卡仍空格，禁止邻月填空。

排序（汇总后）：零件号 → 第一处供货总成零件号。

## 4. 附件价目表（原件列）

现场主合同附件 **「批量零部件价格协议」** 中间那张表。列表和导出对齐这张表，不另发明列。

和 [anchor-true-up-design.md](anchor-true-up-design.md) **同名文书、不同方向**：那边是对客户的销售协议价；本切片是对二级厂（样张甲方采购方、乙方供应商）。本切片只出这张价目表，不导入签字件、不跑价差。

纸面头尾本期不定：代码、编号、币种、不含税声明、11 条备注、甲乙方签字。先把表体列钉死。

数据源按列填：已定为正式口径，其余仍待填。实例用芜湖 T13J D/09、`551003086AA` 这棵树（§4.2.1）；2026-01 采购视图金额已核对。

### 4.1 表头结构

```text
序号 | 存货编码 | 零件号 | 零件名称 | 单车数量 | 计量单位
   | {年}年{月}月 结算价格 (元) × 窗口内每个自然月
   | 单独支付 Y/N
   | 单件工装分摊金额 (元/件)
   |     ├ 分摊价格 (元)
   |     ├ 工装费 (元)
   |     └ 分摊数量 (件)
   | 备注
```

工装三列共用父表头「单件工装分摊金额 (元/件)」。月列随查询窗口增减，**不是**原件上固定 1～11 月。

### 4.2 列清单

| # | 原件表头 | 形态 | 数据源 |
|---|---------|------|--------|
| 1 | 序号 | 固定 | 有下级采购对象：`{L0.seq_no}-{顺序号}`。`seq_no` 取本行所属供货总成（材料清单「序号」列）；顺序号是该总成下采购对象从 1 起的序号，按导入序 `sort_no`。例：总成序号 5 的第一件 → `5-1`。**退化供货件**（L0 自身即采购对象、没有下级对象）只写 `seq_no`，如 `5`，不要写成 `5-1`。 |
| 2 | 存货编码 | 固定 | 本行节点 `internal_number`（内部号）。不是 L0 内部号。 |
| 3 | 零件号 | 固定 | 本行 `part_number`。汇总键。 |
| 4 | 零件名称 | 固定 | 本行 `part_name`。不是 `l0_part_name`。 |
| 5 | 单车数量 | 固定 | 准备表节点单车用量 **求和**（§3.1）。不是单节点相对父件 `qty`。 |
| 6 | 计量单位 | 固定 | 固定写「件」。不读 `qty_unit`。 |
| 7 | `{年}年{月}月 结算价格 (元)` | 动态，每月一列 | 准备表各节点当月 `should_cost`（采购视图红字「总成本」，=`total_amount`）**去重**后的唯一值。不要树根 `grand_total`，不要年度价 `vendor_quote`。4 位小数。无卡 → 空格。同号不同价 → 拒绝（§3.1），不是空格。 |
| 8 | 单独支付 Y/N | 固定 | 待填 |
| 9 | 分摊价格 (元) | 工装子列 | 待填 |
| 10 | 工装费 (元) | 工装子列 | 待填 |
| 11 | 分摊数量 (件) | 工装子列 | 待填 |
| 12 | 备注 | 固定 | 待填 |

供应商不是表体列：对方写在纸面乙方。本页仍按供应商筛，一家一份附件。

初稿里的对象种类、供货总成、原件行号、供应商列 **不出现在这张表上**，除非后面单独要求加核对列。

### 4.2.1 实例（芜湖 T13J D/09）

材料清单树（只用来认列，L2 不出现在价目表）：

```text
L0  551003086AA  右前门上铰链加强板总成
    内部号 ACA674  seq_no=5  用量 1
    ├─ L1  551003096AA  右前门上铰链加强板     内部号 ACA674001  用量 1
    │      采购对象 · 冲压件 · 烟台海众
    └─ L1  551001137AA  左后门上铰链安装板总成 内部号 ACA333N01  用量 1
           采购对象 · 分总成 · 安徽振华
           ├─ L2  551001133AA  左后门上铰链安装板   （挂在分总成下，不是对象行）
           └─ L2  QR36410      焊接方螺母         （标准件，不进合同包）
```

按已定的 1 / 2 / 4 / 5 / 6 / 7 列。芜湖 T13J、2026-01、供货总成 `551003086AA` 采购视图实数：

| 序号 | 存货编码 | 零件号 | 零件名称 | 单车数量 | 计量单位 | 26年1月 结算价格 (元) |
|------|----------|--------|----------|----------|----------|------------------------|
| 5-1 | ACA674001 | 551003096AA | 右前门上铰链加强板 | 1 | 件 | 5.5250 |
| 5-2 | ACA333N01 | 551001137AA | 左后门上铰链安装板总成 | 1 | 件 | 29.5236 |

此表是 **这一棵树** 上各挂一点、用量各 1 时的准备行；若 `551001137AA` 还挂在别的 L0，准备表继续分行，价目表单车数量把各处连乘用量加总，29.5236 去重后仍写一格。

### 4.3 月列

窗口展开方式见 §2。表头写成 `26年1月 结算价格 (元)` 这种，跨年必须带年。

格 = 汇总后的唯一单价（§3.1）。无卡空格；唯一价照写（含 `0`）。禁止邻月填空、禁止平均。同号不同价直接失败，不写出附件。

## 5. 产品形态

仅查询 + 导出，无计算按钮、无审核。不要塞进总成一览 Tab。

### 5.1 侧栏与页名

挂在一级 **核价** 下，与 **总成核价** 并列，不要塞进总成核价子菜单，不要复用 `menu:assembly-cost`。

| | 定名 |
|--|------|
| 侧栏文案 | **采购价格** |
| 页标题 `pageMeta` | 同文案 |
| Hash / `data-page` | `procurement-contract-report` |
| 位置 | **总成核价** 之后、**自动核价引擎** 之前 |
| 形态 | **单页叶子**（无计算页，禁止再套一层子菜单） |

对照同级：**总成核价** 是分组（计算 + 一览）；本切片只有查询 + 导出，名字按现场怎么叫来取。

不用「采购应成本」：核算词，侧栏不像人话。金额列仍读 `should_cost`，只是不把这个词写进菜单。  
不用「采购报表」：和分组同级偏像一块业务；「报表」把形态锁成导出物。  
不用「采购」当分组：现在只有一页，空套一层。以后真有第二页再拆组。  
不用「采购签约报表」：侧栏偏长，「签约」是用途说明，不是菜单词。  
不用「采购合同」：本系统不出合同条款、不跑状态机。  
不用「采购对象报表」：和焊接工程下的「采购对象清单」撞名。  
不用「采购一览」：总成核价一览已有采购视图。  
不用「外发价格」：清单确认态叫外发，菜单不必再学一遍内部词。  
不挂焊接工程：清单是集合；本页是核价金额横表。  
不和「年度零件价」抢名：那是焊接工程里的年协议报价；本页是核价下按月、按厂给二级厂的价。

对照：总成核价一览的 HUD 密表壳（`stamping-part-cost/list` 同族），强调色页内统一 `#FF1E27`。

筛选条：基地、项目、BOM 版本、开始年月、结束年月、供应商。供应商下拉 = 当前清单上已指定的去重名称（只读聚合，不是主数据）。

HUD：准备行数（节点）、价目行数（零件号）、已指定供应商数、窗口月数、缺月格子数。同号不同价不是 HUD 计数，是错误。

分页：`page` + `size`，`page-size.js`。动态列随窗口变，表 `min-width` 随列数增加。操作列：无行内业务操作（不是确认页）；需要时只保留「详情」链到采购对象或总成卡（可选，一期可没有）。

禁止整行点击。禁止勾选列。

导出 Excel：与列表同一套筛选，**不分页**。一家供应商筛出来即一份附件。第一页价目表（汇总）；可选第二页「准备」（按节点，供对用量和单价）。表头含范围与窗口；`qa_passed=false` 或含未指定须印在标题区。金额 VO 规则：Decimal JSON/Excel 用字符串固定小数位，禁止 `float`。

## 6. API / 分层 / 权限

```text
Router  → Costing 本切片 Service
              ├── 只读 ProcurementObjectRepository（行 + 清单头）
              └── 只读 AssemblyCostRepository（范围 + 年月 + `source_node_id` 批量 IN）
```

禁止 Router 查库；禁止 `prepare/engine/persist`；禁止异步任务。

建议路径（实施时再进 `Perm` / `permission-design.md`）：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/costing/procurement-contract-report` | 分页；Query 含范围与窗口；`page`+`size` |
| GET | `/api/costing/procurement-contract-report/export` | 同筛，Excel |
| GET | `/api/costing/procurement-contract-report/prep` | 可选：当前清单供应商去重、窗口校验、缺月统计 |

列表 VO 是 **汇总后的价目行**（按零件号）。准备表只在 Service 内拼、导出可选带出，不要把每个 `source_node_id` 直接当列表行。

响应：`ApiResponse[PageResult[RowVO]]`。`RowVO` 含固定字段 + `month_amounts: list[MonthAmountVO]`（`year`/`month`/`should_cost`），**不要**把 1～12 写成固定 12 个字段。前端按窗口渲染列。

`PageResult.filters` 可用具名 VO：窗口起止、列清单、`qa_passed`。禁止签名 `dict[str, Any]`。

权限（落地时写入 catalog，本期文档先定名）：

| 码 | 用途 |
|----|------|
| `menu:procurement-contract-report` | 侧栏「采购价格」与路由 |
| `op:procurement-contract-report:view` | 查询 |
| `op:procurement-contract-report:export` | 导出 |

建议挂在核价分组下，与总成核价并列（见 §5.1），不要复用 `menu:assembly-cost`。

目录（落地时）：

```text
app/services/costing/procurement_contract_report/
app/routers/costing/procurement_contract_report.py
app/schemas/dto|vo/procurement_contract_report_*.py
static/js/features/costing/procurement-contract-report/
```

无本切片 Model / 无 Parser。金额 join 走现网 `AssemblyCostRepository` 扩展只读方法，不要在 Service 里 `db.query`。

## 7. 缺数怎么展示

| 情况 | 行为 |
|------|------|
| 无采购对象清单 | 拒绝查询，指向生成页 |
| 有清单但无外发已指定行 | 空表，说明文案 |
| 窗口内部分月未算总成 | 行仍出，缺月空格；HUD 计缺月 |
| 同号同月两个单价 | **错误**：算错或数据不一致。拒绝查询/导出，不去空格、不平均 |
| 总成已算但该对象无卡（清单后未重算） | 该行整段窗口可能全空；提示「请按当前清单重算总成」 |
| BOM 重导 `source_node_id` 失效 | 与总成 P18 相同：必须重生成清单并重算；本报表不猜旧 id |

## 8. 做 / 不做

| 做 | 不做 |
|----|------|
| 导出列对齐现场价目表（§4） | 自造对象种类 / 供货总成列 |
| 起止年月动态列（常用 3～6，上限 12） | 固定全年 12 列当唯一 UI |
| 默认外发且已指定供应商 | 标准件/胶等进合同包 |
| 按供应商筛 + 导出（一家一份） | 合同状态机、电子签、一件多家、导入签字协议 |
