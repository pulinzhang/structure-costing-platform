## 2. 查询范围

必填：

| 键 | 含义 |
|----|------|
| `location` | 采购基地 |
| `vehicle_model` | 项目 |
| `bom_version` | BOM 版本（解析当前 snapshot，与清单相同） |
| `start_year` + `start_month` | 窗口起（含） |
| `end_year` + `end_month` | 窗口止（含） |

可选：`view`（与总成核价一览同一参数名，见 §3 / §5.2）。缺省 = `procurement`。只允许 `procurement` | `assembly`。  
可选：`supplier_name`（**仅** `view=procurement`：精确或规范化后全等，签约附件按一家一导）。`view=assembly` **不要带、也不要筛**：整包只有一家，列表和导出都是该范围全部树根。传入则忽略，不要当成过滤条件。

窗口规则：

- 闭区间，按自然月展开列。例：`2026-01`～`2026-03` → 三列；`2025-11`～`2026-02` → 四列。
- 开始不得晚于结束。
- **列数上限 12**（一次查询）。常用 **3～6** 个月。打开页面默认最近一次核价的单月（基地 / 项目 / 版本 / 年月），不默认当前日历月，也不默认 3 个月窗。
- 禁止固定 1～12 月全年横表当唯一形态。
- 超过 12 个月 → `BusinessException`（400），不要截断 silently。

`view=procurement`：清单未生成 → 404 或业务 400「请先生成采购对象清单」（与 summary 一致，实施时与现网采购对象 summary 对齐）。  
`view=assembly`：**不依赖**采购对象清单。范围仍解析当前 snapshot；无材料清单 → 与焊接工程/总成核价相同，指向先上传 BOM。  
检测 `qa_passed=false`（仅采购对象视图有清单头时）：**允许查、允许导出**，页头标明未通过（与清单导出相同：看见缺口，不假装合格）。

## 3. 视图

查询参数 `view` 二选一，**一份协议只出一种**，禁止同一张表混采购对象行和总成行。

对照总成核价一览的 **财务 / 采购**（`view=finance` | `procurement`）。本页换成 **采购对象 / 总成**，集合认定与一览相同，文案和默认相反：

| `view` | 按钮（左→右） | 对齐一览 | 何时用 | 行从哪来 |
|--------|----------------|----------|--------|----------|
| `procurement`（**默认**） | **采购对象**（左） | 同采购视图 | 拆到冲压件 / 分总成 / 退化供货件签二级厂。例：芜湖 T13J | 清单 `section=object`（§3.0） |
| `assembly` | **总成**（右） | 同财务视图的**树根集合**（`parent_id IS NULL`） | 整包总成、不拆一级件。例：T2AA、T28（§3.2） | snapshot 全部树根（含结构化 L0 与退化） |

按钮文案写「采购对象」「总成」，不要写「财务」「采购」「供货总成」「价目行」「L0」。不要复用一览的「财务（树根）」。不要按项目代号写死（禁止 `if T2AA`）。核对区（标准件/胶等、异常）**两种视图都不进**。

禁止本切片再发明第三套 `view` 码。`assembly` 只表示树根集合，**不要**把一览的 `finance` 抄过来当本页参数（本页不是成品账，按钮也不叫财务）。

### 3.0 采购对象（默认，`view=procurement`）

```text
section = object
该 snapshot 的清单行
```

待定、外发、自制、未指定供应商：**全部列出**。供应商下拉只筛已指定名称；不选即全部。至少有一个一级件带内部号的 L0 成品 **不在本视图**（采购对象列入规则不变，见 [bom-procurement-objects-design.md](../bom/bom-procurement-objects-design.md)）。全部 L1 无内部号的 L0 按退化供货件列入。

### 3.1 准备表 → 汇总（价目表，仅 `view=procurement`）

两步，**不落库**。页面和合同附件只出第二步。不要和查询接口 `/prep`（供应商下拉）混名。总成视图走 §3.2，不要套本节「按采购对象一行」。

**① 准备表（按节点）**

采购对象区内每个采购对象一行。键是 `source_node_id`（=`bom_nodes.id`）。清单表 `id` 再生成会变，不要当键。

每行至少：零件号、零件名称、内部号、供应商、所属供货总成、`seq` 口径序号、**节点单车用量**、窗口内各月 `should_cost`。

节点单车用量 = 从所属 L0 到本节点 `qty` **沿树连乘**（BOM 已约定；不要只抄相对父件的 `1`）。  
月价：总成卡唯一键 `(year, month, location, vehicle_model, bom_version, source_node_id)`，IN 节点 id。无卡填 `/`。

例：`551001137AA` 挂在多棵树上 → 准备表多行，各行自己的用量和单价。

**② 汇总（价目表，按零件号）**

本附件范围内（已按供应商筛）按 **`part_number` 一行**。

| | 规则 |
|--|------|
| 单车数量 | `SUM(节点单车用量)` |
| 月结算价格 | 组内该月 `should_cost` **去重**。同号同月只应有一个单价 |
| 名称 / 存货编码 | 组内一致则写出；不一致仍按第一处（准备表可对） |

同号同月只应有一个单价。出现两个不同 `should_cost`：**算错了或数据不一致**（不是缺月那种正常 `/`）。禁止平均、禁止挑一个、禁止静默 `/` 当缺口。查询和导出都 `BusinessException`（400），文案带零件号、月份、各节点 id 与价，去对总成采购视图 / 重算。无卡填 `/`，禁止邻月填空。

排序（汇总后）：基地 → 项目 → 版本 → 序号（总成 `seq_no`，再组内顺序）。不是按零件号。

### 3.2 总成（`view=assembly`）

现场会把 **整棵供货总成** 交给一家，而不是按采购对象拆签。两种常见原因，**同一视图**，不要做成两个开关：

| 现场 | 为什么 | 协议上是什么 |
|------|--------|----------------|
| T2AA | 普威当地没有基地，**项目整包给青岛**，由青岛给奇瑞 | 价目 = 该项目全部 L0；不筛供应商；乙方现场填青岛侧 |
| T28（现网已有） | 约定 **所有总成发包给一个供应商** | 价目 = 全部 L0；不筛供应商；一份协议 |

不是改采购对象分类：主机厂仍不允许把带内部号一级件的 L0 写入 `section=object`。本切片只换读哪一层核价卡。

**① 准备表（按树根节点）**

每个 snapshot 树根一行。键仍是 `source_node_id`（=`bom_nodes.id`，树根）。

每行至少：零件号、零件名称、内部号（**L0 自己的**）、所属供货总成（=自身）、`seq_no`、**节点单车用量**（树根 `qty`，常见 1，没有上级可乘）、窗口内各月树根卡 `should_cost`。

月价：总成卡唯一键与对象模式相同，IN 的是 **树根** `source_node_id`。读该卡 `should_cost`（=`total_amount`）。无卡填 `/`。

禁止：把该 L0 下对象卡 `should_cost` **加总**当总成价（树根焊接口径与对象卡不同，见总成核价 P21，加总会双计或漏）。禁止改填树根 `grand_total`（I3～I8 是普威侧总账，不进给二级厂的协议单价）。

**② 汇总（价目表，按零件号）**

与 §3.1 相同：单车数量 `SUM`、同号同月单价去重、不一致则 400。**不按供应商过滤、不要求 `supplier_name`。** 整包约定只有一家，列表和导出都是该 snapshot 全部树根，一份协议。供应商不是行字段，也不要从下级对象行猜乙方。签字栏乙方 **留空现场填**（整包对方不在采购对象行上，本页不做供应商下拉来凑）。

排序：基地 → 项目 → 版本 → `seq_no`。退化供货件已在树根里，不要再从对象区拼一行。

## 4. 最终报告 = 样张整份

落地后要交出的，就是现场主合同附件 **「批量零部件价格协议」**，不是另做一张系统表。对照样张 `excel_sample/批量零部件价格协议模板2023V1.A2.xlsx`。

和 [anchor-true-up-design.md](anchor-true-up-design.md) **同名文书、不同方向**：那边是对客户的销售协议价；本切片是对二级厂（样张甲方采购方、乙方供应商）。不导入已签字件、不跑价差。

页面列表只预览中间价目表（便于筛、对金额）。**导出 Excel 必须按样张成文**：文头 + 价目表 + 文尾条款 + 甲乙方签字栏。不要附「准备」Sheet。

整份结构（与样张 Sheet1 一致）：

| 区 | 样张位置 | 本期怎么处理 |
|----|----------|--------------|
| 文头 | 第 1～2 行 | 左上「附件二」只占 A1；标题从 B 列起合并到表尾并居中。第 2 行三格分写：`编号：`（现场填）、`币种：人民币`（盖在结算价列上）、`价格均不含增值税`（盖在工装费组上）。 |
| 价目表 | 第 3 行起表头，其下数据行 | **系统填。** 列见 §4.1 / §4.2。单月与样张同形；跨月只展开「结算价格（元）」列，工装费组与备注右移。 |
| 以下空白 | 表体末 | 有数据则不要这行；空表才写。 |
| 文尾 | 「其他说明 / 备注」 | 条款全文只取系统设置里**已保存**的「采购协议备注」，未保存则不写条款。设置页空框时给出普威样例供改写，「恢复默认」填回该样例；导出不读样例字段。占位符：`{company_name}` 为设置中的公司名称（未填则空）；`{start_year}` `{start_month}` `{end_year}` `{end_month}` `{end_day}` 按查询窗口填（开始月 **1 日** 起至结束月 **最后一天**）。空行分段，每段 Excel 一行。未知 `{xxx}` 原样保留。 |
| 签字 | 甲乙方 / 代表 / 日期 | 甲方只取系统设置「公司名称」，未填则空。**采购对象视图**乙方写本附件供应商名称；**总成视图**乙方留空（整包一家，现场填）。双方代表、日期都空着，现场签。 |
| 页码 | 打印页脚居中 | `第 1/3 页`（Excel `&P/&N`），奇偶页相同。 |

数据源按列填：价目表与工装三列已定口径。无模具/检具数据填 `/`。实例用芜湖 T13J D/09、`551003086AA` 这棵树（§4.2.1）；2026-01 采购视图金额已核对。

### 4.1 表头结构

对照样张：`excel_sample/批量零部件价格协议模板2023V1.A2.xlsx`（Sheet1 第 3～5 行）。那是 **单月** 模板：结算价格只有一列，表头写「结算价格（元）」，不写年月。

```text
单月原件（列位置不随月份移动）

序号 | 存货编码 | 零件号 | 零件名称 | 单车数量 | 计量单位
   | 结算价格（元）                          ← 仅 1 列
   | 工装费
   |     ├ 单独支付 Y/N
   |     └ 单件工装分摊价格（元/件）
   |           ├ 分摊价格（元/件）
   |           ├ 工装费（元）
   |           └ 分摊数量（件）
   | 备注
```

跨月：只把 **「结算价格（元）」这一列** 按查询窗口复制展开，插在「计量单位」和「工装费」之间。工装费整组、备注不按月复制。窗口规则见 §2（闭区间自然月、上限 12）。

```text
窗口 2026-01～2026-03 时（3 列结算价）

序号 | 存货编码 | 零件号 | 零件名称 | 单车数量 | 计量单位
   | 2026年1月 结算价格（元）
   | 2026年2月 结算价格（元）
   | 2026年3月 结算价格（元）
   | 工装费 …（与单月原件相同，列整体右移）
   | 备注
```

表头写法：`{年}年{月}月 结算价格（元）`，可缩年如 `26年1月 结算价格（元）`；跨年必须带年。不是原件上印死的 1～11 月。

### 4.2 列清单

逻辑列 12 项。第 7 项在单月是 1 列，跨月变成窗口月数那么多列，填法相同、只换月份。其余列始终各 1 列。

**固定列（不随窗口增减）**

| # | 原件表头 | 数据源 |
|---|---------|--------|
| 1 | 序号 | **采购对象视图：**有下级采购对象 → `{L0.seq_no}-{顺序号}`。`seq_no` 取本行所属供货总成（材料清单「序号」列）；顺序号是该总成下采购对象从 1 起的序号，按导入序 `sort_no`。例：总成序号 5 的第一件 → `5-1`。**退化供货件**只写 `seq_no`，如 `5`，不要写成 `5-1`。**总成视图：**一律只写树根 `seq_no`（如 `5`），不要 `5-1`。 |
| 2 | 存货编码 | **采购对象视图：**本行节点 `internal_number`（不是 L0 内部号）。**总成视图：**树根 `internal_number`。 |
| 3 | 零件号 | 本行 `part_number`。汇总键。总成视图即 L0 号。 |
| 4 | 零件名称 | 本行 `part_name`。采购对象视图不是 `l0_part_name`；总成视图即 L0 名称。 |
| 5 | 单车数量 | 准备表节点单车用量 **求和**（采购对象 §3.1 / 总成 §3.2）。不是单节点相对父件 `qty`（总成视图树根本身通常已是 1）。导出 Excel 写**整数**（数字格式）。 |
| 6 | 计量单位 | 固定写「件」。不读 `qty_unit`。 |

**结算价格（原件 1 列；跨月展开）**

| # | 原件表头 | 导出 / 列表表头 | 数据源 |
|---|---------|----------------|--------|
| 7 | 结算价格（元） | 单月可仍写「结算价格（元）」；跨月每列 `{年}年{月}月 结算价格（元）` | 准备表各节点**该列对应月**的 `should_cost`（=`total_amount`）**去重**后的唯一值。采购对象视图 = 采购视图对象卡；总成视图 = **树根卡**（一览财务那张），列仍叫应成本，**不要** `grand_total`，不要年度价 `vendor_quote`，不要对象卡加总。列表与导出同一套 **四舍五入到分**；**导出 Excel 写数字**（不是文本），单价显示 **2 位小数**（`0.00`）。无卡 → `/`。同号不同价 → 拒绝（§3.1 / §3.2），不是 `/`。 |

**工装费组（父表头「工装费」，始终跟在全部结算价列后面，不按月复制）**

只给 **直接采购的冲压件**（清单 `object_kind = l1_stamping`，且 `view=procurement`）填模具/检具。**分总成**（`l1_subassembly`）、退化供货件、**总成视图全部行**、其它种类：工装三列填 **`/`**，不要从下级冲压件往上加总。

模具费、检具费都是 **按年**，不是按月。工装列不随结算价展开。窗口落在同一自然年 → 用该年账；窗口跨两个自然年 → 仍只一格，取 **`start_year`**，禁止把两年相加或按月加权。不要把本列加进第 7 列结算价（结算价仍只 `should_cost`）。无存档的格子填 **`/`**，不要空格、不要写 `0`。

| # | 层级 | 原件表头 | 数据源 |
|---|------|---------|--------|
| 8 | 工装费 → | 单独支付 Y/N | 固定填 `N` |
| 9 | 工装费 → 单件工装分摊价格（元/件） → | 分摊价格（元/件） | 冲压件：该年 **单件模具费 + 单件检具费**。无数据 → `/`。导出 Excel：数字、单价 **2 位小数**。 |
| 10 | 同上 | 工装费（元） | 冲压件：**模具合计金额 + 检具合计金额**（不是单件）。模具合计 = `final_die_fee × 分摊数量(件)`；检具合计 = 档案 `gauge_fee`（万元）× 10000。无数据 → `/`。导出 Excel：**整数**，千分位 `#,##0`。 |
| 11 | 同上 | 分摊数量（件） | 冲压件：只取 **模具** `stamping_die_fees.allocation_qty`。库内存万件，写出时 × 10000 成件。不取检具档案分摊。无模具行 → `/`。导出 Excel：**整数**。 |

**第 9～11 列怎么折（只 `l1_stamping`）**

| 加项 | 读哪 | 折算 |
|------|------|------|
| 单件模具费 | 只读 `stamping_die_fees`：`(year, location, vehicle_model, part_number)` → `final_die_fee`。已是元/件。无该年行 → 该项按没有。 | 直接用 |
| 模具分摊数量 | 同行 `allocation_qty`（万件） | × 10000 → 件 |
| 单件检具费 | 只读 `stamping_gauge_fees`：`(location, vehicle_model, part_number)` 且 `status = effective`。档案万元 + 分摊万台，没有年。 | `gauge_fee / allocation_qty`（万元 ÷ 万台 = 元/件） |
| 检具合计金额 | 同上 `gauge_fee` | × 10000 → 元 |

第 9 列相加后导出 2 位小数。两项都没有 → `/`。有一项没一项 → 只写有的那项。禁止从下级叶子滚到分总成。禁止读零件核价 `unit_cost` 再拆模具。

**尾列**

| # | 原件表头 | 数据源 |
|---|---------|--------|
| 12 | 备注 | 待填 |

供应商不是表体列：对方写在纸面乙方。**采购对象视图**按供应商筛，一家一份附件。**总成视图**不筛，整范围一份。

初稿里的对象种类、供货总成、原件行号、供应商列 **不出现在这张表上**，除非后面单独要求加核对列。

## 5. 产品形态

仅查询 + 导出，无计算按钮、无审核。不要塞进总成一览 Tab。

### 5.1 侧栏与页名

挂在一级 **核价** 下，与 **总成核价** 并列，不要塞进总成核价子菜单，不要复用 `menu:assembly-cost`。

| | 定名 |
|--|------|
| 侧栏文案 | **采购价格** |
| 页标题 `pageMeta` | 同文案 |
| Hash / `data-page` | `procurement-contract-report` |
| 位置 | **总成核价** 之后、**自动核价引擎** 之前 |
| 形态 | **单页叶子**（无计算页，禁止再套一层子菜单） |

对照同级：**总成核价** 是分组（计算 + 一览）；本切片只有查询 + 导出，名字按现场怎么叫来取。

不用「采购应成本」：核算词，侧栏不像人话。金额列仍读 `should_cost`，只是不把这个词写进菜单。  
不用「采购报表」：和分组同级偏像一块业务；「报表」把形态锁成导出物。  
不用「采购」当分组：现在只有一页，空套一层。以后真有第二页再拆组。  
不用「采购签约报表」：侧栏偏长，「签约」是用途说明，不是菜单词。  
不用「采购合同」：本系统不出合同条款、不跑状态机。  
不用「采购对象报表」：和焊接工程下的「采购对象清单」撞名。  
不用「采购一览」：总成核价一览已有采购视图。  
不用「外发价格」：清单确认态叫外发，菜单不必再学一遍内部词。  
不挂焊接工程：清单是集合；本页是核价金额横表。  
不和「年度零件价」抢名：那是焊接工程里的年协议报价；本页是核价下按月、按厂给二级厂的价。

对照：总成核价一览的 HUD 密表壳（`stamping-part-cost/list` 同族），强调色页内统一 `#FF1E27`。

筛选条：与总成核价一览同壳。默认只露战术胶囊（窗口 / 基地 / 项目 / **供应商**）+ **展开高级筛选** + 查询；下拉收在折叠面板里，禁止一排 ERP 表单常开。选完下拉即刷新列表。供应商下拉 = 当前清单上已指定的去重名称（只读聚合，不是主数据），**仅采购对象视图显示**。切到总成：藏掉供应商胶囊，清空已选 `supplier_name`，不要灰置仍占位。**不要**把视图做成筛选胶囊。

## 6. API / 分层 / 权限

```text
Router  → Costing 本切片 Service
              ├── 只读 ProcurementObjectRepository（采购对象视图：行 + 清单头）
              ├── 只读 BOM 树根（总成视图：`parent_id IS NULL`；与一览财务视图同一认定）
              ├── 只读 AssemblyCostRepository（范围 + 年月 + `source_node_id` 批量 IN）
              ├── 只读 StampingDieFeeRepository（年 + 基地 + 项目 + 零件号 → `final_die_fee`；仅采购对象视图冲压件）
              └── 只读 StampingGaugeFeeRepository（基地 + 项目 + 零件号 → 生效检具档；同上）
```

禁止 Router 查库；禁止 `prepare/engine/persist`；禁止异步任务。禁止在本切片重算模具布点公式或改检具档案。

建议路径（实施时再进 `Perm` / `permission-design.md`）：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/costing/procurement-contract-report` | 分页；Query 含范围、窗口、`view`；`page`+`size` |
| GET | `/api/costing/procurement-contract-report/export` | 同筛，Excel；`view=assembly` 忽略 `supplier_name` |
| GET | `/api/costing/procurement-contract-report/prep` | 可选：当前清单供应商去重、窗口校验、缺月统计 |

列表 VO 是 **汇总后的价目行**（按零件号）。`view` 决定准备表从清单对象还是树根拼。准备表只在 Service 内拼，不要导出，也不要把每个 `source_node_id` 直接当列表行。禁止 costing 再实现 `object_kind` 分类器；树根用 BOM `parent_id IS NULL`，与一览财务视图同一认定。

响应：`ApiResponse[PageResult[RowVO]]`。`RowVO` 含固定字段 + `month_amounts: list[MonthAmountVO]`（`year`/`month`/`should_cost`），**不要**把 1～12 写成固定 12 个字段。前端按窗口渲染列。

`PageResult.filters` 可用具名 VO：窗口起止、列清单、`qa_passed`、`view`。禁止签名 `dict[str, Any]`。

## 7. 缺数怎么展示

| 情况 | 行为 |
|------|------|
| 无采购对象清单 | **采购对象视图**拒绝查询，指向生成页。**总成视图**不因此拒绝 |
| 无材料清单 / 无 snapshot | 两种视图都拒绝，指向焊接工程上传 |
| 有清单但无外发已指定行 | 采购对象视图：空表，说明文案。总成视图：仍出全部树根 |
| 窗口内部分月未算总成 | 行仍出，缺月填 `/`；HUD 计缺月 |
| 同号同月两个单价 | **错误**：算错或数据不一致。拒绝查询/导出，不填 `/`、不平均 |
| 总成已算但该对象无卡（清单后未重算） | 采购对象视图：该行整段窗口可能全 `/`；提示「请按当前清单重算总成」 |
| 总成视图无树根卡 | 该总成缺月 `/`；提示走总成核价一览的财务（树根）算当月，不要去凑对象卡 |
| BOM 重导 `source_node_id` 失效 | 与总成 P18 相同：采购对象视图须重生成清单并重算；总成视图须重算树根卡；本报表不猜旧 id |
| `view=assembly` 带了 `supplier_name` | 忽略，不要过滤、不要 400 |
