# 采购价格 — 设计说明

> **状态：采购对象 / 总成视图已落地。** 只读查询 + 导出，**不算价、不落结果表**。

> 切片：**`costing`**（下游组合）。  
> 集合与供应商：[bom-procurement-objects-design.md](../bom/bom-procurement-objects-design.md)、[bom-procurement-object-supplier-design.md](../bom/bom-procurement-object-supplier-design.md)。  
> 树根有效期 / **爬到树根**：[bom-process-die-effective-period-design.md](../engineering-change/design-change/bom-process-die-effective-period-design.md)；`nodes_in_as_of_trees`：[period_trees](../../app/repositories/bom/period_trees.py)；总成取件同形：[assembly-costing-design.md](assembly-costing-design.md)。设变：[part-number-revision-design.md](../engineering-change/design-change/part-number-revision-design.md)。  
> 金额：采购对象抄一览采购视图 **总成本**（`total_amount`）；总成抄一览财务视图 **总费用**（`grand_total`）。  
> 硬约束：[architecture.md](../architecture.md)。评审已否决第二套委外核价表（P16）；本文不是那张表。

**产品底线：这是指挥舱，不是 ERP。** 打开即定稿；噪点能隐则隐（供应商缩写徽章 / 锁定后藏列）；舞台只留一个执行键（导出协议）。细则见 `.cursor/rules/command-cockpit.mdc`。

## 0.1 铁律：账期月只认所属 L0 树根（爬到树根）

与采购对象清单 §14、有效期设计（**爬到树根**）、总成核价取件、`nodes_in_as_of_trees` **同一把钥匙**。禁止本切片另发明第二套过滤。

| 写死 | 禁止 |
|------|------|
| **取件范围 = 基地 + 项目 + 账期窗口月**；行从命中 L0 树来 | 用 `bom_version` 解析 snapshot 定范围；`get_by_unique_key(基地,项目,版本)` 当取件 WHERE |
| **对象问期 / 问版本浏览：先爬到所属 L0**，再读树根四列或 **L0.bom_version** | 用对象行 / L1 / L2 / source 本行 / 核价卡上的版本字当浏览筛 |
| **命中 L0 → 收整棵子树**（`nodes_in_as_of_trees` / `collect_root_subtrees`）；子孙本行生失效不再筛 | 用 L1/L2 本行四列筛半棵树 |
| 总成视图：树根本身就是 L0，直接问树根四列 | 从下级对象行、分总成、二级件反推「这月交不交」 |
| 设变后旧总成到期、新总成启用：某月只出该月命中的那一棵 | 把 AA / AB 两棵并进同一账期月（例：2025-05 同时出 `710AA-1` 与 `710AB-1`） |
| **导出协议必须「全部版本」**（`bom_version` 空） | 导出时带 `EC-202505` / `D/09` 等具体版本字 |
| 列表可选版本浏览 = 只认 **爬到的 L0.bom_version** | 用 snapshot 头 / 清单头 / source 本行字当浏览真相 |

对象行 **不落** 生失效（跟清单同一纪律）。列表页可以是档案、默认含已过期；**本页是签约账，不是档案**——查询窗口里的 **每一个自然月** 都按该月命中 L0 收行。跨月窗口：某行所属 L0 未命中的月，该月结算价格填 `/`（该月不交货），不要用邻月或旧号填空。

工程变更 **不抄** 总成核价卡；新树要价 → 对该月重算总成。本切片只读卡，不在设变导入里搬金额。

## 2. 查询范围

必填：

| 键 | 含义 |
|----|------|
| `location` | 采购基地 |
| `vehicle_model` | 项目 |
| `start_year` + `start_month` | 窗口起（含） |
| `end_year` + `end_month` | 窗口止（含） |

**不要**必填 `bom_version`。范围键与总成核价同形：基地 + 项目 + 账期月，**不要 BOM 版本、不要指定 snapshot**。

可选：`view`（见 §3 / §5.2）。缺省 = `procurement`。只允许 `procurement` | `assembly`。  
可选：`supplier_name`（**仅** `view=procurement`：精确或规范化后全等，签约附件按一家一导）。`view=assembly` **不要带、也不要筛**：整包只有一家，列表和导出都是该范围 **账期命中** 的树根（§0.1）。传入则忽略，不要当成过滤条件。  
可选：`bom_version`（**仅列表浏览**）：空 = 「全部版本」。有值时：**先爬到所属 L0**，只认 **`L0.bom_version` 字**（与[采购对象清单](../bom/bom-procurement-objects-design.md) §0.1 同形）。**不是** snapshot 键、不是清单头键、不是 source 本行字、也不改取件 WHERE（仍按基地+项目+账期月收树）。  
**导出协议：`bom_version` 必须空。** 带任一具体版本 → `BusinessException`（400），文案「导出协议须选全部版本」。

取件（复用现成，禁止另写）：

```text
list_by_location_vehicle(基地, 项目)     ← 全节点，不按 snapshot / 不按版本字定 WHERE
  → 每个窗口月：nodes_in_as_of_trees     ← 只认 L0 命中，再收下子树
  → 采购对象：list_objects_by_location_vehicle → source 爬到 L0 → 该月命中才进该月格
       （若带了浏览版本：L0.bom_version 必须等于该字，否则整行不出）
  → 总成视图：命中树根一行（浏览版本同：只认该 L0 字）
```

同月可并存多个 **树根** 版本字（SOP 期树上的 `D/09` 与设变树上的 `EC-202505`）。金额按 `source_node_id` 读卡；**读卡不要再带 `bom_version` 过滤**（卡 UNIQUE 已不含版本；浏览筛已在行集合上按 L0 裁完）。

窗口规则：

- 闭区间，按自然月展开列。例：`2026-01`～`2026-03` → 三列；`2025-11`～`2026-02` → 四列。
- 开始不得晚于结束。
- **列数上限 12**（一次查询）。常用 **3～6** 个月。打开页面默认最近一次核价的单月（基地 / 项目 / 年月），版本默认 **全部版本**；不默认当前日历月，也不默认 3 个月窗。
- 禁止固定 1～12 月全年横表当唯一形态。
- 超过 12 个月 → `BusinessException`（400），不要截断 silently。
- **每个月列的行集合按 §0.1 裁：** 所属 L0 在该月命中才出该月金额；未命中 → `/`。价目表行：窗口内 **至少有一个月** 所属 L0 命中才保留；整窗都不命中的行（含已到期旧树）不出。

`view=procurement`：该基地+项目下尚无任一采购对象清单 → 404 或业务 400「请先生成采购对象清单」。有清单但窗口无命中树 → 空表。  
`view=assembly`：**不依赖**采购对象清单。该基地+项目窗口无命中 L0 → 空表；无任何 BOM 树 → 指向先上传材料清单。  
检测 `qa_passed=false`（范围内任一清单头）：**允许查、允许导出**，页头标明未通过（看见缺口，不假装合格）。

### 2.1 实施要点（复用，不新造）

| 能力 | 现成入口 | 协议怎么用 |
|------|----------|------------|
| 爬到树根 | 有效期设计用语；本切片 `l0_node_of`（沿 `parent_id` 上溯） | 对象问期、**版本浏览**只认爬到的 L0；爬不到 → 该行不进 |
| 命中 L0 收子树 | `nodes_in_as_of_trees` / `BomNodeRepository.list_as_of_trees` | 窗口每月（或合并）对基地+项目节点集跑 as_of |
| 按基地+项目收节点 / 对象 | `list_by_location_vehicle` / `list_objects_by_location_vehicle` | 取代「按 snapshot 找唯一清单头」 |
| 裁格 | `assemble.build_prep_rows` / `build_assembly_prep_rows`（已按 L0 `is_in_period`） | 整窗不命中不出行；未命中月 `/`（即使旧卡还在） |

## 3. 视图

查询参数 `view` 二选一，**一份协议只出一种**，禁止同一张表混采购对象行和总成行。

对照总成核价一览的 **财务 / 采购**（`view=finance` | `procurement`）。本页换成 **采购对象 / 总成**，集合认定与一览相同，文案和默认相反：

| `view` | 按钮（左→右） | 对齐一览 | 何时用 | 行从哪来 |
|--------|----------------|----------|--------|----------|
| `procurement`（**默认**） | **采购对象**（左） | 同采购视图 | 拆到冲压件 / 分总成 / 退化供货件签二级厂。例：芜湖 T13J | 基地+项目 object 行 → **爬到 L0** → 窗口月命中裁（§0.1 / §3.0） |
| `assembly` | **总成**（右） | 同财务视图的**树根集合**（`level=0`） | 整包总成、不拆一级件。例：T2AA、T28（§3.2） | `nodes_in_as_of_trees` 命中的树根（含结构化 L0 与退化） |

按钮文案写「采购对象」「总成」，不要写「财务」「采购」「供货总成」「价目行」「L0」。不要复用一览的「财务（树根）」。不要按项目代号写死（禁止 `if T2AA`）。核对区（标准件/胶等、异常）**两种视图都不进**。

禁止本切片再发明第三套 `view` 码。`assembly` 只表示树根集合，**不要**把一览的 `finance` 抄过来当本页参数（本页不是成品账，按钮也不叫财务）。

### 3.0 采购对象（默认，`view=procurement`）

```text
list_objects_by_location_vehicle(基地, 项目) · section=object
→ source 爬到所属 L0
→ 查询窗口每个自然月：该 L0 period_hit 才进该月准备格
```

待定、外发、自制、未指定供应商：在 **命中树** 内全部列出（不是把清单档案里已到期旧树一并签字）。供应商下拉只筛已指定名称；不选即全部。至少有一个一级件带内部号的 L0 成品 **不在本视图**（采购对象列入规则不变，见 [bom-procurement-objects-design.md](../bom/bom-procurement-objects-design.md)）。全部 L1 无内部号的 L0 按退化供货件列入。

例（芜湖 T13J 二级改图，窗口仅 2025-05、全部版本）：只出 `502007710AB-1`（爬到 L0=`502007390AB` 5 月命中）；**不出** `502007710AA-1`（爬到 L0=`502007390AA` 已到期到 4 月）。禁止拿分总成 `710*` 自己的四列、更禁止拿二级 `710AB` 的四列来裁。

### 3.1 准备表 → 汇总（价目表，仅 `view=procurement`）

两步，**不落库**。页面和合同附件只出第二步。不要和查询接口 `/prep`（供应商下拉）混名。总成视图走 §3.2，不要套本节「按采购对象一行」。

**① 准备表（按节点）**

采购对象区内、**所属 L0 在窗口内至少命中一个月** 的每个采购对象一行。键是 `source_node_id`（=`bom_nodes.id`）。清单表 `id` 再生成会变，不要当键。整窗都不命中的旧树对象行 **不出**。

每行至少：零件号、零件名称、内部号、供应商、所属供货总成、`seq` 口径序号、**节点单车用量**、窗口内各月 `total_amount`（一览采购视图「总成本」；该月所属 L0 未命中则 `/`）。

节点单车用量 = 从所属 L0 到本节点 `qty` **沿树连乘**（BOM 已约定；不要只抄相对父件的 `1`）。  
月价：总成卡唯一键 `(year, month, location, vehicle_model, source_node_id)`，IN 节点 id（**不要**再按 `bom_version` 滤卡）。无卡填 `/`。命中与否 **只问爬到的 L0 四列**，不问本节点。

例：`551001137AA` 挂在多棵树上 → 准备表多行，各行自己的用量和单价；某月某棵树 L0 已到期则该行该月 `/`。

**② 汇总（价目表，按零件号）**

本附件范围内（已按供应商筛）按 **`part_number` 一行**。

| | 规则 |
|--|------|
| 单车数量 | `SUM(节点单车用量)` |
| 月结算价格 | 组内该月 `total_amount` **去重**。同号同月只应有一个单价 |
| 名称 / 存货编码 | 组内一致则写出；不一致仍按第一处（准备表可对） |

同号同月只应有一个单价。出现两个不同 `total_amount`：**算错了或数据不一致**（不是缺月那种正常 `/`）。禁止平均、禁止挑一个、禁止静默 `/` 当缺口。查询和导出都 `BusinessException`（400），文案带零件号、月份、各节点 id 与价，去对总成采购视图 / 重算。无卡填 `/`，禁止邻月填空。

排序（汇总后）：基地 → 项目 → 序号（总成 `seq_no`，再组内顺序）。不是按零件号；**不要**再按版本字当主排序键。

### 3.2 总成（`view=assembly`）

现场会把 **整棵供货总成** 交给一家，而不是按采购对象拆签。两种常见原因，**同一视图**，不要做成两个开关：

| 现场 | 为什么 | 协议上是什么 |
|------|--------|----------------|
| T2AA | 普威当地没有基地，**项目整包给青岛**，由青岛给奇瑞 | 价目 = 该项目 **账期命中** 的全部 L0；不筛供应商；乙方现场填青岛侧 |
| T28（现网已有） | 约定 **所有总成发包给一个供应商** | 价目 = **账期命中** 的全部 L0；不筛供应商；一份协议 |

不是改采购对象分类：主机厂仍不允许把带内部号一级件的 L0 写入 `section=object`。本切片只换读哪一层核价卡。

**① 准备表（按树根节点）**

每个 **窗口内至少命中一个月** 的树根一行。键仍是 `source_node_id`（=`bom_nodes.id`，树根）。**禁止**把整窗都不命中的旧 L0 排进准备表（与 snapshot 全量树根无关）。

每行至少：零件号、零件名称、内部号（**L0 自己的**）、所属供货总成（=自身）、`seq_no`、**节点单车用量**（树根 `qty`，常见 1，没有上级可乘）、窗口内各月树根卡 `grand_total`（该月树根未命中则 `/`）。

月价：总成卡唯一键与对象模式相同，IN 的是 **树根** `source_node_id`（**不要**再按 `bom_version` 滤卡）。读该卡 `grand_total`（一览财务视图「总费用」= 月总账 + 间接）。无卡填 `/`。

禁止：把该 L0 下对象卡金额 **加总**当总成价（树根焊接口径与对象卡不同，见总成核价 P21，加总会双计或漏）。禁止改填树根 `total_amount` / `should_cost` 当总成协议单价（那是采购视图「总成本」，不含间接）。

**② 汇总（价目表，按零件号）**

与 §3.1 相同：单车数量 `SUM`、同号同月单价去重、不一致则 400。**不按供应商过滤、不要求 `supplier_name`。** 整包约定只有一家，列表和导出都是该范围 **账期命中** 的树根，一份协议。供应商不是行字段，也不要从下级对象行猜乙方。签字栏乙方 **留空现场填**（整包对方不在采购对象行上，本页不做供应商下拉来凑）。

排序：基地 → 项目 → `seq_no`。退化供货件已在树根里，不要再从对象区拼一行。

### 4.2 列清单

逻辑列 12 项。第 7 项在单月是 1 列，跨月变成窗口月数那么多列，填法相同、只换月份。其余列始终各 1 列。

**固定列（不随窗口增减）**

| # | 原件表头 | 数据源 |
|---|---------|--------|
| 1 | 序号 | **采购对象视图：**有下级采购对象 → `{L0.seq_no}-{顺序号}`。`seq_no` 取本行所属供货总成（材料清单「序号」列）；顺序号是该总成下采购对象从 1 起的序号，按导入序 `sort_no`。例：总成序号 5 的第一件 → `5-1`。**退化供货件**只写 `seq_no`，如 `5`，不要写成 `5-1`。**总成视图：**一律只写树根 `seq_no`（如 `5`），不要 `5-1`。 |
| 2 | 存货编码 | **采购对象视图：**本行节点 `internal_number`（不是 L0 内部号）。**总成视图：**树根 `internal_number`。 |
| 3 | 零件号 | 本行 `part_number`。汇总键。总成视图即 L0 号。 |
| 4 | 零件名称 | 本行 `part_name`。采购对象视图不是 `l0_part_name`；总成视图即 L0 名称。 |
| 5 | 单车数量 | 准备表节点单车用量 **求和**（采购对象 §3.1 / 总成 §3.2）。不是单节点相对父件 `qty`（总成视图树根本身通常已是 1）。导出 Excel 写**整数**（数字格式）。 |
| 6 | 计量单位 | 固定写「件」。不读 `qty_unit`。 |

**结算价格（原件 1 列；跨月展开）**

| # | 原件表头 | 导出 / 列表表头 | 数据源 |
|---|---------|----------------|--------|
| 7 | 结算价格（元） | 单月可仍写「结算价格（元）」；跨月每列 `{年}年{月}月 结算价格（元）` | 准备表各节点**该列对应月**金额 **去重**后的唯一值。采购对象视图 = 一览采购视图对象卡 **总成本** `total_amount`；总成视图 = 一览财务视图树根卡 **总费用** `grand_total`。不要年度价 `vendor_quote`，不要对象卡加总。列表与导出同一套 **四舍五入到分**；**导出 Excel 写数字**（不是文本），单价显示 **2 位小数**（`0.00`）。无卡 → `/`。同号不同价 → 拒绝（§3.1 / §3.2），不是 `/`。 |

**工装费组（父表头「工装费」，始终跟在全部结算价列后面，不按月复制）**

只给 **直接采购的冲压件**（清单 `object_kind = l1_stamping`，且 `view=procurement`）填模具/检具。**分总成**（`l1_subassembly`）、退化供货件、**总成视图全部行**、其它种类：工装三列填 **`/`**，不要从下级冲压件往上加总。

模具费、检具费都是 **按年**，不是按月。工装列不随结算价展开。窗口落在同一自然年 → 用该年账；窗口跨两个自然年 → 仍只一格，取 **`start_year`**，禁止把两年相加或按月加权。不要把本列加进第 7 列结算价。无存档的格子填 **`/`**，不要空格、不要写 `0`。

| # | 层级 | 原件表头 | 数据源 |
|---|------|---------|--------|
| 8 | 工装费 → | 单独支付 Y/N | 固定填 `N` |
| 9 | 工装费 → 单件工装分摊价格（元/件） → | 分摊价格（元/件） | 冲压件：该年 **单件模具费 + 单件检具费**。无数据 → `/`。导出 Excel：数字、单价 **2 位小数**。 |
| 10 | 同上 | 工装费（元） | 冲压件：**模具合计金额 + 检具合计金额**（不是单件）。模具合计 = `final_die_fee × 分摊数量(件)`；检具合计 = 档案 `gauge_fee`（万元）× 10000。无数据 → `/`。导出 Excel：**整数**，千分位 `#,##0`。 |
| 11 | 同上 | 分摊数量（件） | 冲压件：只取 **模具** `stamping_die_fees.allocation_qty`。库内存万件，写出时 × 10000 成件。不取检具档案分摊。无模具行 → `/`。导出 Excel：**整数**。 |

**第 9～11 列怎么折（只 `l1_stamping`）**

| 加项 | 读哪 | 折算 |
|------|------|------|
| 单件模具费 | 只读 `stamping_die_fees`：`(year, location, vehicle_model, part_number)` → `final_die_fee`。已是元/件。无该年行 → 该项按没有。 | 直接用 |
| 模具分摊数量 | 同行 `allocation_qty`（万件） | × 10000 → 件 |
| 单件检具费 | 只读 `stamping_gauge_fees`：`(location, vehicle_model, part_number)` 且 `status = effective`。档案万元 + 分摊万台，没有年。 | `gauge_fee / allocation_qty`（万元 ÷ 万台 = 元/件） |
| 检具合计金额 | 同上 `gauge_fee` | × 10000 → 元 |

第 9 列相加后导出 2 位小数。两项都没有 → `/`。有一项没一项 → 只写有的那项。禁止从下级叶子滚到分总成。禁止读零件核价 `unit_cost` 再拆模具。

**尾列**

| # | 原件表头 | 数据源 |
|---|---------|--------|
| 12 | 备注 | 待填 |

供应商不是表体列：对方写在纸面乙方。**采购对象视图**按供应商筛，一家一份附件。**总成视图**不筛，整范围一份。

初稿里的对象种类、供货总成、原件行号、供应商列 **不出现在这张表上**，除非后面单独要求加核对列。

仅查询 + 导出，无计算按钮、无审核。不要塞进总成一览 Tab。

### 5.1 侧栏与页名

挂在侧栏 **一级叶子**（与「核价」「文件溯源」同级），插在核价分组之后、文件溯源之前。不要挂进核价子菜单，不要空套「采购」分组，不要塞进总成核价子菜单，不要复用 `menu:assembly-cost`。Hash / 权限码不变。授权树 `catalog.json` 同样挂在 `menu:costing` **之外**，勾选「核价」全选不再带上本页。

| | 定名 |
|--|------|
| 侧栏文案 | **采购价格协议** |
| 页标题 `pageMeta` | 同文案 |
| Hash / `data-page` | `procurement-contract-report` |
| 位置 | **核价** 之后、**文件溯源** 之前 |
| 形态 | **一级单页叶子**（无计算页，禁止再套一层子菜单） |

| GET | `/api/costing/procurement-contract-report/prep` | 可选：供应商去重、窗口校验、缺月统计 |

列表 VO 是 **汇总后的价目行**（按零件号）。`view` 决定准备表从对象还是树根拼。准备表只在 Service 内拼，不要导出，也不要把每个 `source_node_id` 直接当列表行。禁止 costing 再实现 `object_kind` 分类器；树根用 `level=0` / `nodes_in_as_of_trees`，与总成核价同一认定。

响应：`ApiResponse[PageResult[RowVO]]`。`RowVO` 含固定字段 + `month_amounts: list[MonthAmountVO]`（`year`/`month`/`should_cost`），**不要**把 1～12 写成固定 12 个字段。前端按窗口渲染列。

`PageResult.filters` 可用具名 VO：窗口起止、列清单、`qa_passed`、`view`。禁止签名 `dict[str, Any]`。

## 7. 缺数怎么展示

| 情况 | 行为 |
|------|------|
| 无采购对象清单（该基地+项目） | **采购对象视图**拒绝查询，指向生成页。**总成视图**不因此拒绝 |
| 该基地+项目无任何 BOM 树 | 两种视图都拒绝或空表，指向焊接工程上传 |
| 有清单但窗口无命中 L0 | 空表；不要报「无 snapshot」 |
| 有清单但无外发已指定行 | 采购对象视图：空表，说明文案。总成视图：仍出 **账期命中** 树根 |
| 窗口内部分月未算总成 | 行仍出（L0 命中的月），缺月填 `/`；HUD 计缺月 |
| 所属 L0 该月未命中 | 该月格子 `/`；整窗都不命中 → 行不出（§0.1） |
| 设变新旧号同窗 | 各月只认当月命中的 L0；禁止 AA/AB 并进同一月列 |
| 同号同月两个单价 | **错误**：算错或数据不一致。拒绝查询/导出，不填 `/`、不平均 |
| 总成已算但该对象无卡（清单后未重算 / 设变后未重算） | 采购对象视图：命中月仍可能 `/`；提示「请按当前清单重算总成」。工程变更不抄卡 |
| 总成视图无树根卡 | 该总成缺月 `/`；提示走总成核价一览的财务（树根）算当月，不要去凑对象卡 |
| BOM 重导 `source_node_id` 失效 | 与总成 P18 相同：须重算树根/对象卡；本报表不猜旧 id |
| `view=assembly` 带了 `supplier_name` | 忽略，不要过滤、不要 400 |
| **导出带了具体 `bom_version`** | **400**：导出协议须选全部版本 |

## 8. 做 / 不做

| 做 | 不做 |
|----|------|
| 导出成样张《批量零部件价格协议》整份（§4） | 只导出一张系统宽表、丢掉文头文尾 |
| 价目表列对齐原件；跨月只展开结算价列 | 自造对象种类列；把「总成」做成价目表体列（那是 HUD 视图开关） |
| 起止年月动态列（常用 3～6，上限 12） | 固定全年 12 列当唯一 UI |
| HUD 双按钮「采购对象 / 总成」，左采购对象、默认采购对象 | 做成筛选胶囊；按钮写成「财务 / 采购」；默认总成；抄一览的 `view=finance` |
| 取件：基地+项目 + `nodes_in_as_of_trees`；对象 **爬到树根**；版本浏览只认 L0 字 | 用 snapshot / 必填 `bom_version` 定范围；用 source/卡上版本字当浏览；另造第二套过滤 |
| 采购对象视图：命中树上的对象区全部列出（待定/外发/自制） | 核对区进合同包；把清单档案里已到期旧树一并签字 |
| **每个账期月只认所属 L0 生失效**（§0.1） | 用 L1 / L2 / 对象节点自身四列裁行；AA/AB 并进同一月 |
| 总成视图：账期命中树根，读树根卡 `grand_total`（总费用） | snapshot 全量树根；把结构化 L0 写入采购对象清单；按 T2AA/T28 写死分支；对象价加总；改填树根 `total_amount` |
| **导出必须全部版本** | 导出带 `EC-202505` / `D/09` 等具体版本；按版本字拆多份协议当默认 |
| 采购对象：按供应商筛 + 导出（一家一份） | 总成视图再做供应商下拉 / 必填乙方 / 按厂拆文件；合同状态机、电子签、一件多家、导入已签字协议；设变导入抄总成卡 |
