# 批量零部件价格协议与价差结算 — 设计说明

> 状态：**已否决（不做）**  
> 决定：2026-09-23。不建对客户的价格协议、销售发票、价差结算。核价仍按现网月账。  
> 下文是否决前的方案，仅作存档。若再有人提「协议价和核价对差额」，先读本节，不要按下文建表。  
> 对二级厂导出《批量零部件价格协议》是另一篇，已经落地，见 [采购价格协议](procurement-contract-report-design.md)。不要跟着本文一起停。

这不是主合同管理。主合同条款多、不进本系统。本系统只管主合同的附件：**批量零部件价格协议**（零件价目）。现场口头或叫「锚点价」，对外和系统里称 **协议价**。

---

## 1. 业务员先看这个

导入「批量零部件价格协议」时，**PDF 与 Excel 必须成对提交**：PDF 是签字件，Excel 是价目，缺一不可。头上要有：协议编号、基地、项目、甲方、乙方、**执行有效期**（价格有效开始时间、价格有效结束时间，闭区间）。

核价按政策算，算多少是多少，不当协议来改。发票是实际送了多少。政策往往第二年 7 月才定死，那时三样放在一起比：

**价差金额 =（核价单价 − 协议单价）× 开票数量**

| 业务上叫什么 | 干什么 |
|--------------|--------|
| **批量零部件价格协议** | 主合同附件上的零件价目。导入后可查、可锁定 |
| **发票** | 执行有效期内实际送了多少、开了多少钱 |
| **核价** | 按政策算出的应结单价，拿来和协议价比 |

```text
同时上传协议 PDF + 价目 Excel → 生成价格协议
        ↓
按协议价送货、开票  →  导入该期销售发票
        ↓
政策定了，系统核价审核通过
        ↓
出面：协议价 vs 核价，× 开票数量
```

现网已有月度核价。还没有：价格协议、发票、价差表。

要管的是协议和发票。核价不另做管理模块，对账时指定一份已审核核价月即可。

## 2. 名词（两边对照）

| 业务怎么说 | 开发怎么写 | 含义 |
|------------|------------|------|
| **批量零部件价格协议** | `parts_price_agreement` | 附件头：协议编号、基地、项目、甲方、乙方、执行有效期 + 零件单价 |
| **协议编号** | `agreement_no` | 协议头主键业务号 |
| **项目** | `vehicle_model` | 车型/项目，与现网 BOM 项目对齐 |
| **甲方 / 乙方** | `party_a` / `party_b` | 签约双方名称，按协议原文存 |
| **执行有效期** | `price_valid_from` ～ `price_valid_to` | 价格有效的开始时间、结束时间。**闭区间**（含开始、含结束） |
| **协议 PDF** | 签字件原件 | 扫描件/正式件，`.pdf` |
| **价目 Excel** | 明细原件 | 零件单价表，`.xlsx` / `.xls` |

| **价差** | `price_diff` | 核价单价 − 协议单价 |
| **价差金额** | `diff_amount` | 价差 × 开票数量 |
| **成品** | L0 / `part_number` | 交给客户的供货总成；协议与发票默认按这个对 |

## 3. 业务规则

1. **价格协议是主数据。** 一次导入必须同时有 PDF 和 Excel，缺一则整单拒绝。Excel 解析价目；PDF 只落盘、不解析条款。列表可查、未生效可改头信息、生效后锁定。不把核价自动写成协议价。  
2. 协议价允许和核价不同。其他商务要素写在协议单价和备注里。  
3. **执行有效期** 是价格有效的开始时间和结束时间，闭区间：开始、结束两天都算。发票开票日落在这段里才算本协议。不必等于自然年。  
4. 比差必须有发票。  
5. 价差按成品零件号汇总开票数量。比的是 **对账核价** 和 **协议价**。  
6. 对不上的单独列出，不编造数字。  
7. 月度核价照旧。不进主合同条款、付款、违约。PDF 不当价目用，Excel 不当签字件用。

金额用精确小数（开发：`Decimal`）。

可选：从某月已审核核价带出草稿，改完再保存为协议。不是主路径。

---

## 4. 系统里三张事

切片建议 `sales`：价格协议、发票、价差。核价仍在 `costing`。

### 4.1 批量零部件价格协议（先做）

头（必填）：

| 业务 | 字段 |
|------|------|
| 协议编号 | `agreement_no` |
| 基地 | `location` |
| 项目 | `vehicle_model` |
| 甲方 | `party_a` |
| 乙方 | `party_b` |
| 价格有效开始时间 | `price_valid_from` |
| 价格有效结束时间 | `price_valid_to`（≥ 开始；闭区间，两天都有效） |

另：状态（草稿 / 已生效 / 已关闭）；`pdf_upload_file_id`、`excel_upload_file_id`（两个都有才允许提交）。

明细来自 Excel：零件号、名称、协议单价、单位、备注。

**成对原件（硬约束）：** 同一次提交必须带 PDF 和 Excel。只传一个 → 拒绝，不写库、不登记溯源。两份都进 `file_trace`（分类如 `parts_price_agreement_pdf` / `parts_price_agreement_excel`），同一协议、同一事务。下载走鉴权接口，不拼 `/uploads`。

同一协议编号再导入：未生效可替换明细和两份原件（仍须成对）；已生效须先反审。幂等键：协议编号 + 零件号。

页面：双文件上传、列表（协议编号、基地、项目、甲乙方、执行有效期）、明细、PDF/Excel 分别下载、生效/反审。已生效不可改单价和头字段。

### 4.2 发票

财务开票 Excel 导入。原件进文件溯源。按 **开票日期** 落入已生效协议：`price_valid_from ≤ 开票日 ≤ price_valid_to`（闭区间），且基地、项目能对上（对不上进「未匹配」）。

| 业务列 | 用途 |
|--------|------|
| 开票日期 | 落入哪份协议的执行有效期（闭区间） |
| 基地 / 项目 | 与协议头对齐，见 §7 |
| 零件号 | 与协议明细匹配 |
| 数量、开票单价、开票金额 | 数量×单价核验金额（容差另定） |
| 发票号、行号 | 去重 |

可追加。除非明确整期替换，不删已入库行。

### 4.3 价差

选定：一份已生效协议 + 一个已审核对账核价月。核价单价抄到价差单上。

| 给客户看的列 | 怎么来 |
|--------------|--------|
| 开票数量 | 执行有效期内该成品发票数量合计 |
| 协议单价 | 协议明细 |
| 核价单价 | 对账核价月抄入 |
| 单价差 | 核价 − 协议 |
| 价差金额 | 单价差 × 开票数量 |
| 开票金额 | 发票合计 |
| 按协议应开 | 协议单价 × 数量 |

## 5. 本期不做

| 不做 | 为什么 |
|------|--------|
| 主合同条款、会签、付款 | 只附件价目 |
| 只传 PDF 或只传 Excel | 不成对则不算导入成功 |
| 解析 PDF 条款 | PDF 只存原件 |
| 用核价自动生成协议 | 协议以导入为准 |
| 对接 ERP 拉协议或发票 | 先 Excel |
| 税、折扣整套财务 | 先数量×单价差 |
| 按开票月取 12 个月不同核价 | 现场是次年核一次价 |
| 发票行级明细册 | 先按成品汇总 |

---

## 6. 开发怎么落（摘要）

| 项 | 约定 |
|----|------|
| 协议、发票、价差 | `sales` 切片；表名按 `parts_price_agreement*` |
| 原件 | 每次协议导入 **PDF + Excel 成对** `register_existing`；发票仍为 Excel |
| 比较 | 只读 `costing` 已审核成品价；协议价只读协议表 |
| 幂等 | 协议 `(agreement_no, part_number)`；发票 `(发票号, 行号)` |
| 权限 | 新菜单：价格协议 / 发票 / 价差（落地补 catalog） |
| 引擎 | 不改月度核价入口 |

实施顺序：**价格协议导入与列表** → 发票导入 → 指定对账核价月出面价差并导出。

## 7. 落地前问现场

1. 价目 Excel 列有哪些？零件号是成品号、冲压件号，还是客户图号？  
2. 甲方、乙方在贵司分别对应客户还是本厂（按协议原文存，筛选是否要区分角色）？  
3. 对账时，是指定一个月的核价套到整个执行有效期，还是必须按开票月用该月核价？  
4. 和客户结账，以 **(核价−协议)×数量** 为准，还是还要以发票含税金额再调一次？

## 8. 验收

> 同时上传青岛某协议的 PDF 和 Excel（协议编号、基地、项目、甲方、乙方、价格有效开始/结束时间齐全）。缺任一文件则导入失败。列表能看见头信息和零件协议单价，两份原件都能下载。导入执行有效期（闭区间）内的发票。指定 2026-07 已审核核价出面：每件能看到协议单价、核价单价、数量、价差金额。已生效协议不可被导入覆盖。没有主合同条款页。
