# 冲压零件 — 钢材采购测算导出

> **状态：已落地。**  
> 零件主数据见 [stamping-process-confirmation-design.md](stamping-process-confirmation-design.md)。  
> 利废不买新板见 [offal-nested-material-design.md](../costing/offal-nested-material-design.md)。  
> 废料副产品同样不买新板见 [stamping-family-die-byproduct-design.md](stamping-family-die-byproduct-design.md)。  
> 排序、短码、取数、表头蓝与现网工艺导出同一套 Service：`StampingPartExportService`。测算簿 **不加** 内控水印（不涉密）；工艺确认表导出仍加水印。  
> 共模关键字：`cost_ratio_resolver`。密度：`SettingsService.get_steel_density`。  
> 单件材料消耗口径与零件核价 `blank_weight_kg`（M）一致，不读当月钢价、不调 costing 计算 Service。

---

## 0. 一句话

主机厂给出 **成品件数** 后，按工艺确认表算出 **要买多少吨新板**。  
用户在 Excel **只填「主机厂数量」**；材料重、采购吨全部是公式，改数量即时出吨。  
共模件（左右 / 双槽 / 合并等）必须带出标记，提醒 **成对件数量应相同**。  
利废件和废料副产品 **采购吨为 0**。数量不入库。

产品入口：零件列表 `#/stamping-parts` 新增按钮；**不替代**现有「导出 Excel」（工艺确认表，含简图与逐序明细）。

## 1. 和现有「导出 Excel」怎么分

| | 现有导出 | 本导出 |
|--|----------|--------|
| 用途 | 核对签字工艺（逐序、简图） | 填数量 → 测算采购钢材吨数 |
| 行 | 一零件多行（工序 / 子片拉开） | **一行一件**（拼焊才按子片分行） |
| 用户改 | 无 | **只改「主机厂数量」** |
| 吨 | 无 | Excel 公式 |
| 权限 | `op:stamping-parts:export` | **复用** |

禁止把测算列塞进现有 28 列工艺导出。本表 **不嵌简图**（工艺导出已有）。

## 2. 谁改哪一列

| 列 | 谁改 |
|----|------|
| 零件身份、料片、标记、共模、材料重、采购吨 | **系统**（值或公式）。工作表保护后锁定 |
| **主机厂数量** | **用户**。导出时空；唯一解锁列 |

禁止预填吨的硬值。禁止让用户改牌号 / 可制件数来「凑吨」。要改工艺请回零件详情或重传工艺表。

## 3. 物理含义与吨公式

| 界面说法 | 含义 |
|----------|------|
| 牌号 | 材质（拼焊看子片） |
| 厚度 | 料厚 mm |
| **材料重** | **一张料片** kg：`长×宽×厚×密度÷10⁶`。密度取 `steel_density`（缺省 7.85），写在表头命名格，**材料重必须是引用该格的公式** |
| 零件重量 | 成品净重 kg，只核对，**不参与**吨 |
| 可制件数 | 一张料单独冲本零件（或本子片）能出几件成品 |
| 主机厂数量 \(Q\) | 成品件数（拼焊填总成件数） |
| 采购钢材(吨) \(T\) | 见下 |

\[
T =
\begin{cases}
0 & \text{利废 = 是，或废料副产品 = 是} \\
\dfrac{W}{n} \times Q \div 1000 & \text{否则（} n>0\text{ 且材料重 }W\text{ 有值）}
\end{cases}
\]

缺长 / 宽 / 厚 / \(n\)：材料重或 \(T\) 空白，**整簿仍导出**。  
**不** `CEILING` 到整张料。

## 4. 利废与废料副产品

| 标记 | 采购吨 | 数量 |
|------|--------|------|
| 利废 | **0** | 仍可填（吨仍为 0） |
| 废料副产品 | **0** | 仍可填；与主导件同装车时建议与主导件 **同一数量**（只为对齐计划，不买钢） |

材料重、零件重量有则仍写出。不要按净重买钢。

## 5. 共模：让用户知道数量应该相等

左右件、双槽、合并、一出二、共用，通常 **成对出件、装车件数相同**。测算簿用「是否共模 / 共模标记」让人一眼看出数量应对齐，**不展示**工序、模具、吨位。内部仍用工序码 / 费用比例判定共模。

### 5.1 是否共模（行级）

本件命中任一即 **是**（调用现成函数，不另发明规则）：

- `is_mate_process_code`（工序代码含合并 / 双槽 / 共用）或模具类型 / 工艺方法命中 `cost_ratio_resolver` 已有共享关键字（双槽 / 合并 / 一出二）
- 任一工序 `cost_ratio` 等于 `SHARED_DIE_FACTOR`（0.50）或级进共模叠乘结果 0.40

不要在测算文件里再抄一份关键字元组。

废料副产品 **另外**打「废料副产品」，不要和共模列混成一种徽章；副产品行「是否共模」仍可按工序码为是（家模常写「合并」）。

### 5.2 必须带出的共模列

| 列 | 写入 |
|----|------|
| 是否共模 | 是 / 否 |
| 共模标记 | 去重后的中文标签，如 `双槽`、`合并`、`一出二`、`共用`、`级进共模`；无则空 |

填写规则写在第二页「填写说明」，不占数据列。

### 5.3 排序（与现网一致），不猜配对零件号

行序 **必须** 与零件列表分页相同：`paginate` 与 `list_for_export` 共用同一套 `order_by`，不要另写。

**基地 → 车型 → 冲压工厂 → 序号 → 零件号**

**禁止**按 `id`、只按零件号、短码或「共模对挨在一起」另排。序号抄工艺确认表 Excel，工程变更换号后仍跟原序号，不能因新行 id 更大排到表尾。共模成对件若在源表里本来相邻，现网序也会相邻；不相邻就靠共模列与提示，不要为了左右件打乱现网序。

拼焊子片：零件顺序仍按上式；同一零件内子片排序 **抄现网** `_write_part_block`（`blank_seq` / `id`）。共模判定读工序时排序抄同一文件里的 `process_order` / `id`。不要再写第三套 sort。

**禁止**用相邻行、零件号末位奇偶、名称含左右去自动填「配对零件号」或把数量公式串到另一行。

---

## 6. 拼焊

按子片分行：零件号仍写总成号；「子片」列写子片号或序号。  
主机厂数量每行都填 **同一总成件数**。默认：**每行都空，用户每行填同一数字**。
总成行无料片则不出吨。拼焊子片单独利废本期不做。

---

## 7. 工作簿

**筛选**：与现有零件导出相同。须选定基地；工厂 / 项目 / 版本 / 零件号可选。不分页。

**第一页** `钢材测算`

第 1～2 行元信息：基地、筛选范围、密度命名格、导出时间。密度来自 `SettingsService.get_steel_density`，禁止写死 7.85 且不可改。

一行一件（拼焊一行一子片）。**不写工艺信息**（无工序/模具/吨位/工艺方法/自动化/费用比例/摆剪）。共模判定仍读工序，只输出是否共模与标记。

共 **22 列**。**短码必出**，紧挨零件号右侧，规则与现网工艺导出相同：`short_part_number_digits`。密度命名格在第 2 行 `U2`（与「主机厂数量」同列）。禁止用焊接分总成 `short_weld_part_number`。

**身份弱化（1–5，灰表头/灰字，列窄）**

| 列 | 来源 |
|----|------|
| 序号 / 基地 / 项目 / 版本 / 冲压工厂 | 主表；**不是操作焦点** |

**零件（6–9，主色）**

| 列 | 来源 |
|----|------|
| 零件号 / **短码** / 零件名称 / 子片 | 主表；拼焊才有子片 |

**料片（10–16）**

| 列 | 来源 |
|----|------|
| 牌号 | 材质 |
| 厚度 | 料厚 |
| 长/卷料宽、宽/卷料步距 | 料片 mm |
| 可制件数 | 主表或子片 |
| 材料重 | **公式** |
| 零件重量 | 净重（核对，不参与吨） |

**标记（17–18）**

| 列 | 来源 |
|----|------|
| 是否利废 | 主表 |
| 废料副产品 | 主表 |

**共模（19–20）**

| 列 | 来源 |
|----|------|
| 是否共模 / 共模标记 | §5 |

**测算（21–22，最右）**

| 列 | 谁改 |
|----|------|
| **主机厂数量** | 用户，空 |
| **采购钢材(吨)** | 公式 §3 |

底部合计行：对采购吨 `SUM`，底色与表头同族深蓝、白字加粗；左侧合并格写「合计」。

可选：保护工作表，仅解锁「主机厂数量」与密度命名格。说明页写如何取消保护。

### 7.1 版式（要对得起「打开就能填」）

对齐现网工艺确认表导出的办公蓝，不要做成网页碳黑。字体 **微软雅黑**。`showGridLines = False`，横向打印、`fitToWidth = 1`。缩放约 90%。

| 区域 | 规格 |
|------|------|
| 第 1 行标题 | 合并整行；填充 `#1F4E79`、白字 14pt 加粗；文案如 `{项目}车身件钢材采购测算-{工厂}`；行高 28 |
| 第 2 行范围 | 填充 `#D6EAF8`、字 `#1F4E79`；左：基地/工厂/项目/版本；右：零件行数、密度（命名格，可改） |
| 第 3 行 | 窄空行（8pt），与工艺导出一致 |
| 第 4～5 行表头 | **两级**：范围（灰）/ 零件 / 料片 / 标记 / 共模 / **测算**（深蓝）。测算是操作焦点 |
| 数据区 | 零件号起 9pt 黑字；斑马 `#F2F2F2`；细边框 `#BFBFBF` |
| 范围列（序号～冲压工厂） | 灰底 `#F4F4F4`、8pt 灰字 `#8A8A8A`、列窄；表头灰而非海军蓝。打开表时眼睛先落到零件号与黄色数量列 |
| 短码列 | 10pt 加粗 `#1F4E79`；列宽约 8 |
| 主机厂数量 | **浅黄** `#FFF2CC`、居中；空单元格可批注「在此填写」；列宽够填 6 位整数 |
| 采购钢材(吨) | **浅青绿** `#E2EFDA`；数字 4 位小数；公式列 |
| 材料重 | 数字 4 位小数；公式列，不必黄底（不是手填） |
| 是否共模 = 是 | 该行「是否共模 / 共模标记」浅橙 `#FCE4D6` |
| 利废或废料副产品 = 是 | 对应标记列浅灰 `#F2F2F2` 即可，吨列公式已为 0 |
| 合计行 | 见上 |
| 冻结 | `freeze_panes` 定在 **数据首行 × 短码下一列**（身份+短码横向滚出测算列时仍可见）。不要只冻 A1 |
| 筛选 | 字段表头行打开 `auto_filter`，范围含全部数据列 |
| 列宽 | 按内容给默认宽（零件号 16、名称 18）；长文本换行，行高默认 18，不撑成简图高 |

测算分组（数量 + 吨）放在 **最右侧**，打开表横向一滚（或冻结后直接看见）就能填。不要把数量夹在料片中间。

**第二页** `填写说明`：短表（项 / 说明）。只填黄色数量列；共模成对数量应相同；利废/副产品吨为 0；可制件数；密度格；拼焊各行同一总成件数。Parser **不读** 本文件。

文件名：`钢材采购测算_{location}_{范围摘要}_{时间}.xlsx`。**不加**内控水印（测算给工厂填数量，不涉密）。工艺确认表导出仍走 `workbook_to_xlsx_bytes`。

## 8. 落点：接在现有导出 Service 上，不许另起一套

测算和工艺确认表是 **同一切片、同一个 Service 的两个方法**。

| 要做的 | 用现成的 | 禁止 |
|--------|----------|------|
| HTTP | `app/routers/stamping/crud.py` 已有 `_export_service`；旁边加一条 GET | 新 Router 文件；Router 里组 Excel |
| 编排 | `StampingPartExportService` 增加方法（如 `export_steel_purchase`），签名与现有 `export` 同参：`location` 必填 + 可选工厂/项目/版本/零件号 + `current_user` | 新建 `*steel_purchase*export_service.py`、新 Orchestrator、新包目录 |
| 取数 / 排序 | 现有 `StampingPartRepository.list_for_export` | 新 Repo 方法、新 `order_by` |
| 短码 | 现有 `short_part_number_digits`（工艺导出已 import） | 自写截码、焊接 `short_weld_part_number` |
| 样式 / 打印 | **同一文件里的** 填色、字体、边框、横向打印、关网格线。测算落盘直接 `workbook.save`，**不**走 `workbook_to_xlsx_bytes` | 复制一份 `_HEADER_FILL`；为测算单独做 theme 模块；测算加水印 |
| 密度 | `SettingsService.get_steel_density` | 写死 7.85；从 costing 核价结果抄密度 |
| 共模 | `cost_ratio_resolver` 已有：`is_mate_process_code`、`SHARED_DIE_FACTOR`（0.50）、关键字元组 | 第三套「双槽/合并」词表 |
| 数字格 | 现有 `excel_money_cell` / `Q4` | 业务 `float` |
| 前端 | 零件列表现有 `exportExcel` + `HttpClient.download` + `op:stamping-parts:export`；加第二个按钮调新 path | 新页面模块；新权限码 |

材料重、采购吨 **只写 Excel 公式**，不要调用 `PartCostCalculator` / 零件核价 Export 去算吨（那些走月度钢价，本表不买价）。

工艺导出 `export()` 行为不变：仍出 28 列主子表 + 简图。测算方法 **不嵌简图**，但筛选校验（须选定基地）与 `export()` 同一段，抽出来共用，不要复制 `BusinessException("导出须选定基地")`。

## 10. 明确不做

- 不新开 Export Service / Orchestrator / Repository / 权限码 / 页面模块  
- 不替代现有工艺导出、不嵌简图、不逐序拉行、测算表不写工艺列  
- 不把主机厂数量落库、不做导入  
- 用户不只填数量以外的业务列（保护后锁定）  
- 不按整张料 `CEILING`、不按零件净重买钢  
- 不另排 `seq_no` / 短码 / 共模对；不自动配对左右件、不把数量公式跨行绑定  
- 短码不用焊接 `-N` 规则  
- 不读一事一议钢价、不调 costing 计算 Service、不出金额  
- 拼焊子片单独利废本期不做  
- 测算簿不加内控水印（不涉密）；工艺确认表导出仍加水印
