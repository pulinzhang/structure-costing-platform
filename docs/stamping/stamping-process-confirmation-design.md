## 0. 一句话

**双方签字的冲压工艺确认表** 是冲压件主数据：零件、料片、工序、吨位、模具编号。  
它同时是 **冲压加工费** 和 **零件材料费（含是否利废）** 的约定来源。模具布点只是模具计划，**不能**改这张表里的利废约定。

产品入口：`#/stamping-upload`；API `/api/stamping/upload`（异步）。

---

## 1. 和模具布点怎么分

| | 冲压工艺确认表（本模块） | 模具布点清单 |
|--|--------------------------|--------------|
| 文件性质 | **双方签字版本** | 模具计划 |
| 核价角色 | 加工费；材料 M/H；**是否利废** | 模具费（重量 / 尺寸 / 分摊比例） |
| 落库 | `stamping_parts` + `stamping_processes`（拼焊另有子片表） | `stamping_die_parts` + 工序子表 |
| 利废 | **只认本表**「料片式样」里的「利用××废料」 | `sheet_shape` 原文可存，不回写零件主表、不改材料价 |

禁止用布点去覆盖工艺表的利废标记。布点写成「条料」、工艺表写成「利用侧围废料」时，以工艺表为准。

## 2. 上传

### 2.1 表单

1. **采购基地**必选。  
2. 拖拽 `.xlsx` / `.xls`（上限 50MB）。车型、版本、冲压厂从文件名或表头解析，须能识别。  
3. 同基地 + 冲压厂 + 车型 + 版本再次上传则 **整包覆盖**。  
4. 提供「下载模板」。

同一零件工序号不得重复，否则整单失败并标出 Excel 行号。

### 2.2 上传页必须写明的利废依据（界面用中文，不要写英文字段名）

右栏说明（或同等位置）须让填写人知道：

1. 本文件是双方签字的工艺确认表。  
2. **是否利废**只根据本表 **「料片式样」** 判定：单元格里出现「利用……废料」（如「利用侧围废料」）即视为利废件，不采购新板；材料按 **成品净重 × 废料月度价**。  
3. 「方料 / 卷料 / 条料」仍是料片几何式样，和利废是两件事。**不要只靠空长宽**判断利废（漏填会误伤）。  
4. **例外（家模副产品，未落地）**：长/卷料宽、宽/卷料步距、可制件数、料片式样 **四列都空** 且成品净重 > 0 → 视为家模带出的副产品，材料按废料净重，加工费/模具费记 0。细则见 [stamping-family-die-byproduct-design.md](stamping-family-die-byproduct-design.md)。  
5. **不要**用模具布点来改利废或家模：布点与本表不一致时，以本表为准。

推荐原文（上传页右栏「说明」；家模句落地后再上屏）：

> 本文件为双方签字的工艺确认表。  
> **是否利废**：只看本表「料片式样」。写有「利用××废料」（例：利用侧围废料）即记为利废件，材料 = 成品净重 × 废料单价（从废料里捡出的成品），不按一事一议新板价。方料 / 卷料 / 条料仍填在同一列，表示料片形状。  
> **家模副产品**：长/卷料宽、宽/卷料步距、可制件数、料片式样都空，且有零件净重 → 视为一副模带出的小件，材料同样按废料净重，加工费和模具费记在主导件上。不要只空长宽、其它列还填着。  
> 模具布点是计划，不作为利废或家模依据；与本表不一致时以本表为准。

## 3. 主表（零件）

唯一键：基地 + 冲压厂 + 车型 + 版本 + 零件号。

现网已有：材质、料厚、净重、料片长宽、可制件数、**料片式样**、模具类型、工艺方法、自动化、简图等；拼焊用 `is_tailor_welded` + 子片表。

**利废字段（与拼焊并列、互不替代，已落地）：**

| 界面说法 | 库字段 | 含义 |
|----------|--------|------|
| 是否利废 | `is_offal_nested` | 默认否。是 = 不采购新板 |
| 利用哪类废料 | `offal_source` | 可空。例：侧围 |

**废料副产品（工艺上传已落地，见 [stamping-family-die-byproduct-design.md](stamping-family-die-byproduct-design.md)）：**

| 界面说法 | 库字段 | 含义 |
|----------|--------|------|
| 废料副产品 | `is_scrap_byproduct` | 默认否。是 = 家模用废料成形，**不算冲压加工费** |

料片式样入库后只保留几何（方料 / 卷料 / 条料）。「利用侧围废料」拆到上面两列，不要整段长期留在料片式样里。

拼焊是多片 **采购钢板**；利废是 **用别人的落料废料**。不要用拼焊子片表表达利废。

解析：匹配「利用」+ 可选名称 +「废料」→ 是否利废为是，利用哪类废料取中间名称。不要用 **仅空长宽** 当利废。不要读布点。已入库工艺在启动时按同一规则回填；核价结果须重算才会带上利废快照。  
家模副产品（四列全空）上传时写入 `is_scrap_byproduct`，见 [stamping-family-die-byproduct-design.md](stamping-family-die-byproduct-design.md)。

零件详情抽屉（有 `op:stamping-parts:update` 时）可用 **是否利废** 开关纠错，并填写「利用哪类废料」；关开关会清空来源。列表「利废」列只展示、不在行上改。改完须重算零件价格才按新规则计价。

---

## 4. 子表（工序）

工序序号、工序代码、套数、模具编号、吨位、加工费 `cost_ratio`（双槽/合并/一出二 ×0.50，级进再 ×0.80）。  
签字利废 **不改** 加工费比例。家模副产品例外：默认 `cost_ratio = 0`（见家模设计）。

---

## 5. 下游怎么用

| 下游 | 读什么 |
|------|--------|
| 冲压加工费 | 工序吨位 × 冲次单价 × `cost_ratio` |
| 冲压零件材料 | 正常件：一事一议 R；利废件：`R = 成品净重 × 废料单价`（从废料捡成品） |
| 模具费 | 读布点，不读本表利废 |

缺废料月度价时，利废件与现网缺废料价一样硬停，不退回一事一议。

---

## 6. 明确不做

- 不根据「同材质废料重量 2～3 倍」自动猜母件  
- 不改母件边角废料扣减  
- 利废材料不记 0  
- 不在布点表增加核价用的利废开关  
- 家模副产品见专文，不在本表用空长宽单独打标
