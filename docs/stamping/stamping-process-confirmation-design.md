# 冲压工艺确认表 — 设计说明

> **状态：导入、主表利废字段与核价换价已落地。**  
> 样本：`excel_sample/T13J/` 下各厂 `T13J项目冲压工艺确认表-….xlsx`。  
> 利废计价见 [offal-nested-material-design.md](../costing/offal-nested-material-design.md)。  
> 四异号家模、料片四列全空见 [stamping-family-die-byproduct-design.md](stamping-family-die-byproduct-design.md)（工艺上传与布点分摊已落地；零件价月快照 / 详情 PATCH 见该文）。  
> 模具布点是另一套表，见 [stamping-die-management-design.md](stamping-die-management-design.md)。  
> **导入顺序**：布点不依赖工艺。本表上传 **只选采购基地**，项目从文件识别，**不要求**已有布点（冲压厂可无布点表）。细则见 [stamping-apqp-die-before-process-design.md](stamping-apqp-die-before-process-design.md)。  
> **模具编号**：本表可空、不得挡导入；无该列表头也可解析。强制编号在布点。  
> 硬约束：分层与切片见 [architecture.md](../architecture.md)。

## 0. 一句话

**双方签字的冲压工艺确认表** 是冲压件主数据：零件、料片、工序、吨位、模具编号。  
它同时是 **冲压加工费** 和 **零件材料费（含是否利废）** 的约定来源。模具布点只是模具计划，**不能**改这张表里的利废约定。

产品入口：`#/stamping-upload`；API `/api/stamping/upload`（异步）。

## 1. 和模具布点怎么分

| | 冲压工艺确认表（本模块） | 模具布点清单 |
|--|--------------------------|--------------|
| 文件性质 | **双方签字版本** | 模具计划 |
| 核价角色 | 加工费；材料 M/H；**是否利废** | 模具费（重量 / 尺寸 / 分摊比例） |
| 落库 | `stamping_parts` + `stamping_processes`（拼焊另有子片表） | `stamping_die_parts` + 工序子表 |
| 利废 | **只认本表**「料片式样」（利用件 / 「要利废」，判定见 §3） | `sheet_shape` 原文可存，不回写零件主表、不改材料价 |

禁止用布点去覆盖工艺表的利废标记。布点写成「条料」、工艺表写成「利用侧围废料」时，以工艺表为准。

## 2. 上传

### 2.1 表单

1. **采购基地**必选。  
2. 项目、版本、冲压厂从文件名或表头解析，须能识别。表单 **不要**传项目。  
3. 拖拽 `.xlsx` / `.xls`（上限 50MB）。  
4. 同基地 + 冲压厂 + 车型 + 版本再次上传则 **整包覆盖**。  
5. 提供「下载模板」。

同一零件工序号不得重复，否则整单失败并标出 Excel 行号。

### 2.2 上传页必须写明的利废依据（界面用中文，不要写英文字段名）

右栏与下面推荐原文保持同一段（家模句已上屏）。**不要只靠空长宽**判断利废。细则见 [stamping-family-die-byproduct-design.md](stamping-family-die-byproduct-design.md)。

> 本文件为双方签字的工艺确认表。  
> **是否利废**：只看本表「料片式样」。写「利用××废料」（如利用侧围废料）或格里写「利废」（含错写成「利费」）即记为利用件，材料 = 成品净重 × 废料单价（从废料里捡出的成品），不按一事一议新板价。写「要利废」表示这件会产出废料给别人用，不是利用件。方料 / 卷料 / 条料仍填在同一列，表示料片形状。  
> **家模副产品**：长/卷料宽、宽/卷料步距、可制件数、料片式样都空，且有零件净重 → 视为一副模带出的小件，材料同样按废料净重，加工费和模具费记在主导件上。不要只空长宽、其它列还填着。  
> 模具布点是计划，不作为利废或家模依据；与本表不一致时以本表为准。

## 3. 主表（零件）

唯一键：基地 + 冲压厂 + 车型 + 版本 + 零件号。

现网已有：材质、料厚、净重、料片长宽、可制件数、**料片式样**、模具类型、工艺方法、自动化、简图等；拼焊用 `is_tailor_welded` + 子片表。

**利废字段（与拼焊并列、互不替代，已落地）：**

| 界面说法 | 库字段 | 含义 |
|----------|--------|------|
| 是否利废 | `is_offal_nested` | 默认否。是 = 不采购新板 |
| 利用哪类废料 | `offal_source` | 可空。例：侧围 |

**废料副产品（工艺上传已落地，见 [stamping-family-die-byproduct-design.md](stamping-family-die-byproduct-design.md)）：**

| 界面说法 | 库字段 | 含义 |
|----------|--------|------|
| 废料副产品 | `is_scrap_byproduct` | 默认否。是 = 家模用废料成形，**不算冲压加工费** |

拼焊是多片 **采购钢板**；利废是 **用别人的落料废料**。不要用拼焊子片表表达利废。

**是否摆剪**（主表 `has_swing_shear`）：工序代码/序号或零件首行工序内容含「摆剪」即记是。Excel 成对右件第一序常只写「合并 / 双槽 / 共用」、不再写摆剪；**上一件已是摆剪**时，本件第一序为这些共模码也记摆剪（与上一件同冲摆剪落料）。下一件第一序是 DR/BL 等普通码则不继承，即使工艺方法也写「合并」。

解析：料片式样是否利废只由 `app/common/offal_nested.py` 判定（不要用仅空长宽、不要读布点）。首次加 `is_offal_nested` 列时按同一函数回填。核价结果须重算才会带上快照。

零件详情抽屉（有 `op:stamping-parts:update` 时）可用 **是否利废** 开关纠错，并填写「利用哪类废料」；关开关会清空来源。列表「利废」列只展示、不在行上改。改完须重算零件价格才按新规则计价。

## 4. 子表（工序）

工序序号、工序代码、套数、模具编号、吨位、加工费 `cost_ratio`。Excel **没有**比例列；新增工序由 `cost_ratio_resolver` 赋默认值，覆盖上传同零件号+工序号由 `cost_ratio_preserver` 沿用库中值（废料副产品强制 0）。

**零件级叠乘**（双槽/合并/一出二 ×0.50，本件自动化或工艺方法含「级进模」、或整格为「级进」、**或本序代码切词含 PRG** 再 ×0.80，可叠成 0.40）。「级进落料」不是级进模，**不按零件级叠乘打到每一序**；多序时走下面 PRG 例外（第一序 0.80，后序 1.00）。

- 共模右件自动化常写「手工线」：本序代码为合并/双槽/共用，且 **Excel 上一件** 自动化为级进/级进模、**或上一件第一序切词含 PRG** 时，再 ×0.80。左件第一序是 BL/FO/DR 等普通码时不继承（避免跟上一家无关级进件叠成 0.40）。
- 单序一律走叠乘（`PRG` + 合并 + 手工线 → 0.40）。
- **一出二（两个条料）**：多序时只有第一序共用落料 **0.50**（右件第一序常写「共用」）；后序各冲各的 **1.00**。后序代码为双槽/合并，或成对右件后序空码（与左件同一副后序模）时后序仍 **0.50**。
- **双槽/合并**：各序都对半 **0.50**（后序也共模）。例外：**双槽**（含「共用/双槽」）多序且第一序为落料（切词含 `BL`，或右件写「共用」「BL+PI(共用)」）时，落料不是双槽模，第一序 **1.00**，后序仍 **0.50**。第一序已是 DR/双槽/合并的，不走此例外。

**多序 PRG 例外**（切词含 `PRG` 即为级进模，含 `PRG`、`PRG-BL`、`PRG-BL+PI`、`BL+PI-PRG`；不要求同时有 `BL`。自动化或工艺方法含「级进落料」同样走本节，第一序不必再写 PRG）：

1. 第一序单独 **0.80**（含上一件第一序已是 PRG、本件第一序写「共用」——共用只表示同一刀落料，不对半）。
2. 从第一序之后起：本件/成对邻件后续代码含双槽/合并，或右件后序空码，或工艺方法为双槽/合并时 **0.50**。**不要**仅因工艺方法「一出二」把后序打成 0.50。成对只认下一件第一序为「共用」，或本件第一序为「共用」则只看上一件。
3. 否则后续序 **1.00**（不再按本件「级进」叠 0.80，后序是普通冲压）。

签字利废 **不改** 加工费比例。家模副产品例外：默认 `cost_ratio = 0`（见家模设计）。

## 5. 下游怎么用

| 下游 | 读什么 |
|------|--------|
| 冲压加工费 | 工序吨位 × 冲次单价 × `cost_ratio` |
| 冲压零件材料 | 正常件：一事一议 R；利废件：`R = 成品净重 × 废料单价`（从废料捡成品） |
| 模具费 | 读布点，不读本表利废 |

缺废料月度价时，利废件与现网缺废料价一样硬停，不退回一事一议。

---

## 6. 明确不做

- 不根据「同材质废料重量 2～3 倍」自动猜母件  
- 不改母件边角废料扣减  
- 利废材料不记 0  
- 不在布点表增加核价用的利废开关  
- 家模副产品见专文，不在本表用空长宽单独打标
