## 0. 一句话

**四个不同零件号共用一副模**时，没有独立料片的小件是 **废料副产品**：主表打 `is_scrap_byproduct`，材料按废料净重，**不算冲压加工费**，模具费挂在主导件上。  
判定不靠穴数、不按重量比自动猜母件，只看工艺确认表上 **料片四列是否全空**。

## 1. 样本事实（T2AA，不是猜测）

同一副模、四个件号（Excel 序号 24～27，行 167～192）：

| 零件号 | 名称 | 净重 kg | 长/卷料宽 | 宽/卷料步距 | 可制件数 | 料片式样 | 工艺方式 / 工序 |
|--------|------|---------|-----------|-------------|----------|----------|-----------------|
| 502018915AA | 左C柱内板 | 2.249 | 1150 | 810 | 1 | 梯形 | 双槽；OP10～50 吨位齐全 |
| 502018916AA | 右C柱内板 | 2.245 | 1150 | 810 | 1 | 梯形 | 双槽；右件工序多为空、OP10 写「双槽」 |
| 502018924AA | 左D柱下隔板 | **0.079** | **空** | **空** | **空** | **空** | OP10 写「合并」 |
| 502018925AA | 右D柱下隔板 | **0.079** | **空** | **空** | **空** | **空** | OP10 写「合并」 |

四点：

1. **四异号家模**，不是同一件一出四。左右 C 柱是主导件，左右 D 柱下隔板是副产品。  
2. 净重大约 **2.25 / 0.079 ≈ 28 倍**。副产品不足以决定压机吨位和模具钢量。  
3. 文件名带「模具布点工艺清单」，表头却是工艺确认表那一套：**预估料片尺寸（长/卷料宽、宽/卷料步距）、可制件数、料片式样**。本规则的判定列以 **工艺确认表** 为准，不另开布点核价开关。  
4. 副产品仍有材质、料厚、净重；不是空行。

## 2. 判定

### 2.1 四列全空 → 家模副产品

零件主数据行上，下列 **全部为空**（单元格无值、仅空白、或解析后等价于空）即视为家模副产品：

| 界面列 | 库字段（工艺件） |
|--------|------------------|
| 长 / 卷料宽 | `sheet_length` |
| 宽 / 卷料步距 | `sheet_width` |
| 可制件数 | `parts_per_sheet`（空或 0 都算空） |
| 料片式样 | `sheet_type`（几何式样；「利用××废料」已拆走之后仍为空） |

同时须有 **零件号**，且 **成品净重 > 0**（材料要按净重计价）。材质、料厚不作为判定开关。普通件上传仍须填写零件名称、材质和料厚，见工艺确认表。

### 2.2 和「漏填」的界限

旧口径：**不要只用空长宽当利废**，避免漏填误伤。本规则收窄为 **四列同时空**。

| 填法 | 结论 |
|------|------|
| 四列全空，有净重 | **废料副产品**：主表 `is_scrap_byproduct = True` |
| 仅长宽空，可制件数或料片式样有值 | **不是**本规则。按漏填 / 现网材料校验处理 |
| 料片式样写「利用××废料」，长宽可有可无 | **签字利废**（已落地），不依赖四列全空 |
| 四列都有值（如 C 柱 1150×810×1 梯形） | 主导件 / 普通件，买新板 |

**不要**用净重比、同材质、Excel 相邻行去猜「谁是母件」。重量悬殊只解释为什么副产品不摊模具，不是 Parser 条件。

### 2.3 哪张表说了算

| 文件 | 角色 |
|------|------|
| **冲压工艺确认表** | **唯一判定来源。** 上传时按 §2.1 打标 |
| 模具布点清单 | 同一四列全空规则 → 默认 `alloc_ratio = 0`，不算模具费、不继承共模重量。**不**写工艺件 `is_scrap_byproduct` |

T2AA 这份样本文件名是布点、内容是工艺表：落地时按 **工艺确认表 Parser** 读这四列。若现场只传了布点、工艺表四列有值，不得用布点空列改核价。

覆盖上传：以本张工艺表为准，整单重打标（与材质、利废短语同一覆盖键）。

## 3. 落库（冲压零件主表加标识列）

**身份在零件主表 `stamping_parts`，单独一列，不要靠 `offal_source = 家模` 猜测，也不要做成 Model `@property` 从空料片现算。**

| 界面说法 | 库字段 | 类型 | 含义 |
|----------|--------|------|------|
| **废料副产品** | `is_scrap_byproduct` | `Boolean`，默认 `False`，建议索引 | 是 = 家模带出、**用废料成形**；**不算冲压加工费**（模具费挂靠主导件，见 §4.3） |

与已有利废、拼焊并列、互不替代：

| | 签字利废 `is_offal_nested` | 废料副产品 `is_scrap_byproduct` |
|--|---------------------------|--------------------------------|
| 怎么来 | 料片式样「利用××废料」 | 料片 **四列全空** 且净重 > 0 |
| 材料 | `R = H×Q` | **同样** `R = H×Q`（用废料做） |
| 冲压加工费 | **照算**（不改 `cost_ratio`） | **不算**（本列 = 是 即跳过冲次） |
| 列表 | 「利废」列 | **另开一列**，不要和利废徽章混成一种 |

上传打标（工艺确认表 Parser / Service，覆盖整单）：

1. §2.1 成立 → `is_scrap_byproduct = True`。  
2. 为走现网材料公式，**同时** 写 `is_offal_nested = True`，`offal_source` 固定 **`家模`**（不要从邻件名称猜「C柱内板废料」）。  
3. 仅命中「利用××废料」、四列并非全空 → 只打签字利废，**本列保持否**（自己有料片，要算冲压费）。  
4. 两者都不是 → 两列都否。

下游 **冲压加工费只读 `is_scrap_byproduct`**，不要读 `offal_source` 是否为家模。本列为是：各序 `cost_ratio` 默认 0，计算层即使吨位齐全也记 0。

纠错：零件详情（权限同改利废）可改本列。关成否时：`is_scrap_byproduct = False`；若 `offal_source` 仍是「家模」则一并清空利废标（避免关掉副产品还按废料价）。关掉且未补料片时，材料按正常件会因缺长宽/`n` 算不出——不在计算层猜回副产品。列表该列只展示、不在行上改。

核价结果 `stamping_part_costs` **按月快照** `is_scrap_byproduct`（与利废快照并列）。已算月份须重算才带上。

VO / 零件列表 / 详情须输出本列。界面中文用「废料副产品」，不要写英文字段名。

## 4. 三块成本

家模是 **一次行程、一副模、四个件号拆账**。副产品只付废钢净重，不参与分母。

### 4.1 材料

与已落地利废同一公式，**不买新板**：

```text
R = H × Q
```

`H` = 成品净重（样本 0.079 kg），`Q` = 当月废料月度销售价（元/kg）。  
不查一事一议、不算 \(M\)、不扣边角。缺 `Q` 与现网利废一样 **硬停**。

主导件（C 柱）仍按各自料片买钢：1150×810×0.7÷可制 1。 **不**把副产品净重从主导件边角 `O` 里扣掉（与利废设计「不改母件边角」一致）。

### 4.2 加工费

现网：`吨位 × 冲次单价 × cost_ratio`。叠乘与多序 PRG 例外见 [stamping-process-confirmation-design.md](stamping-process-confirmation-design.md) §4，本表只约定副产品默认 0。

副产品 OP10 写「合并」时，若仍走关键字，会记 **半次冲次**，等于让 0.079 kg 的件分担压机。禁止。

| 件 | 默认 `cost_ratio` |
|----|-------------------|
| 主导件（四列有料片；本样本双槽） | 现网不变：双槽 0.50（左右合计 1 次行程） |
| **废料副产品** | **0**。主表 `is_scrap_byproduct` 为是时写入；不因工序码「合并/共用/双槽」改成 0.50 |

级进 0.80 也不乘到副产品上（0 × 0.80 仍是 0）。  
已改过的工序覆盖上传仍沿用库值：新规则只约束 **新写入** 的默认值；要把旧「合并=0.50」改掉须人工改或允许一次按新规则重打默认（落地时在上传说明里写清，推荐 **副产品新规则优先于沿用**，避免样本重传后仍各记半锤）。

签字利废「不改加工费比例」仍成立。废料副产品以主表 `is_scrap_byproduct` 为准：加工费必须为 0。

### 4.3 模具费

现网共模：主件外形 × 0.50，紧邻「共用」空重量件 **继承上一件重量再 × 0.50**。  
副产品若走继承，会按 C 柱那副模的吨位重量各摊一半，比记半次冲次更歪。

| 件 | `alloc_ratio` / 有效重量 |
|----|---------------------------|
| 主导件 | 现网左右对半；自有外形，不给副产品继承 |
| **废料副产品**（`is_scrap_byproduct`） | **不算模具费**：默认 `alloc_ratio = 0`，且 **禁止** 作为共模继承的目标件（即使工序码含「合并/共用」） |

系统模具费 ≤ 0 的件现网本就不入库，任务仍可 success。副产品应落入这条：不进年度模具费台账，也不用手调造一行。

检具费：本期不因家模自动改；副产品若无检具档案则本来就是 0。

## 5. 主导件怎么填（约定，不自动配对）

本样本正确拆账（同一序、一次行程）：

```text
加工费 cost_ratio：915 0.50 + 916 0.50 + 924 0 + 925 0  = 1
模具费 alloc_ratio：915 0.50 + 916 0.50 + 924 0 + 925 0  = 1
材料：915、916 按梯形料片；924、925 按 H×Q
```

不要求系统校验「四个件号比例之和 = 1」。只保证：副产品默认 0，主导件仍按双槽/一出二。  
同号一出四、或四穴尺寸接近要按面积加权，**不在本期范围**。

## 7. 明确不做

- 不按穴数均摊（禁止四件各 0.25 / 各 0.50）  
- 不按面积、净重自动拆 `cost_ratio` / `alloc_ratio`  
- 不自动把副产品关联到 915/916，不改主导件 `O`  
- 不把「仅空长宽」扩成利废（仍防漏填）  
- 不在布点表增加核价开关、不拿布点覆盖工艺表  
- 不把副产品材料记 0（废钢净重仍要钱）  
- 不把副产品做成 Model `@property` 从空列现算；上传时写入 `is_scrap_byproduct`  
- 不把本列语义缩成「只改 `offal_source`」；不算冲压费必须读这一列

## 8. 落地进度

**已做（工艺确认表上传）：**

- 主表 `stamping_parts.is_scrap_byproduct`；启动时 ALTER，不回填旧行。  
- Parser：四列全空且净重 > 0 → 打标，并写利废 + `offal_source=家模`。  
- 副产品工序 `cost_ratio = 0`，优先于沿用。  
- 上传页说明、零件列表/详情只读展示。  
- 加工费计算：`is_scrap_byproduct` 整件记 0，不因缺吨位进失败清单。  
- 模具费计算：工艺件已打标 **或** 布点四列全空 → 跳过（不继承共模重量、不入库、不报失败）。  
- 模具布点上传：同一四列判定，默认 `alloc_ratio = 0`（不沿用旧比例）。

**已做（零件价与详情）：**

- 零件价格按当月零件读取 `is_scrap_byproduct`，加工费和模具费记 0。结果行快照当月料片和利废（`is_offal_nested`、`offal_source`），本月行不随后面改零件而变。  
- 零件列表和详情显示废料副产品。利废在详情里改，接口 `PATCH /api/stamping/parts/{part_id}/offal`。废料副产品随工艺表打标，详情不另开开关。  
- 旧行没有这一列时，重传工艺确认表或布点表后才会打上。
