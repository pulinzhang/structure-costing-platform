帮助

登录、侧栏、冲压 / 焊接 / 一事一议 / 核价、采购价格协议、文件溯源、工程变更（设计变更、材料变更）、主数据、设置、右上角浅色界面与退出、AI 助理、Excel 导出。

知识库

核总成、分总成、冲压件；前置含工艺、模具布点、拆解、采购对象；投产后换号走工程变更；冲次/焊接单价一年一传；每月钢价链；AI 解读动因。

样例

按知识库同一结构举例：芜湖 · 2025年01月 · T13J ·「左后尾灯安装板总成」前置→年度→每月→总费用 49.75 元。

建议阅读顺序

  1. 先看知识库 明确「核总成、分总成、冲压件」、投产时把结构和工艺传好、年度与每月各自做什么。
  2. 再看样例 芜湖 · 2025年01月 · T13J，按知识库章节把数字对上。
  3. 最后看帮助 回到系统里按菜单上传、计算、导出。
三块分开看。 导出 PDF：打开 整本打印 （合并帮助 + 知识库 + 样例后一次另存）。
