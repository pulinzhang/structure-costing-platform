平台是什么

把冲压工艺、焊接 BOM、钢材政策与废料价组合成零件价与成品价的一体化核价系统。

平台按业务模块组织：上游准备主数据与政策，下游执行钢材联动 → 冲压零件价 → 成品核价。 日常月度核算可走单步计算页，也可在「自动核价引擎」选定基地、年、月后一键编排。 结果既可在线查询审核，也可一键导出专业 Excel，供核对、存档与汇报。

年度数据

工艺、冲次单价、焊接单价、BOM、年度零件价、包装运输费等，一年内可复用。

月度数据

基准价、加减价政策命中、废料月度销售价等，每月核价前必须齐。

作用与价值

把分散在 Excel、邮件与口头口径里的核价工作，变成可追溯、可复算、可交付的系统流程。

统一口径

工艺、BOM、钢材政策、加工费、焊接费在同一平台衔接，减少「各表各算、对不上账」。

缩短月度周期

仪表盘看缺口，引擎一键补算与串链；从「到处找表」变成「检查就绪 → 启动」。

可审可追

结果带审核状态与操作日志；导出表含溯源列与公式口径，审核人能顺着数字查到源数据。

Excel 闭环

业务习惯仍是 Excel：上传入库、系统计算、再导出核对合册或单表，兼顾效率与交付习惯。

解决什么痛点

  • 数据分散：工艺、冲次单价、政策、BOM、废料价分属多处，月度对账成本高。
  • 口径漂移：手工改表易漏公式、漏政策档；系统按统一规则计算并落库。
  • 缺口难发现：缺钢种、缺政策、缺 L0 往往算到一半才暴露；引擎硬停 + 跳转可前置阻断。
  • 交付不完整：汇报常需多张关联表；合册一次打出成品价、零件价、加工费、钢价等，便于封存。
核心价值一句话：算得准、跑得快、导出可核对——在线完成月度核价闭环，离线仍用专业 Excel 完成审核与汇报。

Excel 导出能力

不是简单「把列表倒成表」，而是面向核对与交付的专业工作簿输出。

设计亮点

多表合册

「导出核对合册」在同一 xlsx 内串联成品核价、冲压零件核价、加工费、钢材联动、年度零件价、包装运输、焊接单价等，并带封皮说明页。

公式可复核

关键金额列可输出 Excel 公式（非整表死数），打开后仍能顺着单元格核对计算逻辑。

人可读溯源

导出含钢价/加工费/废料等溯源说明列，以及关联 ID，方便定位源文件、表名与行号。

排版即交付

标题区、分组表头、冻结窗格、筛选、横向打印适配等，可直接用于审核会与存档，少二次美化。

月度核对合册（推荐交付物）

入口：核价 → 成品核价一览 →「导出核对合册」。 须选定年 / 月 / 基地 / 项目 / BOM 版本（可选冲压工厂）。 合册只导出、不重新算价，保证与系统当前结果一致。

合册内容（同一文件多 Sheet） 用途
封皮 · 核价说明 范围、流程与阅读指引
成品核价及相关明细 L0 总账、材料归集、焊接费、间接费用等
冲压零件核价 材料 / 废料 / 加工费构成与溯源
冲压加工费 年度加工费结果核对
钢材联动价 当月材料单价依据
年度零件价 / 包装运输 / 焊接单价 成品侧取价与费用输入底稿

各业务页也可单独导出

列表页通常有「导出 Excel」按钮（需对应导出权限）。常见包括：

模块 典型导出
冲压工程 冲压工艺确认表、冲次单价、冲压加工费
焊接工程 焊接单价、年度零件价、包装运输费、工艺拆解核对、成品焊接费
一事一议 基准价、加减价政策（主子表）、中标厚度一览、废料月度价
核价 钢材联动价、冲压零件价格、成品核价；以及上方的核对合册
设置 操作日志导出（审计存档）
使用建议：日常在线看仪表盘与一览表；对外汇报、跨部门核对、月度封存，优先导出核对合册。 单表导出适合只核对某一环节（例如只审钢材联动或只审加工费）。
无「导出」权限时按钮会隐藏或提示无权限。合册导出前请确认筛选维度完整，否则文件范围可能不符合预期。

快速入门

登录后从左侧导航进入各功能；无权限的菜单会隐藏。

  1. 登录 打开系统登录页，使用管理员分配的账号进入。会话失效后会自动跳回登录。
  2. 打开导航 点击左上角菜单按钮展开侧栏（Overlay）。按「仪表盘 → 冲压 → 焊接 → 一事一议 → 核价 → 报价 → 设置」顺序浏览。
  3. 看清维度 多数功能按基地 / 工厂 / 车型 / 版本 / 年 / 月筛选。上传与计算前先确认维度一致，避免算到空范围。
  4. 列表只读核对 「上传/计算」写入结果，「列表」用于查询、筛选、导出与明细。明细与删除请用操作列按钮，勿依赖整行点击。
权限由管理员在「设置 → 用户管理」配置。看不到某菜单时，先确认账号权限，而不是页面故障。

推荐核价流程

先齐年度主数据，再齐当月政策，最后跑核价（或引擎一键）。

一、年度主数据（缺则引擎硬停）

顺序 做什么 菜单位置
1 上传冲压工艺（零件 + 工序） 冲压工程 → 冲压工艺 → 上传工艺文件
2 上传冲次单价 冲压工程 → 冲次单价 → 上传
3 上传材料清单（BOM，须含成品 L0） 焊接工程 → 材料清单 → 上传
4 上传焊接单价 焊接工程 → 焊接单价 → 上传
5 上传年度零件价、包装运输费 焊接工程 → 对应菜单

二、月度政策与价格（缺则引擎硬停）

数据 菜单位置 说明
钢材基准价 一事一议 → 基准价格 按年 + 月 + 基地覆盖将算钢种
厚度 / 宽度加减价政策 一事一议 → 加减价政策 政策须能完整匹配材料规格
废料月度销售价 一事一议 → 废料月度销售价 按年 + 月 + 基地维护
系统费率等 设置 → 系统设置 全局配置缺失也会阻断引擎

三、计算结果链

  1. 年度可算结果（引擎可自动补算） 冲压加工费 → 焊接工艺拆解 → 成品焊接费。已有可用结果时默认不重算覆盖。
  2. 月度主链 冲压钢材联动价 → 冲压零件价格 → 成品核价（同项目多 BOM 版本会逐个计算）。
  3. 一键方式 数据齐备后，进入「核价 → 自动核价引擎」，选基地 + 年 + 月，先「检查就绪」再启动。
表非空不等于可用：关键钢种、厚度档、政策匹配不全，仍会被引擎视为缺失并硬停。

冲压工程

工艺主数据与冲压加工费（年度核算）。

冲压工艺

  • 上传工艺文件：导入零件与工序信息。
  • 冲压零件列表：按车型/版本查询、核对、查看明细。

冲次单价

  • 上传：导入吨位/冲次单价矩阵。
  • 冲次单价列表：核对已入库单价，供加工费计算使用。

冲压加工费

  • 计算：基于工艺 + 冲次单价生成年度加工费。
  • 列表：查询、审核或导出计算结果。

在自动核价引擎路径下，若该范围尚无加工费结果，会自动补算。

焊接工程

BOM、焊接单价、年度零件价与成品焊接费（技术目录仍为 bom）。

功能 用途
材料清单上传 / 列表 导入并维护 BOM 快照；成品核价要求清单含 L0
产品结构 / 结构图 树形或图形查看 BOM 层级关系
焊接单价 按年 + 基地维护焊接工时单价等
年度零件价 外购件等年度取价来源
包装运输费 成品侧包装与运输费用输入
焊接工艺拆解 按 BOM + 单价生成拆解结果（引擎可补算）
成品焊接费 基于拆解计算 L0 焊接费（引擎可补算）

一事一议

钢材联动所需的基准价、加减价政策与废料月度价。

  • 加减价政策：上传厚度/宽度等加减价规则，并在列表中核对。
  • 基准价格：按月维护钢厂/牌号基准价。
  • 中标钢厂厚度价格一览表：查看中标厚度价格汇总。
  • 废料月度销售价：维护当月废料销售单价，影响零件废料回收扣减。
月度核价前务必确认：基准价覆盖钢种、政策能匹配规格、废料价已按基地填好。三者任一缺口都会导致引擎硬停。

核价

单步计算与结果一览；也可交给自动核价引擎统一编排。

冲压钢材联动价

将基准价 + 加减价政策落到零件材料规格，生成当月钢材联动单价。

  • 计算页：选择年 / 月 / 基地等范围后启动异步任务。
  • 一览页：查询、筛选、导出联动结果。

冲压零件价格核算

在钢材联动价与加工费等基础上，核算冲压零件月度价格。

成品核价

按 BOM 将冲压件价、焊接费、年度零件价、包装运输等汇总为成品（L0）价格。 同一项目存在多个 BOM 版本时，引擎会逐个全算，不会只算最新版。

自动核价引擎

入口仅三个参数：生产基地、年度、月份。

  1. 选择范围 在「核价 → 自动核价引擎」选定基地、年、月。
  2. 检查就绪 系统校验上传/配置是否齐全。红灯项可点「去处理」跳到对应上传/维护页。
  3. 启动运行 通过门禁后一键启动。引擎会自动补算缺失的年度结果，再跑当月钢材 → 零件价 → 成品核价。
  4. 看进度与历史 前端只轮询一个异步任务。可在运行历史中查看步骤状态；卡住的任务也可删除后重跑。

数据分类速查

类型 行为 举例
硬停 上传/配置 缺失则整次停止，并给出跳转 工艺、冲次单价、BOM、焊接单价、年度零件价、包装运输、基准价、加减价政策、废料价、系统费率
补算 年度结果 缺失则自动计算；已有则默认不覆盖 冲压加工费、焊接工艺拆解、成品焊接费
主链 月度结果 按依赖顺序计算 钢材联动 → 冲压零件价 → 成品核价
引擎不改核价公式，只负责发现范围、门禁、调度与进度。金额规则仍由各原有计算模块执行。

常见问题

操作中最常遇到的阻断与处理方式。

引擎提示数据缺失怎么办？

点硬停列表中的「去处理」，按跳转页补传或补维护，再回到引擎点「检查就绪」。 若按钮禁用，说明当前账号无该页权限，需联系管理员开通。

为什么列表有数据仍报缺失？

引擎按将要计算的范围检查覆盖完整性：缺关键钢种、厚度档、政策匹配失败、BOM 无 L0 等，都会判为缺失。

年度加工费 / 焊接费会被覆盖吗？

默认不会。仅当该范围尚无可用结果时引擎才补算；已有结果（含已审核）默认保留。

任务一直显示运行中？

本机异常关机等可能导致任务卡住。可在引擎运行历史中删除该任务（含运行中状态），补齐数据后重新启动。

单步计算和引擎有何区别？

单步页只跑某一个计算；引擎在同一入口下按依赖串起年度补算与月度主链，并统一进度与缺口跳转。 公式与结果表与单步计算一致。

打不开某个菜单？

多为权限未授权。请管理员在「设置 → 用户管理」检查角色与权限码，刷新页面后再试。

核对合册和单表导出怎么选？

跨部门汇报、月度封存选成品核价一览 → 导出核对合册（多 Sheet 一次齐）。 只审某一个环节时，在对应列表页点「导出 Excel」即可。详见上方「Excel 导出能力」。
