知识库 · 核价方案

结构件自动核价平台按材料清单核总成、分总成、冲压件； 顶栏 AI助理解读动因，不算价。 系统菜单「总成核价」出各级核价结果，「冲压零件价」出冲压件月价。 材料清单、冲压工艺、焊接工艺拆解要在投产时先传好； 投产后改图换号走工程变更（换成新结构，不是再传一整本清单）； 冲次单价、焊接单价一年传一次；模具布点 / 检具 / 采购对象按改版维护；再做每月钢价与总成核价。

帮助入口

核的是什么

平台核的是结构件三类对象：总成、分总成、冲压件，不是只核一张钢板，也不是只出成品账。 成品月总账仍从根走到最末零件 → 零件先有价 → 再往上汇总；分总成、冲压件各自也有核价结果。

前置条件（传一次即可）

这些是核价用的结构和工艺。同一范围传好、生成好之后，日常月度核价不必每月重做； 仅当工艺改版、清单换版、焊接结构变化时再更新。

顺序：先把结构和工艺传齐 → 再做年内价格与年度计算结果 → 每月只跑钢价与成品账。
  • 材料清单 焊接工程 → 材料清单。上传成品清单（基地 + 项目 + 清单版本）。只用于第一次投产。之后：清单换版；投产后换零件号走工程变更；本页不会整份覆盖
  • 冲压工艺 冲压工程 → 冲压工艺。上传零件与工序（自制件工艺）。只用于投产第一次上传。再做：工艺文件改版；投产后新号走工程变更里的工艺确认表
  • 模具布点 / 模具单价 冲压工程 → 冲压模具。布点 Excel + 钢板模/级进模单价、分摊万台（单价无年，取当前生效档） · 再做：布点改版或单价调整后；再重算年度模具费
  • 检具费档案 冲压工程 → 冲压检具费。上传万元与分摊万台；核价时摊成元/件 · 再做：检具清单变更
  • 焊接工艺拆解 焊接工程 → 焊接工艺拆解。按材料清单 + 当年焊接单价生成拆解结果（可引擎自动补算） · 再做：清单结构变更，或当年焊接单价调整后重做
  • 采购对象列表 焊接工程 → 采购对象。从材料清单生成「买哪些」集合；确认外发/自制、指定供应商。不进月度算价链 · 再做：清单换版后重新生成

工程变更

工程变更不是在结构上「改几个零件」，而是按材料清单序号决定：这棵交货总成不动、停止，还是整棵换成新结构。 一棵结构就是一个交货总成。顾客改图后它是另一件存货：旧的到期、新的启用。核价按「某年某月仍有效」来取。

处理顺序：变更单 → 材料清单序号 → 交货总成 → 换成新结构 → 打上版本 → 数采购件

错误

变更单 5 条，所以应该有 5 个采购件。一条变化不是一棵交货总成，改过的零件也不是新版本采购件的全部。

正确

5 条变化 → 1 棵完成停止 + 4 棵换成新结构 → 新结构整体属于 EC-202507 → 在这 4 棵上数采购件，一共 17。

换号原因

图变更即为另一物料。交货总成发生改图 / 此件不装 / 增加零件时，总成图变更、交货总成号随之更换。完成停止没有新图、没有新号。仓库按零件号管理；系统照抄变更单上已写出的号，不自动顺延零件号。

为什么用生效月

生效月 = 新结构 / 新工艺从这月启用；旧结构 / 旧工艺写到生效月的前一月为止（行不删）。前一月旧账仍看见旧号。不使用「作废」；一次换号不另传整本清单。

工程变更三张表各管什么

  • 工程变更单 生效年月 + 前后总成 + 变更类型；新旧号以这张表为准
  • 车身件材料清单 新结构骨架（可含「此件不装」剔除行）；总成列 = 变更后总成；中间分总成新号以本表为准；只写变化的行
  • 冲压工艺确认表 新号工艺（号须等于变更后零件）；零件简图只画在这张表，导入后抄到新号工艺与（若建立了）新号布点

工程变更不填、不解析模具布点表。仅改图且变更前零件有仍有效布点时，从库整行抄到新号；完成停止 / 此件不装 / 增加零件（无旧布点可对）不建布点。 工程变更写入后自动列入本结构的采购对象，并从旧结构结果抄焊接拆解；换号则自动抄包装运输费与年度零件价。新加零件的年度价仍人补。

四种变更类型（口径）

  • 完成停止 该交货总成从生效月起不再交货；只到期、不启用新总成；旧工艺 / 布点不到期
  • 改图 旧总成到期、新总成启用；改图层与上级分总成整条链换号（中间分总成号认材料清单）；没改的零件原号带走
  • 增加零件 加在原来的总成上（不是另交一个新总成）；变更后总成须换号；变更前零件空、变更后零件写新号；旧工艺不到期
  • 此件不装 总成还交货但须换总成号；该件用量 0 且备注含「此件不装」；变更后零件空
这棵结构没有「增加零件」时不得改用量；有增加零件则已是新总成，不再拿旧用量拒收。 左右总成共用件：旧号当月仍挂其它有效总成时，不能按改图单独停掉。 操作步骤见帮助 · 工程变更（设计变更与材料变更）；芜湖 T13J · 2025年01月走账见样例。

年度维护（一年传一次 / 算一次，年内复用）

按年 + 基地维护单价与年度计算结果；同年 1～12 月共用，不必每月重传。

  • 冲次单价 冲压工程 → 冲次单价。吨位 / 冲次单价矩阵，供年度加工费使用。
  • 焊接单价 焊接工程 → 焊接单价。焊接工时等单价，供工艺拆解与成品焊接费使用。
  • 上传年度零件价 外购件、沿用件、分总成一口价等取价来源。
  • 上传包装运输费 成品侧运输、仓储捆包等间接费用输入。
  • 算冲压加工费 依赖前置「冲压工艺」+ 本年「冲次单价」。缺失时引擎可自动补算；已有默认不覆盖。
  • 算冲压模具费 依赖模具布点 + 生效模具单价。按年+基地+项目计算，得到元/件最终模具费。有布点且当年无结果时引擎自动补算；缺生效模具单价就算不下去。零件价页不补算，无结果记 0。
  • 算成品焊接费 依赖前置「焊接工艺拆解」（拆解又依赖本年焊接单价）。缺失时引擎可自动补算；已有默认不覆盖。
  • 牌号分类 主数据。一个牌号一行，挂冷轧 / 镀锌 / 酸洗；只手工维护。工艺或基价导入缺档会整批拒绝，不自动补行。
  • 钢厂 主数据。一家一行：缩写显示在页面上，全称对表头，可挂别名。只手工维护。基准价或加减价导入对不上、或命中已停用钢厂，整本退回，不自动建档。
  • 系统费率 财务 / 管理 / 仓储+包装，管理费用率 / 报废 / 税前利润等，全站配置，一般很少改。公司名称与文尾条款同页维护，只进入采购协议导出。

每月核价（月月要做）

前置与年度结果已齐时，每月主要处理「跟钢价走」的账，并算出当月成品总费用。

  • 基准价格、加减价政策、废料月度销售价 当月钢价与废料扣减依据。缺基准价或废料就不能启动。某一钢厂本期已有厚度政策但料厚对不上，也不能启动；该钢厂本期没有厚度政策时按基价计，不因此拦住。
  • 算钢材联动价 政策落到材料规格 → 当月钢价。
  • 算冲压零件价格 材料净额 + 加工费 + 模具费 + 检具费 → 自制件当月单价。无模具/检具档案则费用为 0。
  • 算总成核价 菜单名「总成核价」。按材料清单自下而上汇总成品 → 月总账 + 间接费用 → 总费用。
  • 中标钢厂厚度价格列表（可选） 一事一议：预览/导出中标基价叠厚度加减价。不写入核价结果表。
  • 导出月度核对（可选） 总成核价列表：只导出、不算价；须选定年/月/基地/项目，版本可选。
  • 导出采购价格协议（可选） 采购价格协议（一级菜单）。读已算应成本按月横排，出《批量零部件价格协议》。不算价。采购对象视图一家一导；总成视图整包一份。
同一年里，1～12 月通常变化的是冲压件月价（跟钢价走）； 材料清单、冲压工艺、焊接拆解、模具布点、采购对象不必每月重做； 若当月发生工程变更，核价按该月仍有效的树 / 工艺 / 布点取件（旧号已到期则取新号）。 冲次单价、焊接单价、年度零件价、包装运输、加工费、模具费、焊接费等按年维护。 因此成品总费用会随月微调，而结构和年内单价保持稳定（工程变更月会换号）。

零件取价顺序

  1. 完整零件号 → 当月冲压零件价（算成功的）
  2. 否则完整零件号 → 当年年度零件价（0 表示不计金额，如某些辅料）
  3. 仍找不到且零件号带「-」→ 取第一个「-」前的号，只再用冲压价对一次

自制冲压件当月单价（零件核价）

直接成本 = 原材料净成本 + 加工费 + 模具费 + 检具费

无模具费 / 检具费档案时对应项为 0，零件价页不拦住计算。自动核价会先补算模具费（或缺单价就算不下去）；零件价页缺档就记 0，两处不一样。

公式（成品 / 总成）

月总账 = 冲压件金额 + 外购/年度价金额 + 分总成一口价 + 成品焊接费 + 焊接其它

总费用 = 月总账 + 间接费用合计（含检具分摊预留项，上游未建时为 0）

分总成两种算法

拆散计价（常见）

分总成没有「一口价」时：零件各自计价后向上汇总，不对分总成本身再要一笔。

一口价（包价）

分总成在年度零件价里有包价：只认这一包，不再把下面零件加一遍。

采购对象（集合，不算价）

交主机厂的是有子件的供货总成；采购要管的是能单独向二级买的件，以及「成品就是一张板」的退化供货件。 生成入口：焊接工程 → 采购对象。列入只看树结构，不看有没有价。

  • 退化供货件 成品，下面没有零件
  • 分总成 分总成，下面还有零件
  • 冲压件 这一层已经是最末，且是板料

下面还有零件的供货总成不列入。更下一层的零件不单独列入。分总成这一层上的螺母、胶等进核对区「标准件/胶等」。 列表上确认外发/自制、指定供应商。给二级厂签字的月度价目在「采购价格协议」，不是本页；金额读总成核价已算的应成本，本页不另算一遍。 按工程变更版本筛选，是在数采购件：问「这棵结构属于哪一版」，不是「这次改了几个件」。
