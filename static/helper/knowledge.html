② 知识库 · 核价方案

一句话：按材料清单核算每个成品（供货总成）的月度总费用。 系统菜单叫「总成核价」。材料清单、冲压工艺、焊接工艺拆解为前置底盘； 投产后改图换号走工程变更（时间轴切点，不是再拍全量快照）； 冲次单价、焊接单价一年传一次；模具布点 / 检具 / 采购对象按改版维护；再做每月钢价与总成核价。

核的是什么

核的是交到客户手里的成品（树上的根），不是零散的一个螺栓或一张钢板。 真正算账：从根走到最末叶子 → 叶子先有价 → 再 rollup 回根。

带金额的成品树见样例（青岛 · 2025 · 01 · T28）。 下面各节讲前置、年度、每月如何把叶子价准备好。

成品 = 完工产品

材料清单最顶层的供货总成。系统为每个成品出月总账和总费用。

不是只核冲压件

成品下面既有自制冲压件，也有外购件、分总成。全部挂到同一棵树上再汇总。

材料清单是主线

先有树，再挂价。没有材料清单，就无法确定核价对象。清单属于前置底盘：同一基地 / 项目 / 版本投产传好后长期复用；结构换号、此件不装、增加零件、完成停止走工程变更工程变更，不要当「再传一遍全量清单」。

主线 · 前置
材料清单

告诉系统：成品由哪些分总成、零件组成，各用多少件。

辅助 · 挂价
工艺 / 冲次 / 钢价 / 废料 / 加工费 / 模具费 / 检具费

算出自制冲压件「每个多少钱」。

辅助 · 挂价
年度零件价 / 焊接与拆解 / 包装运输 / 费率

外购件、焊接、间接费用从这里来。

树长什么样

成品（供货总成）── 核价对象
　├── 分总成（下面还有零件）
　│　　├── 自制冲压件
　│　　└── 外购件（螺母、标准件…）
　└── 零件（直接挂在成品下）

用量会沿树往下乘：相对成品的有效用量 = 路径上各层用量连乘。

前置条件（传一次即可）

这些是核价的结构与工艺底盘。同一范围传妥、生成妥之后，日常月度核价不必每月重做； 仅当工艺改版、清单换版、焊接结构变化时再更新。

实务上：先把前置底盘铺齐 → 再做年内价格与年度计算结果 → 每月只跑钢价与成品账。

工程变更（时间轴切点）

工程变更不是在树上「改几个零件」，而是在槽位里决定：这棵树不动、停止，还是换成一棵新树。 一棵树就是一个交货总成。顾客改图后它是另一件存货：旧树到期、新树启用。核价按「某年某月仍有效」取树。

第一屏只记这条链：变更单 → 树坑 → 树 → 换树 → 盖章 → 数采购件

一个序号，就是一个「树坑」；一个交货总成，就是这个树坑里的一棵树。完成停止：旧树到期，历史仍在；新的有效状态下这个树坑不再种新树。

变更单有 5 行，表示记录了 5 条变化；系统再根据这些变化判断哪些树坑需要换树或停止。本例最终处理结果是：1 棵完成停止，4 棵交货总成换成新树。一行变更单不等于一个树坑——同一棵交货总成可以有多条变化记录。

4 是树的数量。17 是树里面采购对象的数量。两者本来就不应该相等。

不要这样理解

变更单 5 行 → 所以应该有 5 个采购对象。也不要：1 行变更单 = 1 个树坑；也不要把改过的零件当成新版本采购对象的全部。

应该这样理解

5 条变化 → 判断树坑 → 1 棵停止 + 4 棵换新树 → 新树完整建立并盖章 → 新树里一共 17 个采购对象。

为什么必须换号

图变了就是另一物料。交货总成只要碰上改图 / 此件不装 / 增加零件，总成图必然变、交货总成号必然换。完成停止没有新图、没有新号。出入库主键是零件号；系统照抄变更单格子，禁止自己把 AA 加成 AB。

为什么用生效月

生效月 = 新树 / 新工艺从这月启用；旧树 / 旧工艺写失效到生效月的前一月（不删行）。前一月旧账仍看见旧号。不要说「作废」；不要为一次换号新建清单版本当切点。

工程变更三张表各管什么

表作用
工程变更单生效年月 + 前后总成 + 变更类型；新旧号以这张表为准
车身件材料清单新树骨架（可含「此件不装」剔除行）；总成列 = 变更后总成；中间分总成新号以本表为准；只写变化的行
冲压工艺确认表新号工艺（号须等于变更后零件）；零件简图只画在这张表，导入后抄到新号工艺与（若建立了）新号布点

工程变更不填、不解析模具布点表。仅改图且变更前零件有仍有效布点时，从库整行抄到新号；完成停止 / 此件不装 / 增加零件（无旧布点可对）不建布点。 工程变更落库时自动插本树采购对象，并从旧树结果抄焊接拆解；年度价 / 包装运输仍人补。

四种变更类型（口径）

类型对交货总成意味着什么
完成停止该交货总成从生效月起不再交货；只到期、不启用新总成；旧工艺 / 布点不到期
改图旧总成到期、新总成启用；改图层与上级分总成整条链换号（中间分总成号认材料清单）；没改的零件原号带走
增加零件加在原来的总成上（不是另交一个新总成）；变更后总成须换号；变更前零件空、变更后零件写新号；旧工艺不到期
此件不装总成还交货但须换总成号；该件用量 0 且备注含「此件不装」；变更后零件空
本树没有「增加零件」时不得改用量（EC_QTY_CHANGED）；有增加零件则已是新总成，不再拿旧用量拒收。 左右总成共用件：旧号当月仍挂其它有效总成时，不能按改图单独停掉。 操作步骤见帮助 · 工程变更；青岛 T28 · 2025年07月五种填法见样例。

年度维护（一年传一次 / 算一次，年内复用）

按年 + 基地维护单价与年度计算结果；同年 1～12 月共用，不必每月重传。

工作说明
一年一传 冲次单价 冲压工程 → 冲次单价。吨位 / 冲次单价矩阵，供年度加工费使用。
一年一传 焊接单价 焊接工程 → 焊接单价。焊接工时等单价，供工艺拆解与成品焊接费使用。
上传年度零件价 外购件、沿用件、分总成一口价等取价来源。
上传包装运输费 成品侧运输、仓储捆包等间接费用输入。
算冲压加工费 依赖前置「冲压工艺」+ 本年「冲次单价」。缺失时引擎可自动补算；已有默认不覆盖。
算冲压模具费 依赖模具布点 + 生效模具单价。按年+基地+项目计算，得到元/件最终模具费。有布点且当年无结果时引擎自动补算；缺生效模具单价硬停。零件价页不补算，无结果记 0。
算成品焊接费 依赖前置「焊接工艺拆解」（拆解又依赖本年焊接单价）。缺失时引擎可自动补算；已有默认不覆盖。
牌号分类 主数据。一个牌号一行，挂冷轧 / 镀锌 / 酸洗；只手工维护。工艺或基价导入缺档会整批拒绝，不自动补行。
系统费率 财务 / 管理 / 报废 / 税前利润等，全站配置，一般很少改。

每月核价（月月要做）

前置与年度结果已齐时，每月主要处理「跟钢价走」的账，并算出当月成品总费用。

工作说明
钢材基准价、加减价政策、废料月度价 当月钢价与废料扣减依据；缺则引擎硬停。
算钢材联动价 政策落到材料规格 → 当月钢价。
算冲压零件价格 材料净额 + 加工费 + 模具费 + 检具费 → 自制件当月单价。无模具/检具档案则费用为 0。
算总成核价 菜单名「总成核价」。按材料清单自下而上汇总成品 → 月总账 + 间接费用 → 总费用。
中标钢厂厚度价格一览（可选） 一事一议：预览/导出中标基价叠厚度加减价。不写入核价结果表。
导出月度核对（可选） 总成核价一览：只导出、不算价；须选定年/月/基地/项目，版本可选。
导出采购价格协议（可选） 采购价格协议（一级菜单）。读已算应成本按月横排，出《批量零部件价格协议》。不算价。采购对象视图一家一导；总成视图整包一份。
同一年里，1～12 月通常变化的是冲压件月价（跟钢价走）； 材料清单、冲压工艺、焊接拆解、模具布点、采购对象不必每月重做； 若当月发生工程变更，核价按该月仍有效的树 / 工艺 / 布点取件（旧号已到期则取新号）。 冲次单价、焊接单价、年度零件价、包装运输、加工费、模具费、焊接费等按年维护。 因此成品总费用会随月微调，而结构底盘与年内单价保持稳定（工程变更月会换号切树）。

零件取价顺序

  1. 完整零件号 → 当月冲压零件价（算成功的）
  2. 否则完整零件号 → 当年年度零件价（0 表示不计金额，如某些辅料）
  3. 仍找不到且零件号带 - → 取第一个 - 前的号，只回退冲压价

自制冲压件当月单价（零件核价）

直接成本 = 原材料净成本 + 加工费 + 模具费 + 检具费

无模具费 / 检具费档案时对应项为 0，零件价页不阻断计算。引擎路径：有布点则先补算模具费（或硬停缺单价），与零件价页「缺档记 0」分工不同。

公式（成品 / 总成）

月总账 = 冲压件金额 + 外购/年度价金额 + 分总成一口价 + 成品焊接费 + 焊接其它

总费用 = 月总账 + 间接费用合计（含检具分摊预留项，上游未建时为 0）

分总成两种算法

拆散计价（常见）

分总成没有「一口价」时：零件各自计价后向上汇总，不对分总成本身再要一笔。

一口价（包价）

分总成在年度零件价里有包价：只认这一包，不再把下面零件加一遍。

采购对象（集合，不算价）

交主机厂的是有子件的供货总成；采购要管的是能单独向二级买的件，以及「成品就是一张板」的退化供货件。 生成入口：焊接工程 → 采购对象。列入只看树结构，不看有没有价。

列入采购对象树上的样子
退化供货件L0 且下面没有 L1
分总成L1 且下面还有 L2
冲压件L1 叶子且是板料

有子件的 L0 永不列入。L2 不单独列入。L1 上的螺母、胶等进核对区「标准件/胶等」。 列表上确认外发/自制、指定供应商。给二级厂签字的月度价目在「采购价格协议」，不是本页；金额读总成核价已算的应成本，本页不另算一遍。 筛 EC-* 版本，问的是「这棵树属于哪个版本」，不是「这次改了几个件」。
