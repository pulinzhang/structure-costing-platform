Operations Guide

① 帮助 · 怎么操作系统

本块只讲「按钮点哪里、任务怎么跑」。概念与算账见知识库；真实数字见样例（2025·01·青岛·T28；工程变更另见 2025·07）。侧栏现网顺序：仪表盘 → 冲压工程 → 焊接工程 → 工程变更 → 一事一议 → 核价 → 采购价格协议 → 文件溯源 → 主数据 → 设置。

快速入门

登录后从左侧 Overlay 导航进入各功能；无权限的菜单会隐藏。

  1. 登录 默认管理员账号见登录页提示。会话失效会跳回登录。
  2. 打开导航 点左上角菜单展开侧栏：仪表盘 → 冲压工程 → 焊接工程 → 工程变更 → 一事一议 → 核价 → 采购价格协议 → 文件溯源 → 主数据 → 设置。没有单独的「报价」菜单。
  3. 先定维度 上传/计算前确认基地、项目、清单版本、年、月一致，避免算到空范围。
  4. 列表只读核对 上传/计算负责写入；列表负责查询、审核、导出。明细请用操作列按钮，不要点整行。

菜单地图

侧栏模块与日常动作对应关系（年/月节奏见知识库）。

菜单你在这里做什么
仪表盘按年/月/基地/项目看本期产出、待补价、待审
冲压工程工艺、模具布点与单价、冲次单价、加工费、模具费、检具费。投产 SOP 后再换号请走工程变更，不要在本页整包覆盖。
焊接工程材料清单（核价主线）、焊接单价、包装运输、采购对象、年度零件价、焊接拆解与焊接费。投产后结构换号走工程变更。
工程变更合册上传（变更单 + 材料清单 + 工艺确认表）；列表核对与整本回滚。路径 #/engineering-change-upload、#/engineering-change-order-list。
一事一议加减价政策、基准价、中标钢厂厚度价、废料月度价
核价钢材联动 → 冲压零件价 → 总成核价（成品月总账）；自动核价引擎；核对合册
采购价格协议签二级厂的《批量零部件价格协议》；只读、不算价；一级菜单
文件溯源查历史上传的原件（分类、基地、年月、项目、上传人）
主数据基地、项目、供应商、牌号分类
顶栏 AI 助理用自然语言问核价结果或操作步骤；系统算数，AI 写 Markdown 解释
设置个人资料、系统费率、用户权限、操作日志
材料清单在「焊接工程」里维护，但它是整棵核价树的主数据；其它菜单多是给树上的节点挂价钱。 菜单上的「总成核价」就是按材料清单根节点（供货总成 / 成品）出月总账。

冲压工程

自制件工艺底盘 + 年度费用。冲次单价一年一传；模具单价是当前生效档，不算年。

菜单做什么
冲压工艺上传工艺确认表；零件列表核对自制件与工序。
冲压模具上传模具布点；模具清单；维护钢板模 / 级进模单价与分摊万台。
冲次单价按年 + 基地上传吨位矩阵，供冲压加工费使用。
冲压加工费按年 + 基地 + 项目计算；缺失时引擎可自动补算。
冲压模具费按年 + 基地 + 项目，用布点重量 × 模具单价算出元/件最终模具费。引擎不自动补算；无档案时零件价里模具费记 0。
冲压检具费上传检具档案（万元与分摊万台）。零件核价时万元÷万台 = 元/件；无档案记 0。
家模副产品（布点四列全空或工艺已打标）不算模具费、不继承共模重量。加工费与模具费公式互不共用。

焊接工程

先有材料清单树，再挂焊接与采购集合。采购对象不管价，只回答「买哪些」。

菜单做什么
材料清单上传、列表、产品结构、结构图。同一套 BOM。
焊接单价一年一传；拆解与成品焊接费都依赖它。
包装运输费按年维护成品侧运输 / 仓储捆包。引擎里缺档是软提示，不阻断启动。
采购对象从材料清单生成集合：退化供货件、分总成、冲压件列入；标准件/胶等与异常进核对区。列表可确认外发/自制、指定供应商、导出。
年度零件价外购件、沿用件、分总成一口价等取价来源。
焊接工艺拆解按清单 + 当年焊接单价生成；已有结果时引擎默认不覆盖。
焊接费按拆解结果算成品焊接费；引擎可对缺失结果自动补算。
有子件的供货总成永不列入采购对象（主机厂不允许整层外发）。L2 跟在分总成下，不单独列入。

工程变更

投产 SOP 之后，顾客改图换号、此件不装、增加零件、完成停止，一律走侧栏「工程变更」。 不要再在材料清单 / 冲压工艺 / 模具布点上传页做整包覆盖换号。

菜单做什么
上传工程变更 选采购基地、项目、生效年/月，上传合册 Excel。路径 #/engineering-change-upload。异步解析，本页看进度。
工程变更单列表 按变更单行查询；可筛年/月/基地/项目/状态/变更类型。路径 #/engineering-change-order-list。删任意一行 = 按同一次上传整本回滚，并删除上传头 / 变更单 / 效果链接；原件仍在文件溯源。

合册怎么传

  1. 定切点 上传页的采购基地、项目、生效年月必须与工程变更单一致（不填清单版本、不填顾客）。生效月写入切点：新总成从该月启用；变更前总成用到前一月到期（行不删）。生效月须晚于旧总成生效月。
  2. 下模板或按样表填 「下载模板」即青岛 T28 五种填法对照本（与现网 build_engineering_change_template 同一本）。硬门禁三张表：工程变更单、车身件材料清单、冲压工艺确认表。不要「零件汇总」。
  3. 变更单一行一种改法 类型只准四句：完成停止 / 改图 / 增加零件 / 此件不装。零件层级只准：总成 / 一级 / 二级。同一本可多行；同一总成多场景须连续行并合并变更前/后总成格。
  4. 新旧号只认格子 系统照抄工程变更单与材料清单已写出的号，禁止自己把 AA 加成 AB。材料清单总成列 = 变更后总成；中间分总成新号以材料清单为准；只写变化的行。本树没有「增加零件」时，有旧可对的零件用量须等于变更前总成（此件不装只能写 0）。
  5. 上传后核对 成功后到列表看变更单行。合册会自动为本树插入采购对象，并从旧树结果抄焊接拆解；年度零件价 / 包装运输费仍要人补。工艺 / 模具列表带生失效区间（可含已到期）；月度核价按账期月命中仍有效的树与工艺。

四种变更类型（操作要点）

类型你在 Excel 里做什么
完成停止变更后总成空；材料清单不写该总成。整棵交货总成到期停交；旧工艺 / 布点不到期。
改图写出旧→新总成。层级=总成时零件两列空；一级/二级写出改图层旧→新号，材料清单写出整条换号链。工艺确认表给出新号（含简图）。有旧布点则系统从库逻辑建立新号布点（简图从工艺确认表抄）。
增加零件变更后总成须写出新号；变更前零件空、变更后零件写新号；材料清单只写新件（用量 > 0）；冲压件须出新号工艺。不停旧工艺；无旧布点可对则不建布点。
此件不装变更后总成须写出新号；用量 0 且备注含固定句「此件不装」（双信号缺一拒收）；变更后零件空。不碰布点。
删除前确认：状态不是「进行中」；其后没有未回滚变更；相关采购对象未审（或已反审）。否则会提示不能删本次。原件请到文件溯源下载。 概念与按月取树规则见知识库 · 工程变更；青岛 T28 五种填法见样例。

一事一议

钢价联动的输入。每月核价前要齐基准价、厚度加减价政策、废料月度价。

菜单做什么
加减价政策上传厚度 / 分类级加减价。覆盖不全时引擎作软提示（不硬停）。
基准价格当月各钢厂牌号基价；缺则引擎硬停。牌号必须已在主数据牌号分类。
中标钢厂厚度价格一览表选定年/月/基地后预览或导出：中标基价叠厚度加减价。不改核价库。
废料月度销售价当月废料扣减依据；缺则引擎硬停。

核价模块

月度主链：钢材联动 → 冲压零件价 → 总成核价。也可交给自动核价引擎一次跑完主链。签二级厂走一级菜单「采购价格协议」，不在核价里。

菜单做什么
冲压钢材联动价政策落到材料规格 → 当月钢价。
冲压零件价格核算材料净额 + 加工费 + 模具费 + 检具费 → 自制件当月单价。无模具/检具档案则对应费用为 0。
总成核价按材料清单自下而上汇总成品月总账与总费用。计算页路径 #/assembly-cost-calc，一览 #/assembly-cost。旧称「成品核价 / L0」。
自动核价引擎只选基地 + 年 + 月；见下一节。

自动核价引擎

入口只有三个参数：生产基地、年度、月份。先「检查就绪」，再「启动」。

  1. 选范围 例如样例：青岛 · 2025 · 01。
  2. 检查就绪 硬门禁缺上传/配置会红灯，可点「去处理」跳到对应页。厚度加减价、包装运输费为软提示，不阻断启动。
  3. 启动 缺的年度加工费、焊接拆解、成品焊接费会自动补算；再跑当月钢材 → 冲压零件价 → 全部 BOM 版本的总成核价。模具费 / 检具费 / 采购对象不在引擎补算计划里。
  4. 看历史 一个任务通道看进度；任意状态（含运行中）的任务都可删除后重跑，避免本机关机后卡住。

采购价格协议

一级菜单，与核价并列。给二级厂签《批量零部件价格协议》。只读查询 + 导出，不算价。

项说明
入口路径 #/procurement-contract-report，在核价之后、文件溯源之前。不在核价子菜单里。
视图默认「采购对象」（可筛供应商，一家一导）；「总成」整包一份、不筛供应商、乙方现场填。
窗口最多 12 个月；打开页面默认最近一次核价的单月。缺结算价显示斜杠。
前提采购对象视图须先有采购对象清单；总成视图不依赖清单，但要先有材料清单和已算的总成价。

文件溯源

侧栏独立入口。所有历史上传的 Excel / 原件在此按分类、基地、年、月、项目、上传人、文件名筛选；操作列打开详情，可核对是哪一次上传写入了核价主数据。

  • 不改业务数据，只查档案。
  • 无权限时菜单隐藏。

主数据

绝对上游档案。一事一议和核算只读，不在此切片之外写入牌号分类。

菜单做什么
牌号分类一个牌号一行，挂冷轧 / 镀锌 / 酸洗。只在本页手工新增或编辑。冲压工艺、基准价导入不自动补档；缺牌号整批拒绝。档案仍被零件材质或基价引用时不能删除。

AI 助理（核价智能分析）

顶栏右侧 AI 助手 按钮打开浮窗。数字由核价库计算，AI 只负责用自然语言解释——问什么答什么，不铺固定报告模板。

  1. 提问 直接输入或点下方胶囊，例如：「青岛 T28 近 3 个月成品价趋势」「今年与去年对比」「501006875AA 为什么涨了」。可接着问「那青岛呢」「贵在哪」——系统沿用上一问的基地、项目和期别。清空本机对话后重新起问。对话进行中从历史点开只是阅读；若要接某条历史接着问，先清空再打开那一条。
  2. 等待分析 系统异步跑查询与统计（无流式打字机）；状态栏显示进行中，完成后聊天区展示 Markdown 正文。
  3. 分析历史 点浮窗右上角时钟图标，查看本人历史记录（分页加载）；可重开、删除。管理员也只能看自己的记录。
  4. 导出 单条回答可打印或导出 Word（含问句、范围与时间元信息）。
口径说明：若 BOM 版本变化导致不可严格同比，正文会写明 tight / loose；缺价零件不计入趋势与动因，并在正文中提示排除条数。
  • 无 LLM_ANALYSIS_RUN 权限时顶栏按钮隐藏。
  • 未配置 LLM_API_KEY 时仍可分析，但解释层会降级为规则摘要。
  • 问操作步骤（如「怎么上传工艺」「采购对象在哪」）会命中本帮助语料，不编造菜单路径。

导出 Excel

各列表页有「导出 Excel」；总成核价一览还有「导出核对合册」（多表一本）；「采购价格协议」页导出的是《批量零部件价格协议》。

  • 合册：须选定年 / 月 / 基地 / 项目 / 清单版本。同一文件串联总成价、冲压零件价、加工费、钢材联动、年度价、包装运输、焊接单价等，带封皮说明。只导出、不算价。
  • 采购价格协议「导出协议」：与页上筛选同一套（含采购对象 / 总成视图），不分页、无水印。采购对象视图筛一家供应商即一份；总成视图整范围一份。先算总成核价才有结算价。
  • 单表：只审某一环节时用对应列表的导出按钮（含模具费、检具费、采购对象、中标厚度价）。
  • 无导出权限时按钮会隐藏或提示。

操作问答

看不到某个菜单？

找管理员在「设置 → 用户管理」开通权限后刷新。

引擎一直运行中？

本机异常关机可能导致自动核价引擎任务卡住。在「核价 → 自动核价引擎」的运行历史中删除该任务后重新启动。删除不会撤销已写入的钢材价、零件价或总成价。

采购价格协议和采购对象有什么区别？

「焊接工程 → 采购对象」只管集合：买哪些、外发还是自制、供应商是谁，不管价。「采购价格协议」（一级菜单）读已算的应成本，按合同期横排月列，导出给二级厂签字的协议。拆到冲压件 / 分总成签用「采购对象」视图；整包总成签用「总成」视图。

投产后改图、换零件号走哪里？

走「工程变更 → 上传工程变更」。材料清单 / 冲压工艺 / 模具布点页只做投产 SOP；已有 SOP 后再导文件出现新号会整单拒绝。合册须含工程变更单、车身件材料清单、冲压工艺确认表；不要「零件汇总」。

工程变更上传失败或想撤销？

业务失败时系统会先回滚半截写入再记失败。成功后要撤销：打开「工程变更单列表」，删任意一行即整本回滚（删上传头 / 变更单 / 效果链接）；原件仍在文件溯源。进行中、其后还有未回滚变更、或采购对象已审未反审，会拒删。

成品核价计算卡住了？

总成核价（旧称成品核价）计算时，本机异常关机或关闭浏览器后，计算历史里可能仍显示计算中，系统会拒绝重复提交。打开「核价 → 总成核价计算」（路径即成品核价计算页），在页面下方计算历史中找到状态为「计算中」的记录，点删除释放锁，再重新「开始计算」。删除只清日志与计算锁，不会撤销已写入总成核价一览的数据。

AI 助理一直分析中？

同一时间每人最多 2 个并发任务。若长时间无响应，可缩小时间范围后重试，或清空本机对话后重新提问。

需要了解概念或计算细节？

请参阅 知识库；需要对照实例请参阅 样例。
