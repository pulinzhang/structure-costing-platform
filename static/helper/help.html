Operations Guide

① 帮助 · 怎么操作系统

本块只讲「按钮点哪里、任务怎么跑」。概念与算账见知识库；真实数字见样例（2025·01·青岛·T28）。

快速入门

登录后从左侧 Overlay 导航进入各功能；无权限的菜单会隐藏。

  1. 登录 默认管理员账号见登录页提示。会话失效会跳回登录。
  2. 打开导航 点左上角菜单展开侧栏：仪表盘 → 冲压工程 → 焊接工程 → 一事一议 → 核价 → 报价 → 设置。
  3. 先定维度 上传/计算前确认基地、项目（车型）、清单版本、年、月一致，避免算到空范围。
  4. 列表只读核对 上传/计算负责写入；列表负责查询、审核、导出。明细请用操作列按钮。

菜单地图

侧栏模块与日常动作对应关系（详细「年/月」见知识库）。

菜单你在这里做什么
冲压工程上传工艺与冲次单价；计算/查看冲压加工费
焊接工程上传材料清单（核价主线）、焊接单价、年度零件价、包装运输；拆解焊接并算成品焊接费
一事一议基准价、加减价政策、废料月度价（钢价联动输入）
核价钢材联动 → 冲压零件价 → 成品核价；自动核价引擎；导出合册
顶栏 AI 助理用自然语言问核价结果（趋势、动因、对比、下钻、风险）；系统算数，AI 写 Markdown 解释
设置系统费率、用户权限、操作日志
材料清单在「焊接工程」里维护，但它是整棵核价树的主数据；其它菜单多是给树上的节点挂价钱。

自动核价引擎

入口只有三个参数：生产基地、年度、月份。先「检查就绪」，再「启动」。

  1. 选范围 例如样例：青岛 · 2025 · 01。
  2. 检查就绪 缺上传/配置会红灯，可点「去处理」跳到对应页。
  3. 启动 缺的年度计算结果会自动补算；再跑当月钢材 → 冲压零件价 → 成品核价。
  4. 看历史 一个任务通道看进度；卡住的任务可删除后重跑。

AI 助理（核价智能分析）

顶栏右侧 AI 助手 按钮打开浮窗。数字由核价库计算，AI 只负责用自然语言解释——问什么答什么，不铺固定报告模板。

  1. 提问 直接输入或点下方胶囊，例如：「青岛 T28 近 3 个月成品价趋势」「今年与去年对比」「501006875AA 为什么涨了」。
  2. 等待分析 系统异步跑查询与统计（无流式打字机）；状态栏显示进行中，完成后聊天区展示 Markdown 正文。
  3. 分析历史 点浮窗右上角时钟图标，查看本人历史记录（分页加载）；可重开、删除。管理员也只能看自己的记录。
  4. 导出 单条回答可打印或导出 Word（含问句、范围与时间元信息）。
口径说明：若 BOM 版本变化导致不可严格同比，正文会写明 tight / loose；缺价零件不计入趋势与动因，并在正文中提示排除条数。
  • 无 LLM_ANALYSIS_RUN 权限时顶栏按钮隐藏。
  • 未配置 LLM_API_KEY 时仍可分析，但解释层会降级为规则摘要。
  • 问操作步骤（如「怎么上传工艺」）会命中本帮助语料，不编造菜单路径。

导出 Excel

各列表页有「导出 Excel」；成品核价一览还有「导出核对合册」（多表一本）。

  • 合册：同一文件串联成品价、冲压零件价、加工费、钢材联动、年度价、包装运输、焊接单价等，带封皮说明。
  • 单表：只审某一环节时用对应列表的导出按钮。
  • 无导出权限时按钮会隐藏或提示。

操作问答

看不到某个菜单？

找管理员在「设置 → 用户管理」开通权限后刷新。

引擎一直运行中？

本机异常关机可能导致自动核价引擎任务卡住。在「核价 → 自动核价引擎」的运行历史中删除该任务后重新启动。

成品核价计算卡住了？

本机异常关机或关闭浏览器后，计算历史里可能仍显示计算中，系统会拒绝重复提交。打开「核价 → 成品核价计算」，在页面下方计算历史中找到状态为「计算中」的记录，点删除释放锁，再重新「开始计算」。删除只清日志与计算锁，不会撤销已写入成品核价一览的数据。

AI 助理一直分析中？

同一时间每人最多 2 个并发任务。若长时间无响应，可缩小时间范围后重试，或清空本机对话后重新提问。

需要了解概念或计算细节？

请参阅 知识库；需要对照实例请参阅 样例。
