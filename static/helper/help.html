Operations Guide

① 帮助 · 怎么操作系统

本块只讲「按钮点哪里、任务怎么跑」。概念与算账见知识库；真实数字见样例（2025·01·青岛·T28）。

快速入门

登录后从左侧 Overlay 导航进入各功能；无权限的菜单会隐藏。

  1. 登录 默认管理员账号见登录页提示。会话失效会跳回登录。
  2. 打开导航 点左上角菜单展开侧栏：仪表盘 → 冲压工程 → 焊接工程 → 一事一议 → 核价 → 报价 → 设置。
  3. 先定维度 上传/计算前确认基地、项目（车型）、清单版本、年、月一致，避免算到空范围。
  4. 列表只读核对 上传/计算负责写入；列表负责查询、审核、导出。明细请用操作列按钮。

菜单地图

侧栏模块与日常动作对应关系（详细「年/月」见知识库）。

菜单你在这里做什么
冲压工程上传工艺与冲次单价；计算/查看冲压加工费
焊接工程上传材料清单（核价主线）、焊接单价、年度零件价、包装运输；拆解焊接并算成品焊接费
一事一议基准价、加减价政策、废料月度价（钢价联动输入）
核价钢材联动 → 冲压零件价 → 成品核价；自动核价引擎；导出合册
设置系统费率、用户权限、操作日志
材料清单在「焊接工程」里维护，但它是整棵核价树的主数据；其它菜单多是给树上的节点挂价钱。

自动核价引擎

入口只有三个参数：生产基地、年度、月份。先「检查就绪」，再「启动」。

  1. 选范围 例如样例：青岛 · 2025 · 01。
  2. 检查就绪 缺上传/配置会红灯，可点「去处理」跳到对应页。
  3. 启动 缺的年度计算结果会自动补算；再跑当月钢材 → 冲压零件价 → 成品核价。
  4. 看历史 一个任务通道看进度；卡住的任务可删除后重跑。

导出 Excel

各列表页有「导出 Excel」；成品核价一览还有「导出核对合册」（多表一本）。

  • 合册：同一文件串联成品价、冲压零件价、加工费、钢材联动、年度价、包装运输、焊接单价等，带封皮说明。
  • 单表：只审某一环节时用对应列表的导出按钮。
  • 无导出权限时按钮会隐藏或提示。

操作问答

看不到某个菜单？

找管理员在「设置 → 用户管理」开通权限后刷新。

引擎一直运行中？

本机异常关机可能导致卡住。在运行历史删除该任务后重跑。

需要了解概念或计算细节？

请参阅 知识库；需要对照实例请参阅 样例。
