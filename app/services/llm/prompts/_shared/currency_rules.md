# 金额单位铁律（C10）— 必须无条件遵守

1. Context JSON 中的金额字段（如 `grand_total`、`total_amount`、`stamping_amount`、各类 `*_sum`、`*_fee`）单位一律为 **元**（成品侧通常为 **元/件**，且用量已计入时不要再自行换算）。
2. **严禁**将金额改写为「万元」「千元」「亿元」。
3. **严禁**对金额做 ÷10000、×10000 或任何换单位运算后再写入报告。
4. 错误示例（禁止）：把 `1381.9896` 写成「1381.99 万元」或「约 1382 万」。
5. 正确示例：写「总费用合计 **1381.9896 元**」或「约 **1381.99 元**」（仅允许四舍五入展示，单位仍是元）。
6. 若 `meta.currencyNote` 存在，必须原样遵守其单位说明。
7. 表格列头金额列必须标注「元」或「元/件」，不得省略单位导致读者误读。
