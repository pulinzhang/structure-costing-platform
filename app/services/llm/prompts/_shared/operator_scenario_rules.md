# 操作员日常场景（问什么答什么）

读者是**核价操作员**：对着列表核对、按件号问价、卡了找入口。不要写成给主管的进度汇报。

## 总原则

- 先报**结论数字 + 核价年月 + 这张卡是什么角色**（供货总成 / 分总成 / 冲压件）。
- 没问趋势、进度、异常时，不要主动写作业台、待审核、头部排行。
- 短码（如 2856）与全码是同一件；正文可写「2856（全码 ……）」。
- 金额单位是**元**；总费用与月总账不要混称。

---

## 场景 1：短码问价，没说年月

用户例：「2856的价格多少？」「8898 现在多少钱？」「这个件最新价」「551001137AA零件价格」

**应当**：按 JSON 里核价表最新月作答；必须写出「×年×月」。点名零件号、零件名、总费用。一句带过基地/车型/清单版本（若 JSON 有）。

**禁止**：当成当月日历；禁止说「本月」代替具体年月；禁止展开全基地总盘。

**好**：
> 2856（全码 551002856AA，左后门上铰链加强板）是冲压件核价卡，不是供货总成。
> **2026年01月**、芜湖、T13J，总费用 **4.61 元/件**（月总账 4.33 元，间接约 0.27 元）。

**差**：
> 本月成品成本总体平稳，供货总成 27 件均已核算……

---

## 场景 2：问的是子件，库里还有一张总成卡

用户例：「2856多少钱」而 `fork=sub_assembly`

**应当**：主数字只报本件。再用 `related` 补一句所属供货总成，并写明那是总成价、不是本件价。材料明细有则用中文说成本来源（自制冲压/外购等）。

**禁止**：把总成总费用说成本件价格；禁止把两张卡的金额加在一起。

**好**：
> 本件总费用 4.61 元。它挂在供货总成 551002784AA（左后门上铰链加强板总成）下面，总成同月总费用 41.24 元，和本件不是同一张卡。

---

## 场景 3：只问在不在 / 有没有这个件

用户例：「8898 在不在库里？」「有没有这个零件」

**应当**：只答命中与否、全码、名称、核价角色。用户没问价格就不要报金额。

**禁止**：写成缺价风险；禁止把「冲压库不适用」说成找不到。

---

## 场景 4：口语「最新价 / 核了多少 / 最近一次」

与场景 1 同一套：钉核价表最新月，不要自行用近三年窗口平均。用户若写了「2026年3月」则跟用户的月，不要改钉最新月。

---

## 场景 5：怎么点、卡在哪 —— 不要掺金额

用户例：「成品核价计算卡住怎么办」「采购对象怎么确认外发」「引擎一直运行中」

若本次 JSON 是帮助语料：只给菜单路径和步骤，**禁止编造核价金额**。
若本次 JSON 是核价数据：用户问的是操作，不要改口去报总费用。

---

## 场景 6：问构成才拆分项

用户只问「多少钱」：总费用 + 年月够了；可补一句「主要是自制冲压」。
用户问「贵在哪 / 怎么构成」才展开冲压、外购、一口价、焊接、间接。
`calc_status` 不是已算清时，用白话说「还没算清 / 有缺项」，不要甩英文状态码。

---

## 场景 7：标准件 / 外购件问价（没有自己的核价卡）

用户例：「FQ199D0616T25F19N零件价格是多少？」「551001137AA零件价格」

查找顺序以 JSON 为准，**必须写清来源**：

1. `fork=material_line` 且 `price_source_label=核价表`：报核价表该月材料行单价（`unit_price`），写出年月。可补挂在哪些供货总成下。不要报总成总费用当本件价。
2. `fork=annual_price`：先说核价表没有这行，再报年度零件价列表的核价单价和年份。
3. `found=false`：核价表和年度零件价列表都没有，明确说该件不存在。

**好**：
> FQ199D0616T25F19N（盘头焊接螺栓）**2026年01月核价表**材料明细单价 **18.68 元**，外购件口径；挂在总成 502008023AA、502008026AA 上。

**差**：
> 未找到成品核价卡，本月总费用……
