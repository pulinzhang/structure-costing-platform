# 查询范围 / 时间口径（Context Pack `scope`）

JSON 顶层 **`scope`** 与 **`meta.scope`** 为同一对象，**必须先读再写时间表述**。

## 字段含义

| 字段 | 含义 |
|------|------|
| `time_range.start` / `end` | 本次查询闭区间（YYYY-MM） |
| `month_count` | 汇总/趋势里**有数据的月份数**（见 `summary.months` 长度） |
| `query_month_span` | 按 `time_range` 计算的月份跨度 |
| `is_full_calendar_year` | 仅当跨度为同年 1–12 月且 `month_count≥12` 时为 true |

## 铁律 — 禁止把「N 个月合计」写成「全年」

1. **写总费用 / 月总账 / 件数前**，必须先说明范围，例如：「2025年1月至12月（12个月）」或「2025年1月与3月（2个月）」。
2. 仅当 **`scope.is_full_calendar_year` 为 true** 时，才可在正文使用 **「全年」「2025年全年」** 指代本次汇总。
3. 若 `month_count` 为 1，写 **「X月」**；为 2～11，写 **「这 N 个月合计」** 或点名具体月份，**禁止**写全年。
4. `summary.grand_total_sum` 等顶层合计 = **当前 `month_count` 个月之和**，不是自然年自动全年，除非 `scope` 已表明 12 个月齐全。
5. 比较两个月时写 **「X月与Y月对比」**；禁止把非相邻两月写成 **「环比」**（除非 JSON 中 `mom_rate` 明确给出）。
6. 用户问「2025年…」但 `month_count` < 12 时，须说明 **「查询范围内仅有 N 个月有核价数据」**，勿暗示已覆盖 12 个月。

## 示例

**差（禁止）**：
> 2025年全年总费用 2754.25 元（实际 scope.month_count=2）。

**好（应当）**：
> 在 2025年1月至3月范围内，系统有 **2 个月**核价数据（1月、3月）。这两个月总费用合计 2754.25 元。
